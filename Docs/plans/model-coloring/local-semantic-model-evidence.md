## 已取得的模型证据

1. MediaPipe 官方 C 接口正面探针：方飞、刘亦菲各 1 张脸，双人 2 张脸，动物 0 张脸。原始人体分割在动物上仍误报身体皮肤，因此脸部检测门槛必须保留。这不等于六视角动物回归已经通过。
2. MobileSAM 已纠正归一化补边、尺寸取整及坐标换算。耳部离线结果中，刘亦菲、方飞和双人女性有可用轮廓；双人男性只选出部分内耳，即使质量分数高也记为失败/部分结果。
3. 扩展眼部/眉毛后，模型表现按目标区不同。刘亦菲眉毛存在连接邻近头发/眼区的风险，方飞虹膜可能包含眼白，不能直接用未经保护的软掩膜覆盖材料。
4. 对照工具现对两模型采用相同的正负提示一致性选择规则，读取真实模型质量分数。EfficientSAM 固定实现对负点 label=0 的支持未获证实；不把接口契约不满足直接等同于模型轮廓能力差。
5. 固定提示、自动提示、C++ 原生输出、三维材料变化将分开记录。ROI 图改善但三维材料未变不计作优化成功。

## 限制与启用结论

MobileSAM 为本机实验候选，耳发、眼部、眉毛分别验证；低可靠度 ROI 保留基线。EfficientSAM 保留作离线能力/接口对照，当前不接入程序自动配色。以上不是商用发布资格结论，也不代替用户的四模型六面视觉反馈。

当前材质统计按可靠语义连通区独立进行，避免全局肤色/发色中心；尚未建立跨视角稳定人物身份。任意相连双人网格不能据此宣称人物完全独立。四样本的技术结果与残留问题记录在 `local-semantic-validation.md` 的候选 e 段落；用户六面视觉判断尚未完成。

无可信人工标注，轮廓 P95 和准确率不报告数值。ImageMap 独立探针的预测颜色也不作为实物叠色标定结果。
