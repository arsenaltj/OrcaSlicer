# 模型生成三风格质量扩展报告

日期：2026-08-27

范围：单色写实雕塑、多色写实、多色卡通；不包含自定义风格和 Tripo 付费生成。

## 结论

- 第一轮覆盖 16 个不同案例、48 张 Image2：48/48 成功，48/48 通过 3D 输入门禁，平均质量分 99.25。
- 定向修正覆盖 5 个高风险案例、15 张 Image2：15/15 成功，15/15 通过 3D 输入门禁，平均质量分 98.67。
- 两轮合计 63 次 Image2、0 次失败、0 次 Tripo、0 次自动付费重试；三种风格各 21 张。
- 结构门禁只有 6 个非阻断提示：4 个轻微软透明边缘、1 个主体接近画框、1 个疑似多组件；没有不可解码、主体丢失、严重裁切、背景未隔离或不可作为 3D 输入的结果。
- 定向修正已经验证：非人物无底座源图不再新增展示底座；浅浮雕/徽记刻线在四色映射后仍保留；人物配饰、手持物和复杂叶片按源图保留。2026-08-28 起，人像为保证摆放稳定，统一增加低矮一体底座。

## 三种风格分别优化了什么

### 单色写实雕塑

- 单色只改变材质，不再被解释成“减少零件”。开孔、把手、轮子、肢体、层级和源图已有底座都必须保留。
- 保留人物身份、年龄、脸型、头部方向、发型、眼镜/帽子、手部接触和裁切范围。
- 人像无论源图是否带底座，都增加一个低矮、平底、一体连接的展示底座；半身像只连接现有躯干下缘，不补造骨盆、腿或脚；非人物仍保持源图底座语义。
- 细杆、栏杆、触角、枝杈只允许轻微加粗，不允许删除、复制或断开。

### 多色写实

- 只改变材质和颜色处理，主体身份、视角、左右关系、比例、数量和组件布局保持不变。
- 商品与机械不再被泛化成“同类常见产品”；轮组、旋钮、镜头、把手、开孔、格栅、表盘和天线按源图数量与位置保留。
- 徽记刻线、格栅条、面板分界和关键接缝使用连续的可打印结构色，不依赖会被四色映射吃掉的微弱明暗。
- 色彩仍沿用当前“耗材色 + AI 推荐/自定义”逻辑，最终 model-reference 只包含加载的打印色。

### 多色卡通

- 可爱感来自更干净的曲线、圆润转折、友好表情和材料感，不通过换脸、过度放大眼睛、缩短鼻嘴或改变标志性比例实现。
- 人像保留年龄、脸型、发型、姿态、服装和配饰；不会统一成通用娃娃脸或动漫脸。
- 动物保留品种线索、耳形、口鼻、眼睛、尾巴姿势及毛色/壳片/羽毛花纹。
- 商品和建筑仍按真实组件库存生成，不因卡通化而减少轮子、窗户、旋钮、书本、叶片或结构连接。

## 建议的内部测试方法

1. 每个案例依次生成单色写实雕塑、多色写实、多色卡通，先对照 raw 预览检查主体，再对照四色 3D 参考图检查颜色映射。
2. 按表中“数量型”元素逐个数：眼镜、书、叶片、轮子、旋钮、窗户、门、镜头、手柄、肢体。
3. 再检查“关系型”元素：左右朝向、手持物接触、背带路径、轮臂连接、开孔/负空间、人像一体底座，以及非人物已有底座与无底座语义。
4. 任何一项丢失、增加、镜像或泛化，都记录案例、风格、raw/3D reference 哪一阶段开始变化；这能区分 Image2 问题和本地四色映射问题。
5. 只有通过本地 3D 输入门禁且人工保真检查通过的图片才进入 Tripo；本报告没有为验证而批量调用 Tripo。
