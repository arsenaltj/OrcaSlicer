# 三风格、色板保真与一键 G-code 设计

## 目标

把当前 `输入 -> 风格预览 -> 3D -> 导入` 流程扩展为稳定的 Windows 演示黄金路径：用户选择 Q 版卡通、赛博朋克或古典风格，确认风格化图片后只需一次生成操作，系统负责生成可打印低模、颜色映射、导入、尺寸规范化、摆盘和切片，最终进入 G-code 预览。

## 图片与颜色

风格不再依赖自由文本中的关键词，而以 `q_cartoon`、`cyberpunk`、`classical` 三个稳定 ID 在 GUI、C++ 客户端和 sidecar 间传递。每个 profile 独立描述造型比例、材质、构图、打印结构和禁止项，并共享单主体、完整轮廓、稳定底座、无悬浮碎件约束。

图片生成阶段把耗材色作为主导色和语义分区建议，不再要求 provider 直接输出仅含精确 HEX 的图。生成后使用确定性两阶段映射：先从平滑后的 AI 图提取与耗材色数量相同的自适应颜色簇，再将颜色簇与耗材色做一对一最小感知距离匹配。这样每个配置色都会对应一个真实图像区域，避免最近色量化和大窗口众数滤波把小面积颜色吞掉。输出仍严格只含耗材色，并记录每种颜色的像素占比。

## 3D 与自动切片

Tripo 目标面数下调，为 20,000 面硬门禁留余量。每次用户生成最多进行有限次自动尝试；每个生成/转换 task ID 和失败诊断都持久化到任务目录。只有 OBJ 同时满足三角面、单连通、封闭流体和严格色板门禁才允许导入，因此 Orca 不再需要手工修复或简化。

Orca 增加 AI 专用 OBJ 导入入口：按当前项目耗材色自动把顶点色映射到挤出机，不显示颜色映射对话框。导入成功后自动选择新对象、适配打印体积、确保落床、摆盘，并触发当前 plate 切片；完成后切换 Preview。自动流程失败时保留模型和任务目录，显示具体停在哪一步，不静默丢色或删除产物。

## 验收

- 三种风格都能在同一输入上生成可辨识、完整构图的预览。
- 打印预览精确使用全部选择色，色板外像素为零，且不存在大片噪点抖动。
- 真实 3D 产物通过面数、连通、流体和色板门禁。
- 导入过程不出现颜色映射、修复、简化或尺寸确认对话框。
- 自动摆盘后完成切片并进入 Preview，G-code 可导出。
- Python 回归、Windows Release 构建和 200% DPI GUI 验收通过。
