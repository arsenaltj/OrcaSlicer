# ImageMap 核心移植

用户于 2026-09-17 明确要求将 ImageMap 的核心思想移植到当前产品。此项取代此前下一步 C+ 离线去杂色实验；Windows 本地实现和验证，不发布、不打印。

固定来源：sentientstardust-dev/OrcaSlicer-ImageMap v1.0.44，提交 `235e94dbbde65b2d0750df9a7574c050f90739df`。保留 AGPL/GPL/MIT 来源说明。原工程与先前未提交工作均保留。

## 本轮交付

1. 原版 Generic Solver / PigmentPainter；连续 UV/顶点色保留到切片阶段。
2. 现有颜色匹配弹窗增加 ImageMap 连续色选择，使用准备页物理耗材，沿用事务取消/撤销。
3. 每个完整层轮换一种物理耗材；按纹理求得的分量可见度调整外壁宽度与挤出量。普通配色行为不变。
4. 模型携带纹理，3MF 保存/重开及撤销保留。切片变化能够正确失效重算。
5. 针对性算法、真实 FFF G-code、格式/事务回归；Windows 增量构建和受影响主窗口检查。

不包含上游顶部成像、标定 UI、任意渐变编辑。实物效果与四喷嘴/六材料设备映射仍未验证；不得把软件通过写成实物通过。

## 当前进度

- 已完成上述 Windows 纵向实现。当前入口为原生颜色匹配弹窗中的 **ImageMap 连续色（实验）**；不增加独立页面，不修改普通配色默认值。
- 保留源三角形角点 UV、贴图与顶点色；3MF 内嵌 `Metadata/ImageMap/*.bin`，使用原版 PigmentPainter / ClosestMix / OklabSoftCap4Dark4 求解器。每层只使用一个物理耗材，外壁可见度同时改变线宽、中心线与挤出量。
- 25 项 ImageMap / 模型导入 / 更新配色 / 配方撤销测试通过；14 项原有混色 FFF 回归通过。已实际验证两个原始 GLB 导入、取消、模型与自动配方同时撤销/重做、3MF 重开、真实切片及本地 G-code 导出。
- 写实样本 0.12 mm：833 层、832 次换色、六色轮换高度 0.72 mm；卡通样本 0.20 mm：500 层、499 次换色。两者均只有 T0–T5，外壁线宽 0.32–0.95 mm（0.4 mm 喷嘴）。没有针对模型身体部位的坐标规则。
- 实际 G-code 对照显示主样本的肤色、头发与白外套分布接近官方版本；正面仍有条纹、顶部仍会露出周期色。切片器版本与工艺配置不同，不将时间、重量差异单独归因于移植算法。
- 原生主样本首次切片的擦料塔位于板边，移动到板内后复核；原几何悬空/开放边保留记录。证据及当前输出见 `.tmp/dev/imagemap-port/validation.json`，可旋转对照见该记录中的 URL。

## 使用与边界

直接导入原始 GLB 或带贴图的 OBJ，在既有颜色匹配弹窗勾选 ImageMap 后导入，再切片查看耗材路径。准备页仍显示虚拟配方的代表色，不把原始贴图预览当作打印仿真。工作台既有的 GLB→顶点色 OBJ 路径仍按其采样颜色导入；要验证完整 UV 贴图，应使用上述原始文件入口。

这轮是原计划第 3 步的原生软件验证，并开始第 5 步的可选集成；不是默认替换，也未进入第 4 步实物验收。下一轮根据同条件视觉反馈处理工艺参数与顶部成像，再做耗材标定及硬件小样。仅两个不同模型，不能声称任意模型或任意材料均已验证。
