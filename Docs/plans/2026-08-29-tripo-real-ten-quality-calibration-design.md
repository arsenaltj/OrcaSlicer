# 10 次真实 Tripo 质量校准设计

## 目标与样本

本轮新增恰好 10 个真实 Tripo 图生 3D 任务，用当前 Image2 提示、图片门禁和两档 Tripo 策略验证端到端质量。每个输入只创建一个模型任务，不用失败重试或同对象抽卡补结果。冻结样本为：爱因斯坦半身雕塑、莎拉·伯恩哈特全身写实、虚构双人卡通组合、两只虎斑猫、开屏孔雀、复古显微镜、履带挖掘机、灯塔、盆景树、雨伞下的猫。

前八个高保真对象使用 `quality`（H3.1、100 万面、detailed geometry、detailed texture）；挖掘机和雨伞猫中的两例用于 `performance`（30 万面、standard geometry、standard texture）对照。P1 面向 2 万面以内低多边形，不替换当前收藏摆件质量档。

## 数据流与付费边界

公开或既有合法源图 → 当前版 Image2 单候选 → 严格色板/自然色模型参考图 → 本地 3D 输入门禁 → 哈希绑定的人工目检 → 一次性 Tripo 创建 → 只读轮询 → OBJ 转换与下载 → 顶点色/拓扑处理 → 结构门禁 → 五视图渲染与人工复核 → 汇总报告。

每个阶段在 `generated_models/tripo-real-10-wave1/` 保存状态。Image2 和 Tripo 在远端请求前先记录调用意图；已有调用记录但缺少产物时禁止自动重放。Tripo 任务 ID 返回后立即持久化；恢复只能轮询已保存 ID。转换不是新的模型生成，但同样保存远端任务 ID并只恢复原任务。

## 检查与优化原则

统一检查任务成功率、下载完整性、三角面/顶点数、边界边、非流形边、退化面、连通体、底面接触、包围盒比例、顶点色/贴图和五视图语义。人像额外检查恰好一个平底一体底座；半身不补腿，全身不改姿态，多人共用一个底座。非人物不得被人像规则误加展台。

只有在多例中重复出现、可通过固定测试复现的问题才进入正式策略。单例随机语义错误进入报告，不新增对象专属硬编码。修改不得改变 Provider Gateway、3MF/profile、端口或 Orca 原有功能边界。

## 验证

先为付费运行器补 `generation_profile` 冻结与恢复测试，再增加 10 例 manifest、调用计数、哈希批准、失败不重试和报告汇总测试。完成后运行定向测试、全部 `tools/ai/test_*.py`、Python 语法检查、`git diff --check`；若修改 C++ 再执行 Windows Release 构建。本轮预计只修改 Python/文档，不需要修改 C++。
