# 高精度 OBJ 颜色与分组设计

## 目标

将 AI 3D 生成从固定约 1.2 万面的低模模式改为可选的 10 万、30 万、50 万和 100 万面质量档位，默认 30 万面。同时撤销“生成结果必须是单一对象、单一连通体”的错误约束，保留 Tripo 输出中的对象、组、材质和纹理边界，避免强制合并导致颜色错误。

## 数据流

- GUI 在确认生成 3D 前选择目标面数，并随生成请求发送 `face_limit`。
- sidecar 只接受 100,000、300,000、500,000、1,000,000 四个档位，并将选择固化到任务状态和模型库元数据。
- Tripo 使用高质量几何、纹理和 UV；关闭 `smart_low_poly`。若供应商接口支持高质量模式下的面数目标，则传递所选 `face_limit`；否则以所选档位作为本地验收上限。
- 原始 OBJ 资源包完整保存在任务目录。自然色正常导入优先保留原始 `OBJ + MTL + 纹理`，同时生成自包含顶点色兼容 OBJ 供当前 Orca 导入。
- 顶点色兼容转换继续复用几何位置索引，避免 UV 接缝拆点后被切片器判为开放网格；但不再使用固定 216 色和离散多数投票。关闭可打印颜色时对该位置的纹理采样 RGB 做全精度平均，开启时才映射到耗材色板。原始 `OBJ + MTL + 纹理` 始终保留，可用于后续支持逐角颜色的导入器。
- 保留 `o`、`g` 以及材质派生的分组。允许多个连通部件，只对每个部件分别进行非流形/开放边检查与可控修复，不再以“必须单连通”拒绝整个模型。

## 导入与兼容

- 正常导入保留颜色和结构分组；多个部件保持原始相对位置，作为同一个生成资产进入 Orca。
- 单色导入仍是显式降级选项，只在用户选择时忽略颜色。
- 原有模型库记录继续可读；缺少质量字段时按旧模型处理，不改变历史文件。
- 不自动触发任何付费 Tripo 任务。

## 验收

- GUI 提供四档面数选择，默认 30 万面，并正确传入 sidecar。
- Tripo 请求不再启用低模模式，sidecar 可处理最多 100 万三角面。
- 输出顶点全部带 RGB，关闭色板时不经过固定 216 色量化；UV 接缝仍保持拓扑焊接，避免制造非流体边。
- 多对象、多组或多连通部件不会仅因数量大于一而失败；模型结构和颜色在正常导入中保留。
- Python 契约与 OBJ 回归通过，Windows Release 构建通过。
