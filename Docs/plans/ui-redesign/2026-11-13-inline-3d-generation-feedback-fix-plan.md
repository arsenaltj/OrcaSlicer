## 3. F1：隐藏智能输入页底部恢复按钮

### 3.1 展示修改

1. 仅在智能模式的Input空态中，不再把RestoreLatest配置为左栏底部次按钮；隐藏该按钮及专属间距，不保留空白按钮位置。
2. 原“生成3D模型”的文案、样式、尺寸、底部锚定、资格、禁用原因和点击命令沿用现有规则。所谓恢复旧UX仅指恢复原单主按钮布局，不回退整个智能页面。
3. 生成中停止、失败／停止后的恢复、中央恢复、服务重检、返回创作及完成双按钮保留。高级页面不受此显隐条件影响。
4. 已完成模型继续通过右侧历史进入原工作台；历史过滤、资产校验及未保存编辑保护不变。

### 3.2 隐藏按钮后的恢复保障

这是F1的必要兼容措施，不引入新的任务管理界面。

- 优先核对原未完成任务还原在新智能宿主中是否已可达；如果可达，直接复用，避免增加第二条还原链。
- 当前已发现旧Panel可见性门槛会阻断还原。必要修改仅把既有最近任务查询／还原接到“智能创作页面首次可见且服务就绪”的接缝；复用原Host接口、查询、可恢复资格和代次保护，不改变后端最近任务筛选、历史格式或任务重试策略。
- 查询只在无当前任务、不忙、无工作台切换且用户尚未建立新输入意图时进行，复用既有检查标记避免轮询式重复查询。异步返回时重新验证页面／输入／任务代次；用户已经编辑、发起新任务或切换上下文时丢弃旧返回，不能覆盖新输入或抢页。
- 本接入只接受原规则允许恢复的未完成智能任务；无任务、仅完成历史或高级任务时保持输入空态，由原历史入口查看完成模型。这里仅约束新宿主接入，不改其他显式历史打开行为。
- 还原任务身份、输入和已有状态后，沿既有中央／失败区入口显示适用的继续或恢复动作。停止／失败任务仍由用户显式恢复；已有远端任务可沿原轮询／下载规则取得状态和成果。
- 查询和还原不调用新建2D／3D任务，不自动推进新的付费阶段；不把“重新生成”当成恢复，不放宽结果不明确时的原保护。

若实现发现上述保障需要修改后端候选策略、持久化格式或新增恢复产品流程，超出本方案，记录原因后单独对齐；不扩大此次隐藏按钮的改动。

## 5. F3：高级3D提示统一中文

### 5.1 复用方式

1. 在现有`ModelGenerationStatusText`文案模块内复用智能已具备的状态／阶段／错误映射。为高级提供必要的薄适配或明确上下文，智能现有默认行为保持。
2. 只依据结构化state、phase、错误字段及本地加载阶段选择文案；不根据英文句子识别或改变业务状态，不向Python工作流反向写入中文UI文案。
3. 通用且语义相符的3D阶段复用既有文案；高级已确认四图、停止／恢复、本地拓扑校验等提示按真实能力处理，避免出现重新准备智能参考图、特定OBJ转换或人像／颜色检查等未实际执行的说明。
4. 优先在高级Workspace消费`host.model_state()`的现有位置，先按group／job／epoch核对身份，再对临时展示副本统一格式化status_text及失败摘要。顶部和中央视图使用同一投影／格式化函数，原Host快照、Session及后端message不被改写；不新增轮询、持久化或第二份业务状态。TaskFlow／Monitor的任务观察和本地获取生命周期无需为此重构。
5. 高级顶部状态和中央状态副文消费同一任务的文案结果；3D处理、停止及失败时，通用Host诊断不能重新覆盖为原始英文。保留原观察器已经提供的中文重连提示，避免用最后一次远端阶段掩盖重连；这只适配显示，不据英文句子推断业务状态。本地预览失败若由共用视图直接显示原异常，则仅对高级来源加中文说明兜底并保留诊断，不改智能异常展示。中央标题继续承担阶段标题，不要求标题与副文重复。
6. 原始后端message、错误码、Provider任务ID等诊断事实继续保留在原任务结构和既有诊断路径；用户说明使用中文。任务ID、文件名和Tripo等专有名称不要求翻译，不新增诊断面板。

### 5.2 文案规则

| 实际状态／阶段 | 中文显示规则 |
| --- | --- |
| 排队 | 复用“3D 生成任务已排队…”的现有通用提示 |
| 远端生成 | 复用适用的“AI 正在生成 3D 模型…”及原长等待说明；高级需要说明输入时使用已确认四视图语义 |
| 下载／本地解析 | 按实际本地阶段显示正在下载、校验或解析模型；不能仍显示远端生成副文 |
| 本地模型校验 | 使用与高级实际校验相符的中文，不套用智能人像、颜色清理等专用描述 |
| 停止中／已停止 | 中文说明停止事实，保留原输入、四图和已取得成果；不宣称远端请求已被撤销 |
| 重连／恢复 | 中文说明正在重连／恢复当前任务，不误导为创建新任务 |
| 失败、限流、连接失败、下载失败、结果不明确 | 复用语义适用的错误映射；按原可恢复资格显示建议，不提示不安全的重复提交 |
| 未知非终态／空消息 | 中文兜底“正在处理当前3D模型任务…”；不能误报成功或失败 |
| 未知失败 | 中文兜底“模型生成未完成，请保留任务信息并查看诊断记录。”；结果不明确时叠加原避免重复提交说明 |
| 已完成 | 沿原本地加载及有效首帧条件进入完成态，不以中文文案或远端ready替代完成条件 |

现有智能映射的未知状态／未知错误可能回退原始英文。本次只为高级受影响显示路径补齐中文兜底，不扩展为全软件国际化整理，也不批量修改智能其他提示。

## 6. F4：明确智能参考图准备提示

### 6.1 拟定文案

| 位置 | 拟定内容 |
| --- | --- |
| 中央准备阶段标题 | 正在准备建模参考图… |

### 6.2 保留的业务

纯文字仍先生成建模参考图；图片输入仍按原描述／风格准备或优化参考图；原质量、资格和校验通过后自动衔接3D。准备失败、停止或恢复后需要显式继续时，仍使用原对应状态和动作，不显示“将自动生成”误导用户。估时保持估算性质，不加固定等待、不改计时或进度算法。
