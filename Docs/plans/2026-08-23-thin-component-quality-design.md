# 阶段 67：薄型连通部件预检设计

日期：2026-08-23

## 目标

在不引入切片器壁厚算法的前提下，可靠识别“整个连通实体在一个方向上明显过薄”的生成模型，例如薄挂牌、薄叶片、独立装饰片和细杆状附件。

本阶段不声称识别附着在大型主体上的局部薄壁或细连接。那类问题需要空间索引和表面对射厚度采样，应在独立阶段实现。

## 方案选择

不采用以下代理信号：

- 三角边长：反映网格细分密度，不代表实体厚度。
- 轴对齐包围盒最小尺寸：模型旋转后结果会改变。
- 体积/表面积单一比例：不同形状的比例系数差异大，容易把小立方体误判为薄片。

采用每个连通组件的主轴投影尺寸：

1. 复用现有拓扑并查集，收集每个组件的唯一顶点。
2. 计算顶点协方差矩阵。
3. 用确定性的对称 3×3 Jacobi 迭代求最小特征值对应主轴。
4. 把组件全部顶点投影到该主轴，取最大值减最小值作为旋转不变的最薄尺寸代理。
5. 只有组件包围盒对角线至少 2 mm 且最薄投影小于 0.8 mm 时，计为薄型组件。

## 误报控制

- 只有全局无开放边、非流形边、绕序错误和退化面时启用厚度指标；否则报告 `component_thickness_available = false`。
- 对角线小于 2 mm 的微小组件继续交给已有 `tiny_detached_components`，不重复报薄。
- warning 只产生 `review`，不阻断导入、不自动加厚或删除几何。
- 该尺寸是“组件整体最薄方向”，不是局部壁厚，也不用于推导喷嘴或切片参数。

## 契约

- 报告 schema 保持 `1`，门禁版本提升为 `structural-v5`。
- 新 thresholds：`min_component_thickness_mm`、`min_thin_component_diagonal_mm`。
- 新 metrics：`component_thickness_available`、`thin_component_count`、`minimum_component_thickness_mm`。
- 新 warning：`thin_structural_components`。
- C++ 只读取可选字段并显示中文建议；旧报告继续按原路径显示。

## 边界

实现只修改模型生成质量模块、Sidecar/C++ 模型生成契约、模型生成 GUI 和测试。不修改 3MF、profile、打印参数、Orca 网格修复或智能切片逻辑，不调用任何 Provider。
