# AI 智能切片需求与方案基线

- 日期：2026-09-28
- 状态：需求与总体方案基线已冻结，可进入详细方案设计；参数初值和六喷头设备数据待样机验证
- 范围：Windows 内部开发版中的 Orca 主窗口智能切片体验
- 非范围：公共发布、网站、签名、部署和真实打印效果宣称

## 1. 文档目的

本文冻结当前已经明确的 AI 智能切片产品需求、架构方向、第一版边界和建议参数基线，作为后续设计、实现和验收的共同依据。

本文中的内容分为三类：

- **已确认需求**：用户已经明确选择的产品行为和支持范围。
- **已确定方案**：基于现有 Orca 和智能切片代码现状选定的实现方向。
- **待校准初值**：用于第一版候选搜索和安全限制的建议值，必须经过 WonderMaker 样机和实物打印调整，不能标记为最终打印结论。

六喷头设备/Profile 明细、固定测试模型和实物校准数据属于已知的外部输入，不再视为未完成的产品决策。详细方案可以先定义接口、数据契约和验证流程；没有这些真实输入时，不得宣称六喷头支持或打印质量已经验收通过。

## 2. 产品目标

普通用户不需要理解 Orca 大量切片参数。系统读取当前打印板的模型、设备、材料和颜色信息，直接提供三种可比较的智能切片方案：

1. **综合最优**：平衡外观质量、尺寸精度、结构强度、打印成功率、时间和耗材。
2. **速度优先**：在最低质量、强度和成功率门槛内缩短真实预计打印时间。需求原称“速度最优”，界面统一采用“速度优先”。
3. **质量优先**：优先提高表面表现、尺寸精度和结构强度，允许增加时间和材料。

每个方案必须经过 Orca 原生切片核心的隔离试切，向用户展示实际可取得的参数变化、预计时间、耗材、支撑、多色废料、换头次数和风险信息。用户明确选择后才应用到正式工程并开始原生切片。

专业用户继续使用完整的 Orca 原生切片功能，可以查看和自定义全部原生参数，包括支撑相关参数。AI 关闭、失败或不可用时不得改变普通 Orca 行为。

## 3. 已确认需求

| 主题 | 已确认决定 |
|---|---|
| 质量含义 | 质量由外观质量、尺寸精度和结构强度三者共同构成。 |
| 第一版设备 | WonderMaker 4 喷头和 6 喷头打印机；单喷头放到后续版本。实施和内部测试先交付 4 喷头候选，6 喷头保持接口与能力模型兼容；只有真实 Profile 和样机验证完成后才启用并宣称 6 喷头支持，第一版最终验收仍包含 4/6 喷头。 |
| 喷嘴 | 第一版限定 0.4 mm。 |
| 材料 | 第一版覆盖 PLA、PETG、TPU。 |
| 模型朝向 | AI 可以自动改变模型朝向。 |
| 多对象策略 | 整个打印板使用统一目标策略，不让不同对象分别选择“综合/速度/质量”；AI 可在该统一目标下分别优化各对象的朝向、支撑、接缝和变量层高。 |
| 用户用途 | 用户可选“装饰/通用/功能”用途，默认“通用”；用途作为候选约束和排序输入，不覆盖设备与材料安全边界。 |
| 支撑影响 | 支撑允许接触和改变普通可见表面；脸部属于重点保护区域。 |
| 脸部风险确认 | 所有可行方案都无法避开脸部支撑接触或接缝时，可以展示风险最小方案，但应用前必须由用户明确确认。 |
| 多色顺序 | AI 可以调整喷头、耗材和换头顺序，但必须保持颜色/材料意图并通过物理槽位校验。 |
| 参数自主权 | AI 可以自主控制普通全局切片工艺参数；用户明确建立的对象锁定、局部涂绘、修改器和对象级覆盖等人工意图属于硬约束。所有输出仍须经过参数策略、设备/材料边界、原生校验和隔离试切。 |
| 材料组合 | 第一版自动推荐只使用同一规范化材料家族，不自动推荐 PLA、PETG、TPU 跨材料混合打印；衍生材料和专用支撑料必须由兼容表明确放行。 |
| 速度门槛 | 推荐阶段按 Orca 隔离试切的预计时间判断，预计节省至少 10% 才提供速度优先方案，并明确标为预计值；最终实物验收要求实际打印时间至少缩短 10%。 |
| 应用失败语义 | 用户执行“应用并切片”后，如果方案已应用但正式切片失败，保留已应用的模型和配置，不自动回滚；界面显示失败原因并提供重试和一次 Undo 恢复，未成功进入 Preview 前不得去打印。 |
| 尺寸关键特征 | 第一版普通用户流程不新增尺寸关键特征标记控件；没有工程元数据或固定测试清单中的明确声明时，只评价通用尺寸风险，不宣称尺寸精度得到改善。 |
| 处理范围 | 每次只分析和优化当前打印板，不自动跨打印板或跨工程优化。 |
| 工程持久化 | 未应用候选只存在于当前智能切片运行态，不写入 3MF；应用后的原生配置和模型变化按 Orca 现有工程规则保存。 |
| 数据与隐私 | 第一版模型分析、候选生成和试切全部在本机完成，不上传模型网格或工程内容。 |
| 性能目标 | 普通模型在 2 分钟内返回第一张可用方案卡；采用渐进式返回，整次推荐硬超时 10 分钟。 |
| 六喷头定义 | 六喷头是六个可独立寻址的实体喷嘴；具体偏移、可达范围、换头和冲刷等设备数据后续提供并验证。 |
| UX 对接 | 最终能力必须接入后续开发的 UX 中“综合最优”“速度优先”“质量优先”三个固定选项；当前 UX 尚未开发，智能切片内核先提供稳定、与控件无关的接口和结果模型。 |
| 原生模式 | 保留 Orca 原生切片和完整专业参数入口。模型导入不得自动改变预设或自动开始切片。 |
| 验收数据 | 当前没有固定模型和真实打印基准；先建立候选和校准集，再按实际打印结果调整。 |

### 3.1 参数自主权的工程解释

“AI 可以自主控制所有切片参数”不等于允许模型改写硬件事实或未经验证的校准值。参数分为三层：

1. **AI 可自主控制的工艺策略**：朝向、层高、墙、顶底层、填充、工艺速度、工艺加速度、支撑、裙边、接缝、路径、换头顺序等。
2. **受校准范围约束的参数**：线宽、支撑间距、冷却、回抽、冲刷量、擦料塔等。AI 只能在设备/材料已验证范围内选择。
3. **不可当作推荐策略改写的事实**：喷嘴直径、打印空间、喷头偏移、机器运动极限、材料温度范围、最大体积流量、流量系数、Pressure Advance 等硬件或材料校准值。

AI 的任何建议都不能绕过 Orca 原生配置校验、模型校验、设备兼容性和真实试切结果。

参数所有权还必须区分人工意图和普通全局基线：

- 用户明确建立的对象位置/朝向锁定、手绘支撑、手绘接缝、修改器、层高范围和对象级参数覆盖属于硬约束。候选生成不得静默删除、迁移或覆盖这些设置；只有用户另行明确移除或替换对应约束后，AI 才能改变受约束部分。
- 当前工艺 Profile 中的普通全局参数是推荐基线，不因用户当前选中了该 Profile 就自动成为硬约束。AI 可以在已确认的参数权限和安全范围内优化这些值，但必须展示旧值、新值、原因和代价。
- 无法同时满足人工意图、安全边界和目标收益时，该目标返回不可用或冲突说明，不得通过弱化人工意图来凑出候选。

## 4. 架构决策

采用“**保留现有安全工作流和 Orca 适配，重建智能决策内核**”的 V2 路线，不全部推倒重写，也不继续在现有候选函数中无限堆叠规则。

### 4.1 保留的现有能力

- `SmartSlicingCoordinator` 的工作流状态、取消、失败和工作区版本失效机制。
- `WorkspaceRevision` 对候选、试切结果和正式工程版本的绑定。
- `OrcaTrialSliceExecutor` 基于模型和配置副本的隔离试切。
- `OrcaOfficialSliceGateway`、原生正式切片、Preview 导航和结果通知。
- `Plater::TakeSnapshot` 事务、正式工程失效处理和 Undo 恢复。
- 参数类型、范围、所有权、目标和禁改项校验框架。
- 多色物理槽位、颜色映射、冲刷、擦料塔和换头指标采集。
- Presenter/ViewModel 单向展示方式及现有安全、取消、恢复和事务测试。

这些代码虽然不是 Orca 上游原生功能，但实际切片仍调用 Orca 的 `Model`、`DynamicPrintConfig`、`Print::validate/process/export_gcode`、Arrange、Plater 和 Preview，不是第二套切片器。

### 4.2 重建的决策能力

- 结构化模型特征分析：尺寸、底面积、高宽比、曲率、薄壁、桥接、悬垂、封闭性、朝向敏感面、支撑接触风险和多色复杂度。
- 脸部和其他重点保护区域的结构化表示。
- 综合最优、速度优先、质量优先三套目标契约和硬约束。
- 朝向、支撑、层高、墙/顶底层、填充、速度、附着、接缝和多色顺序候选生成器。
- 参数策略注册表，用风险等级和当前 Profile 边界替代现有少量手写白名单。
- 真正的质量风险评价，替换“支撑体积越少等于质量越好”的临时代理。
- 原生基线加三个 AI 方案的稳定结果模型；决策内核不依赖最终 UX 控件、布局或中文显示文案。

### 4.3 目标数据流

```text
Orca 当前工程
  -> 工作区快照与版本
  -> 用户用途（装饰/通用/功能，默认通用）
  -> 模型/重点区域特征分析
  -> 板级统一目标下的逐对象朝向/支撑/接缝/变量层高候选生成
  -> 参数策略与设备/材料安全校验
  -> Orca 隔离试切
  -> 原生指标 + 质量/强度/尺寸风险评价
  -> 原生基线与三个 AI 方案比较
  -> 用户选择
  -> 单次原生 Undo 事务应用
  -> Orca 正式切片与 Preview
```

### 4.4 运行态与数据边界

- 智能切片只读取当前打印板的快照，不自动优化其他打印板、其他工程或历史项目。
- 特征分析、候选生成、隔离试切和比较均在本机完成；第一版不引入模型网格、3MF 或工程内容上传接口。
- 原生基线、三个 AI 候选、解释信息和未应用的试切缓存属于可丢弃运行态，不写入 3MF。
- 用户应用方案后，只有已应用的模型朝向和原生配置进入正式工程，并沿用 Orca 的保存、恢复和 Undo 语义。
- 运行日志只记录诊断所需的结构化指标和错误，不记录完整模型几何；后续若增加云端能力，必须另立需求、隐私和授权评审，不能默认为本基线的一部分。

## 5. 用户流程与界面

智能切片位于 Orca 主窗口打印准备流程内。目标界面包含：

- `AI 智能切片` 与 `Orca 原生` 两个清晰入口。
- 提供“装饰/通用/功能”用途选择，默认选中“通用”；用户不需要填写更多专业参数即可开始推荐。
- 原生基线单独展示，不占用三个 AI 方案名额。
- 三张固定目标卡：综合最优、速度优先、质量优先。
- 每张卡展示层高、墙、填充、速度、支撑、预计时间、总耗材、换头和主要风险。
- 参数详情展示相对当前原生配置的旧值、新值和修改原因。
- 明确显示“为什么推荐、改善了什么、牺牲了什么”。
- `应用并切片` 与后续 `去打印` 分离。只有正式切片和 Preview 成功后才能进入打印动作。
- 应用成功后保留明确的“撤销本次应用”；后续工程已经变化时使用 Orca 原生 Undo 并解释原因。
- 方案已经事务式应用但正式切片失败时，保留已应用的模型朝向和配置以及对应 Undo 快照，不自动回滚。界面必须显示失败原因，并允许用户重试正式切片或执行一次 Undo 完整恢复本次应用；失败状态不得进入 Preview 成功态或启用“去打印”。
- 当脸部支撑接触或接缝风险无法消除时，卡片必须标出风险区域；用户展开风险并明确确认后才能应用。

试切结果出来之前不得把时间、耗材或质量写成确定结果。没有安全或有意义的某一档候选时，应明确显示“当前模型没有明显更优的该类方案”，不能为了凑齐三张卡提交退化配置。

### 5.1 渐进式结果与超时

- 在约定的 Windows 内部测试硬件和普通模型集上，从用户启动推荐到第一张通过硬门槛、可查看并可应用的 AI 方案卡出现，目标不超过 2 分钟。
- 三张卡独立完成后立即展示，不等待全部目标完成；后到方案不得引起已展示卡片的参数内容静默变化。
- 单次推荐总硬超时为 10 分钟。超时后取消剩余分析和试切，保留已经完成且仍与当前工作区版本一致的方案，并明确标出未完成目标。
- 用户取消、切换工程、改变模型或配置时，应尽快终止后台工作；过期结果不得重新写回界面或正式工程。
- “普通模型”的固定模型、面数/对象数/颜色数范围、测试机器和计时起止点在详细设计的性能测试规范中冻结；在该规范冻结前，2 分钟目标只能作为设计预算，不能作为已通过结论。

### 5.2 后续 UX 对接契约

当前 UX 尚未开发。需求截图用于说明未来产品意图：在 Orca 主窗口相关侧栏提供 `AI 智能切片` 与 `Orca 原生` 入口，AI 模式下显示“综合最优”“速度优先”“质量优先”三个选项、当前选项的关键参数和预计结果，并保留“开始切片”到“去打印”的两阶段动作。截图不是现有实现完成或最终视觉稿的验收证据。

智能切片实现必须先形成与具体控件无关的应用层接口和 ViewModel。后续 UX 只能通过该接口发起分析、选择方案、应用并切片、取消和撤销，不能直接调用候选生成器、修改正式工程或根据中文文案推断策略。三个选项使用稳定语义标识进行绑定：

| 稳定标识 | 中文显示 | 含义 |
|---|---|---|
| `balanced` | 综合最优 | 平衡质量、可靠性、时间和材料。 |
| `speed` | 速度优先 | 在全部硬门槛内优先缩短时间。 |
| `quality` | 质量优先 | 优先外观、尺寸精度和结构强度。 |

显示文案由 UX/本地化层维护；内部枚举名称即使调整，也必须通过单一映射层保持上述标识兼容。每个方案结果至少向 UX 提供：

- `goal_id`、`candidate_id`、`workspace_revision` 和结果状态。
- 层高、墙数、填充率、速度摘要、支撑策略等主要参数。
- 预计时间、总材料、换头/废料等原生试切指标。
- 相对原生基线的变化、推荐原因、收益、代价和风险。
- 脸部等重点区域风险以及是否需要用户显式确认。
- `analyzing`、`ready`、`unavailable`、`failed`、`stale` 和 `applied` 等可展示状态。
- 当前允许的动作，例如选择、查看详情、应用并切片、取消、撤销和切换到 Orca 原生模式。

接口必须支持三个方案独立、渐进式到达，以及工作区修订变化后的结果失效。后续 UX 接入不得要求重新实现推荐规则，也不得把试切前的占位数值当成真实结果。详细设计阶段应冻结请求/响应对象、状态转换、错误码、取消语义、线程回调方式和版本兼容策略，并为三种 `goal_id` 到目标契约的映射建立无需最终 UX 即可运行的契约测试。

## 6. 三档策略与初始参数

以下参数是第一版搜索中心和门槛，不是写死的三份 Profile。候选应从当前 WonderMaker 有效设备、工艺和材料 Profile 派生，并根据模型分析结果调整。

| 项目 | 综合最优 | 速度优先 | 质量优先 |
|---|---:|---:|---:|
| 推荐基础工艺 | 0.20 mm Standard | 0.24 mm Draft | 0.12 mm Fine |
| 可选层高 | 0.16-0.20 mm | 0.24 mm；低细节模型可到 0.28 mm | 0.12 mm；大模型或预算受限时 0.16 mm |
| 墙数 | 默认 3 | 最少 2 | 默认 3 |
| 普通填充 | 15% | 未知用途保持 15%；确认非承力装饰件后可用 10-12% | 默认 15%；结构模型可提高到 20% |
| 顶面有效厚度 | 不低于 0.8 mm | 不低于 0.8 mm | 不低于 1.0 mm |
| 底面有效厚度 | 不低于 0.6 mm | 不低于 0.6 mm | 不低于 0.8 mm |
| 支撑接口层 | 2-3 | 最少 2 | 3-4 |
| 朝向目标 | 平衡稳定、支撑、时间和重点表面 | 减少层数、支撑和换头，服从质量硬门槛 | 保护关键曲面、脸部和尺寸特征 |
| 接缝 | 避开正面和脸部 | 必须避开脸部，普通区域可放宽 | 隐藏到背面或低可见区域 |

WonderMaker 当前已提供 0.12、0.16、0.20、0.24 和 0.28 mm 的 0.4 mm 工艺基线，第一版优先选择和组合这些已验证工艺，而不是让模型凭空发明全部绝对值。

### 6.1 综合最优资源边界

- 相对当前原生基线，默认打印时间最多增加 15%。
- 包含模型、支撑、冲刷和擦料塔的总材料最多增加 10%。
- 当脸部或关键曲面的风险获得显著改善时，可放宽到时间增加 25%、材料增加 15%，但界面必须解释原因。
- 新候选不得新增原生校验错误、材料不兼容、物理槽位错误或颜色映射退化。
- 没有可解释的质量、强度、尺寸或可靠性收益时，不得仅凭内部评分推荐更慢或更费料的方案。

综合策略内部初始侧重为：质量 45%、打印可靠性 25%、时间 20%、材料及多色废料 10%。先执行硬门槛和 Pareto 淘汰，再用权重处理近似候选；用户界面不显示不透明的单一“AI 总分”。

### 6.2 速度优先最低门槛

- 推荐阶段以 Orca 隔离试切得到的预计时间为在线判定依据；相对原生基线预计至少节省 10%，否则不宣称存在有意义的速度方案。卡片和详情必须明确使用“预计”表述，不能把该门槛写成实际打印收益。
- 不新增原生错误，不明显提高打印失败风险。
- 未知用途模型至少保留 2 道墙和 15% 填充。
- 只有确认属于非承力装饰件后，填充才允许降至 10-12%。
- 0.4 mm 喷嘴的层高不得超过 WonderMaker Profile 的 0.28 mm。
- 存在小字、五官、陡斜面、薄壁或关键曲面时不得使用 0.28 mm。
- 不删除必要支撑，不允许把支撑接触转移到脸部来换取速度。
- 不提高材料 Profile 的最大体积流量、温度或机器运动极限。

### 6.3 质量优先边界

- 同时评价外观、尺寸精度和结构强度，不以层高或支撑量单独代表质量。
- 初始时间上限为原生基线的 2 倍，总材料上限为原生基线增加 20%；超过时不作为默认推荐，但可在详情中作为高成本候选说明。
- 优先保留薄壁、小孔、小字、五官、顶面覆盖和桥接质量。
- 重点表面支撑接触、接缝和粗层纹属于高惩罚项。
- 可以使用 Orca 的变量层高能力，但多头打印与擦料塔兼容性必须先通过原生验证。

## 7. 脸部重点保护

脸部保护不等同于禁止所有可见表面变化。默认策略为：

1. 优先寻找不让支撑接触脸部的朝向。
2. 接缝不得落在眼、鼻、嘴和主要正面轮廓。
3. 脸部优先使用质量档层高或变量层高。
4. 所有可行朝向都无法避开脸部支撑接触或接缝时，只能选择风险最小的候选，明确标记高风险区域，并要求用户在应用前显式确认。
5. 模型生成链路优先复用已有语义脸部区域。
6. 普通导入模型无法可靠识别人脸时，提供简单的重点保护面标记入口；系统不得伪称已经识别。

后续可以把重点保护机制扩展到文字、徽标、配合面和尺寸关键面，但不阻塞第一版脸部保护。

## 8. WonderMaker 设备与材料边界

### 8.1 当前事实

- 仓库已有 WonderMaker ZR Ultra / ZR Ultra S 的 4 个 0.4 mm 喷头配置。
- 当前没有完整的 6 喷头 WonderMaker 设备 Profile。
- 当前已有 WonderMaker PLA Basic、PETG Basic 和 TPU 95A 材料 Profile。
- PLA Basic 当前最大体积流量为 21 mm3/s，PETG Basic 为 8 mm3/s；AI 不得自行提高这些校准上限。
- TPU 的真实高速能力仍需 WonderMaker 样机验证。第一版 TPU 速度方案只通过层高、朝向、支撑和路径取得收益，不主动提高流量或设备速度。

### 8.2 六喷头前置输入

六喷头机型已经确认为六个可独立寻址的实体喷嘴。以下设备数据由 WonderMaker 后续提供；在宣称支持 6 喷头前必须全部进入正式 Profile 并完成验证：

- 六个喷头的直径、物理编号和偏移。
- 可打印区域、各喷头可达区域和碰撞/净空限制。
- 换头 G-code、换头耗时、预热/待机和回抽行为。
- 六槽材料映射、颜色映射和故障处理。
- 擦料塔/预充结构、冲刷量和空间约束。
- 4 头与 6 头工程/Profile 的保存、恢复和兼容行为。

### 8.3 材料组合

第一版自动推荐以同一规范化材料家族多色打印为默认支持路径。当前打印板实际使用的全部物理槽位必须能归一到同一个受支持家族：全部为 PLA、全部为 PETG，或全部为 TPU；同一家族的不同颜色可以参与推荐。材料家族由受版本控制的兼容注册表根据有效 Filament Profile 判定，不能依赖显示名称或自由文本猜测。

PLA-CF 等增强/复合衍生材料、专用支撑料以及其他具有不同温度、磨蚀、粘接或冲刷特性的材料默认不视为已支持的同家族组合，只有兼容注册表在取得设备和材料证据后明确放行才可参与自动推荐。PLA/PETG/TPU 跨材料混合打印在温度范围、层间结合、支撑可拆除性和冲刷数据没有实物证据前，不作为自动推荐能力。当前打印板已经混用不同材料家族或包含未放行材料时，V1 不生成 AI 推荐，明确说明限制并保留 Orca 原生模式；用户在原生模式手动配置时仍遵循 Orca 自身能力和警告。

## 9. 候选评价指标

每个候选至少记录：

- 原生校验错误和警告。
- 预计打印时间。
- 模型、支撑、冲刷和擦料塔材料体积。
- 换头次数、层级工具序列和物理槽位兼容性。
- 颜色映射是否退化。
- 悬垂、桥接、薄壁、小特征和床面附着风险。
- 脸部及重点区域的支撑接触、接缝和层纹风险。
- 顶底有效厚度、墙厚和填充形成的结构风险。
- 尺寸关键特征风险。第一版仅接受工程已有的明确元数据或固定测试清单对孔径、配合面等特征的声明，不新增普通用户标记控件；没有明确关键特征时只记录通用尺寸风险，不得伪造精度改善结论。

正式推荐先经过硬门槛，再进行目标内比较。不能把缺失指标当成零成本或自动通过。

## 10. 第一版实现边界

第一版不要求训练新的切片大模型。优先使用：

- 几何和语义特征分析。
- 设备、工艺和材料 Profile。
- 可解释的安全规则与候选模板。
- 小规模参数搜索。
- Orca 真实隔离试切和确定性评价。

后续积累足够真实打印反馈后，可以加入学习排序模型，用于调整候选权重和选择；学习模型仍不能绕过安全策略和原生试切直接写入工程。

第一版暂不包含：

- 单喷头智能方案。
- 未验证的 PLA/PETG/TPU 混合材料自动推荐。
- 自动改写设备固件、运动极限或耗材校准。
- 把切片成功宣称为实物质量通过。
- 没有可靠语义或用户标记时伪造脸部保护结果。

## 11. 校准与验收基线

当前没有足以证明“最优”的实际打印数据。因此第一版界面使用“推荐方案”，不能宣称全局最优或已证明打印质量最佳。

最低固定模型集建议包含：

1. 人脸或胸像。
2. 有复杂曲面的手办。
3. 普通装饰物品。
4. 功能/承力件。
5. 薄壁和小孔模型。
6. 细高、床面附着敏感模型。
7. 桥接和悬垂压力模型。
8. 4/6 色频繁换头压力模型。

### 11.1 在线模型获取方案

本地当前没有上述八类完整固定模型。模型集在后续 AI 智能切片开发实施过程中从互联网筛选和下载，本轮只确定获取与管理方案，不立即下载。

可从 Printables、Thingiverse、MakerWorld、Thangs、NIH 3D、Smithsonian Open Access 等公开来源查找候选，但必须逐个核验模型页面和随附文件中的许可证，不能根据网站名称推断授权范围。“免费下载”不等于允许修改、商业开发或再分发。

模型准入规则：

- 优先选择 `CC0`、`CC BY` 或其他明确允许修改、测试和商业使用的许可证。
- 不纳入许可证不明、仅限个人使用或来源无法追溯的模型。
- `NC`、`ND` 等受限许可证默认不进入可修改、可随内部构建分发的固定测试集；确有测试价值时只能作为单独的只读外部资产候选，并记录限制。
- 人脸和胸像优先采用公共领域雕塑、明确授权的虚构人物或其他不存在隐私/肖像权疑问的资产，不使用来源不明的真人扫描。
- 不把网站账号、访问令牌、作者私有附件或其他无关内容保存到仓库和测试记录。
- 资产下架或下载地址失效时保留既有来源、许可证和哈希证据，不使用同名但内容不同的文件静默替换。

八类模型的筛选目标：

| 类别 | 选择重点 |
|---|---|
| 人脸/胸像 | 五官清楚、正侧面曲率丰富，可检查脸部支撑、接缝和层纹。 |
| 曲面手办 | 有复杂衣褶、曲面和局部细节，能区分朝向与层高策略。 |
| 普通装饰物 | 花瓶、动物或摆件等常见普通用户模型。 |
| 功能/承力件 | 支架、卡扣、螺纹或配合结构，可检查强度与尺寸。 |
| 薄壁和小孔 | 包含不同壁厚、孔径和小字的公差测试模型。 |
| 细高模型 | 窄底、高重心或长柱结构，可检查附着和稳定性。 |
| 桥接和悬垂 | 有分级桥接、悬垂角度和支撑需求的标准压力模型。 |
| 多色换头 | 具有明确 4 色/6 色分区和频繁换头层序，可检查颜色映射、换头和废料。 |

每个候选下载后先进行只读登记和适用性检查，再决定是否进入固定集。至少核对：文件格式、单位、实际尺寸、对象/部件数、网格闭合性、退化面、颜色/纹理、是否已带支撑、是否适合 0.4 mm 喷嘴，以及是否真正覆盖对应测试目标。网页缩略图不能代替模型检查。

### 11.2 资产冻结与可追溯性

为每个资产维护结构化清单，至少包含：

```text
asset_id
category
source_url
source_page_title
author
license
license_url
downloaded_at
original_filename
original_sha256
normalized_filename
normalized_sha256
units
expected_size_mm
color_count
known_mesh_issues
allowed_uses
normalization_steps
```

保存原始下载文件且不覆盖。单位修正、缩放、拆分、网格修复、颜色整理和用于固定测试的版本另存为规范化副本，并记录每一步变换和新哈希。固定测试只引用 `asset_id + SHA-256`，防止同名文件或网站更新导致基线漂移。

初期资产放在忽略目录或专用外部测试资产目录，不自动提交大型二进制模型。只有许可证允许、文件规模合理且自动测试确实需要时，才随源码提交；同时保留许可证文本和署名。不能提交或分发的资产只保存清单、下载说明和本地哈希，不进入内部安装包或便携包。

下载动作属于后续开发实施步骤。实施时应先形成候选清单，再按每类至少一个主模型、必要时一个反例模型的原则下载，避免无目标地批量收集资产。

第一阶段安排约 18-24 次代表性实物打印即可建立参数初值，不必一开始穷举设备、材料、模型和三档策略的全部组合。每次分别记录：

- 源模型、朝向、设备/Profile、材料和完整参数快照。
- 三档候选与原生基线的试切指标。
- 切片是否成功、打印是否完成和失败位置。
- 表面、尺寸、强度、脸部、支撑接触和多色结果。
- 实际打印时间、材料和换头问题。
- 调整结论及适用范围。

代码测试通过、切片成功、屏幕预览合格和实物打印合格分别评价，不能相互替代。

### 11.3 第一版量化验收门槛

以下门槛已经确认为第一版初始验收线。自动化验收、真实主窗口验收和实物打印验收分别记录，不能用其中一类代替另一类：

| 类别 | 初始门槛 |
|---|---|
| 正式工程隔离 | 用户点击应用前，正式工作区的模型、配置和工程修订不得发生变化。 |
| 撤销 | 一次 Orca Undo 可以完整恢复一次 AI 方案应用引入的模型朝向和配置变化。 |
| 速度收益 | 在线推荐以隔离试切的预计时间至少缩短 10% 为出卡门槛，并始终标为预计值；在同一模型、设备、材料和基线条件下，最终实物验收还要求实际打印时间至少缩短 10%，未达到时不得宣称速度方案已通过实物收益验收。 |
| 时间估计 | 预计时间相对实际打印时间的绝对误差不超过 15%。 |
| 材料估计 | 预计总材料相对实际总材料的绝对误差不超过 10%，总材料包含模型、支撑、冲刷和擦料塔。 |
| 尺寸精度 | 对工程元数据或固定测试清单已声明的尺寸关键特征，绝对误差不超过 `max(0.2 mm, 标称尺寸的 0.5%)`；无明确声明的普通模型不适用该量化项，也不得宣称尺寸精度得到改善。 |
| 外观质量 | 按冻结的缺陷类型、拍摄条件和评分方法，所有最终推荐的 AI 方案表面缺陷不得劣于原生基线。 |
| 结构强度 | 使用同材料、同方向和同批次标准试样时，所有最终推荐的 AI 方案强度指标不得低于原生基线的 95%。 |
| 多色/多喷头 | 颜色映射退化、错误喷头使用和已知碰撞均为 0；任一发生即为失败。 |

性能方面同时采用第 5.1 节的“第一张卡 2 分钟、总硬超时 10 分钟”门槛。外观缺陷评分方法、强度试样类型、尺寸测量工具、实际耗材称量方法和测试硬件必须在详细测试方案中冻结，不能在结果出来后修改口径。

## 12. 现有实现差距

后续实现需明确处理以下差距：

- 当前工作流始终以 `Stability` 目标运行，没有三档独立目标。
- 当前最多比较三个候选，且原生基线占一个名额；目标需要一个原生基线加三个 AI 方案。
- 当前候选主要是原生 XY 自动摆放和细高/小底面增加裙边。
- 当前质量目标用支撑体积作为主排序依据，不能代表外观、尺寸和强度。
- 当前参数安全列表只有少量打印板级参数，不能覆盖新的策略范围。
- `IParameterAdvisor` 尚未实际接入候选生成。
- 当前工作区快照缺少薄壁、悬垂、桥接、曲率和重点区域特征。
- 当前 WonderMaker Profile 只完整描述 4 喷头机型，6 喷头契约缺失。
- 现有多材料兼容证据不足以支持 PLA/PETG/TPU 任意混合自动推荐。
- 最终 UX 尚未开发；现有 `SmartSlicingPanel` 不能被当作目标 UX，应用层仍需形成可供未来三个固定选项直接绑定的稳定接口和 ViewModel 契约。

## 13. 详细设计与实施顺序

1. 输出详细架构、领域模型、UX 对接接口、ViewModel、状态机、线程/取消、持久化和测试设计；同时冻结性能测试口径。
2. 冻结 4 喷头设备/Profile 契约，定义可扩展到 6 个独立喷头的能力模型；先形成可供内部测试的 4 喷头候选，并行收集第 8.2 节六喷头真实输入。6 喷头能力在正式 Profile 和样机验证完成前保持禁用，不对外宣称支持。
3. 定义模型特征、脸部保护区域、用户用途和三目标契约。
4. 建立参数策略注册表、风险分层、候选预算和硬门槛。
5. 实现三目标候选生成、逐对象局部优化和质量/强度/尺寸风险评价。
6. 在不依赖最终 UX 的条件下完成 `balanced`、`speed`、`quality` 契约测试、渐进式结果和应用/撤销闭环。
7. UX 开发完成后，通过第 5.2 节接口接入三个 AI 选项及 Orca 原生入口；不得在 UX 层复制推荐和安全规则。
8. 按第 11 节筛选、下载并冻结固定模型集，再完成自动测试、真实主窗口试切和 18-24 次初始打印校准。
9. 补齐六喷头 Profile 后启用 6 喷头能力，完成 4/6 喷头专项回归和实物验收；第一版只有在两类设备的最终验收均完成后才关闭设备范围验收项。根据证据调整阈值，再决定是否引入学习排序模型。

## 14. 详细方案设计就绪结论

本需求与总体方案基线已经足以启动详细方案设计。三档目标、用户流程、AI 与原生模式边界、板级与对象级策略、参数权限、隐私与持久化、性能预算、材料范围、未来 UX 对接契约和初始验收线均已明确，不再需要为这些问题等待新的产品选择。最终 UX 尚未开发不是智能切片内核设计的阻塞项；接口稳定后，未来 UX 应直接绑定三个固定目标及其结果状态。

仍需在设计或实施阶段补齐的内容均属于工程输入或校准证据：

- 六喷头设备/Profile 的真实偏移、可达范围、碰撞、换头、冲刷和材料映射数据。
- 性能验收机器、“普通模型”范围和完整计时口径。
- 八类固定模型的来源、许可证、原始/规范化文件和 SHA-256。
- 外观评分、强度试样、尺寸测量和材料称量的详细测试规程。
- WonderMaker 样机上的 18-24 次初始实物打印数据，以及由此产生的参数和阈值微调。

上述输入不阻塞架构、接口、状态机、UI 信息结构和 4 喷头候选引擎的详细设计，也不阻塞先交付 4 喷头内部测试候选；但缺少对应证据时，6 喷头能力必须保持禁用，且不能关闭第一版的六喷头、性能或实物质量验收项。
