# 阶段 76：最终模型目标色覆盖度设计

日期：2026-08-23

## 目标

把阶段 64 在 Image2 预览端已有的“显著主体色”概念延伸到最终 OBJ，量化 Image2→Tripo→顶点色量化后目标四色是否仍形成有意义的模型表面区域。

## 算法

1. `analyze_printable_obj` 接受可选目标调色板；没有调色板时保持原结构检查行为。
2. 对每个三角面计算面积，再按三个顶点颜色的出现次数把该面面积分配到目标色；所有颜色的分配面积之和等于模型表面积。
3. 每个目标色输出表面积和表面积占比，顺序与用户确认的调色板一致。
4. 沿用预览端语义：占模型表面积至少 2% 视为显著目标色；所需显著色数为 `min(目标色数, 3)`。
5. 显著色不足只产生 `too_few_meaningful_target_palette_colors` 复核警告，不拒绝制品、不强迫四种颜色全部使用。
6. 目标调色板外颜色只计入覆盖率，不在此阶段修改或重新量化模型；正常生成链路仍由既有精确调色板校验保证覆盖率为 100%。

## 报告与 GUI

- 质量门版本升级为 `structural-v9`，schema 保持 `1`。
- thresholds 新增 `meaningful_target_palette_surface_ratio=0.02`。
- metrics 新增目标色数量、已使用数量、显著数量、所需显著数量、覆盖率和多样性状态。
- evidence 新增最多四项 `target_palette_surface_usage`，包含十六进制颜色、面积、比例和显著状态。
- GUI 的展开指标显示“最终模型目标色：显著 N/M · 覆盖 X%”及逐色占比，并为新警告提供中文解释。

## 生命周期与兼容性

- 首次 Tripo 制品分析和手动“重新检查”都传入任务已确认的调色板。
- 历史任务没有调色板时不输出新指标；旧 v8 报告继续安全解析。
- 不修改 Provider 请求、付费调用、OBJ/3MF/profile 格式或 Orca 默认行为。
