# 阶段 66：接地面积与局部悬垂预检验收

日期：2026-08-23

## 结论

阶段 66 已在模型生成结构门禁中补充实际接地投影面积和局部悬垂区域分析。新规则解决了“接地点跨度很大但只有少量针脚”和“整体向下面比例不高但局部存在明显平台底面”两类盲区；两者只产生 `review`，不会拒绝导入、修改模型或自动生成支撑。

报告 schema 保持 `1`，门禁版本由 `structural-v3` 提升为 `structural-v4`。旧报告缺少新 metrics 时，C++ 客户端继续使用原来的接地覆盖显示，不把缺失值误报为 0%；重新检查后才显示接地跨度、实际接地面积和显著局部悬垂数量。

## 实现与阈值

- `min_contact_area_ratio = 0.002`：接地带内、法向朝下三角面的 XY 投影面积，占模型 XY 包围盒面积的比例。
- `min_overhang_region_area_mm2 = 4.0`。
- `min_overhang_region_area_ratio = 0.0005`。
- 局部悬垂复用现有 45° 向下法向、面面积和面邻接；排除接地带后按连通域统计。
- 整体 `high_downward_surface_ratio` 已触发时不重复增加 `localized_overhang_regions`。
- 新 metrics 包括接地面积、接地面积占比、悬垂区域数量、显著区域数量、最大区域面积占比和最低离床间隙。

本阶段没有用短三角边估算壁厚。细分密度不代表实体厚度，薄壁检测留给后续保守厚度采样，避免制造大量误报。

## 真实模型复核

对三个近期 282k–297k 面模型和阶段 45 的 478k 面人像、467k 面机器人进行离线重算：

- 全部保持非 `reject`，没有新增硬阻断。
- 实际接地面积占比为 4.9%–77.2%。
- 每个模型识别出 7–25 个达到阈值的局部悬垂区域。
- 两个阶段 45 基准的最大局部悬垂区域分别占总表面积 1.11% 和 0.34%，说明信号不是由单个微小三角面触发。
