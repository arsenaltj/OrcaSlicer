# 方飞总多色写实肖像专项设计

## 问题定义

上一轮自然写实路线在二维预览和三维结果中都把真人特征逐步泛化。更严重的是，Tripo 对交叉手臂遮挡面的补全把白色袖管误生成为裸露肘部；四色最近邻映射随后把这片错误固化为大面积肤色。单色雕塑路线在同一姿态下保留了更清楚的脸部实体起伏和连续袖管，因此本轮不再把“照片感”当成写实质量，而把可识别的三维几何和正确的语义材质边界作为写实质量。

## 方案比较

### A. 单图照片写实继续加强提示

优点是调用链最短。缺点是脸部身份依赖二维纹理和柔和明暗，进入三维后容易被通用化；交叉手臂背面仍由单图模型猜测，无法从输入上证明袖管连续。上一轮已经证实这条路线不能单独解决问题，因此只保留为对照，不作为推荐方案。

### B. 彩色写实肖像雕塑单图

先以相似度较好的单色雕塑图为几何母版，再用 Image2 只施加黑发、自然肤色、白西装、深绿内搭和深色底座，保持雕塑表面的鼻、眼睑、颧骨、笑纹和下颌起伏。Tripo 读取的是带几何明暗的 raw 彩色雕塑，不是扁平化后的严格四色图；输出再映射到用户耗材色。该方案调用短、身份信息强，是推荐的单图生产基线。

### C. 彩色肖像雕塑四视图

从通过门禁的彩色母版生成前、左、后、右四个一致正交视图，明确规定两只袖管从肩到袖口连续为白色，肤色只出现在脸、耳、颈及源图可见手腕/手部。使用 Tripo multiview-to-model，可从输入层消除“看不见的肘部由模型自由猜测”。这最有希望解决手臂混色，但多一次 Image2，且四视图身份一致性必须硬门禁。

### D. 保留雕塑网格，只重新生成纹理

复用上一轮已经闭合、单连通且袖管正确的雕塑 Tripo task，通过 Tripo `/v3/models/texture` 提供单图或四视图彩色参考，只替换纹理而不改变几何。这是几何与颜色最彻底的解耦，能直接验证“雕塑更像”是否可以与多色共存。代价是生产链需要两步 Tripo 任务；若质量优势不明显，不进入默认路径。

## 决策与十次 Tripo 预算

先用不限次数 Image2 建立 r1/r3 两张雕塑母版的彩色候选池，并按身份、白袖连续、肤色边界、姿态和底座筛选。十次 Tripo 任务自适应分配，但每个新 Tripo task ID（包括纹理任务）都计入总数，最多且目标为恰好 10：

1. 两到三个彩色雕塑单图直接建模，比较母版和材质表达。
2. 两到三个四视图建模，比较 `original_image` 与 `geometry` 对齐。
3. 两到三个既有雕塑网格重纹理，比较单图与四视图参考。
4. 剩余次数用于对首批优胜路线做单变量确认，不重复原样抽卡。

任务创建前保存输入哈希、参数和 paid intent；失败或结果不确定时恢复原 task，不创建替代任务。

## 验收标准

- 脸部：与原图逐项比对脸宽/脸长、眼型与眼距、眉弧、鼻梁/鼻翼/鼻尖、嘴宽与笑容、颧骨、下颌和下巴；不得只因“是亚洲成年女性、微笑、盘发”就判定相似。
- 发型与姿态：保持原图发缝与后梳盘发、露耳、开放下颌线、正面头角度、双臂交叉顺序、同侧手表和原裁切。
- 材质：白西装的肩、上臂、肘下、袖口、腋下遮挡边和衣身必须连续为衣料色；肤色不得出现在袖管、衣身或底座。仅源图可见的脸、耳、颈、手和腕可使用肤色。
- 三维：单一主要连通体、闭合、无非流形和退化面，一体低底座可站立；五视图均检查袖管和背面，不以正面漂亮替代完整检查。
- 耗材色：最终 OBJ 只包含选定四色，保留眼眉/头发、肤色、白衣和绿内搭的可读边界；任何连续大面积错误肤色为 reject。
