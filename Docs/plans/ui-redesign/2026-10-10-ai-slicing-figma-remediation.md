## 3. 状态与工程更新

| 状态 | 目标卡 | 开始切片 | 去打印 |
| --- | --- | --- | --- |
| 首次进入 / 分析中 | 初始无选中，逐目标显示实际状态 | 禁用 | 无有效 G-code 时禁用 |
| 方案可用、未选择 | 展示真实结果，无选中 | 禁用 | 依据当前板有效 G-code 判断 |
| 已选择可用方案 | 当前卡选中，摘要与候选一致 | 必要确认完成后启用 | 依据当前板有效 G-code 判断 |
| 正式切片中 | 锁定影响当前任务的操作 | 不可重复启动 | 禁用 |
| 切片成功 | 展示本次方案与实际结果 | 按结果态设计呈现 | 可打印结果就绪后启用 |
| 模型 / 配色 / 打印配置 / 当前板变化 | 旧候选和选择失效，重新分析 | 禁用直至新方案被选择 | 旧结果失效后禁用 |
| 分析失败 / 方案不可用 | 显示真实原因并允许相关重试 | 不自动降级为原生切片 | 依据真实结果有效性判断 |

“未选中”是 UI 状态，不能直接把空值用于现有三目标枚举数组下标。协调器可保留内部计算目标，正式 Apply 必须同时验证用户选择、候选身份和 workspace revision。

检查结果与信息浮层应以本页实际显示的正式模型为准，并绑定模型身份及工程版本。已有工作台检查记录仅在模型身份一致时复用；原生编辑、模型替换或版本变化后，不继续展示原始生成资产的旧检查结果或旧统计。

配色操作应更新当前操作模型在正式工程中的区域配色；复用其原色与区域数据、已有匹配算法和耗材能力校验。提交前固定目标对象与工程版本；计算失败或工程变化时不产生半提交。一次完成的操作形成一次 Undo，保留其它对象、原始生成资产与物理耗材配置，随后重新分析。Undo / Redo 同样失效旧候选与 G-code。不能只更新工作台预览、却让正式切片继续使用旧配色。

## 4. 实施步骤与验收输出

1. **固定图层规格与状态映射。** 从上述 Figma 节点提取所需视觉属性和已有图标对应关系，更新与本轮用户确认冲突的 UX 条款。输出逐项规格与确认后的状态表；核对四类 AI 页面状态。
2. **还原页面与专用控件。** 实现侧栏、检查行、两个配色下拉、滑块、色板、美颜入口、统一切片模块、底部按钮和信息浮层。输出可运行的可见页面；在基准尺寸与当前 Windows DPI 对照截图。
3. **接通正式工程配色。** 复用现有颜色处理，通过当前工程事务更新目标模型。验证操作成功、失败零写入、一次撤销/重做、其它对象保留，以及旧候选/结果失效。
4. **调整 AI 选择与执行状态。** 初始未选、自动分析、真实结果渐进更新、选中后启用、风险确认及禁止隐式原生路由。验证候选失败不会覆盖其它目标、工程变化不会 Apply 旧候选、重复点击不会重复提交。
5. **还原画布、进度和结果衔接。** 使用原生 3D / Preview 渲染与切片线程，按设计控制工具、浮层、首次构图、进度和去打印按钮。验证 AI / 原生切换、切片取消、完成、返回与结果失效。
6. **构建并实际检查。** 在本 checkout 的 `.tmp/dev/build` 增量构建，安装到 `D:\OrcaSlicer\.tmp\dev\run`，核对源码与运行产物身份；用隔离配置与已有真实资产操作受影响流程，保存 Figma / 实际程序的同状态对照与差异记录。

主要落点：

- `src/slic3r/GUI/Redesign/RedesignModelWorkflow.cpp`、`RedesignShell.hpp` 与必要的页面专用组件：容器、状态呈现、按钮和浮层。
- `src/slic3r/GUI/AI/ModelGeneration/ModelPreviewColorControls.hpp`、现有 FeatureHost / Orca 配色适配器：复用配色能力并接正式工程更新。
- `src/slic3r/GUI/AI/SmartSlicing/SmartSlicingWorkbenchState.hpp` 与 FeatureHost：用户选择、有效性和执行路由。
- 现有 Canvas / Plater 展示入口：工具栏状态、视角和真实进度适配；按需增加小范围展示接口。

检查范围：受影响的 UiRedesign、PostGenerationWorkbench、ModelPreviewPalette、颜色事务和 SmartSlicing 相关用例；如调整跨模块契约或共享边界，执行对应集成检查并保留全部结果。纯样式不增加照抄实现的单元测试。

实际 GUI 验收使用已有真实资产，覆盖本页正常状态、失败/取消、配色 Undo / Redo、切页状态、AI / 原生切换和结果有效性。模型或机器不满足真实 AI 候选条件时，准确记录该成功路径未验证，不能解除能力校验来展示设计示例。普通原生切片可另行验证其真实成功路径。
