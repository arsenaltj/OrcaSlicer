# 模型导入颜色模式设计

## 目标

将 AI 生成阶段的“使用可打印颜色”与 OBJ 导入阶段的颜色处理解耦，避免关闭生成色板约束时强制按单耗材导入。

## 交互

- “使用可打印颜色”只控制 AI 图片、模型和色板约束。
- 新增“导入颜色”选择，默认“正常导入（保留颜色）”，可切换为“单色导入”。
- 正常导入且生成结果带可打印色板时，优先自动映射到当前耗材槽位。
- 自动映射失败不再判定模型导入失败；模型保留在准备页，不自动切片，并提示用户使用 Orca 手动上色。
- 正常导入且生成结果为自然色时，复用 Orca 原生 OBJ 颜色导入流程。
- 单色导入显式忽略 OBJ 颜色，并按当前单一耗材继续切片。

## 安全边界

- 开放或非流体网格仍不得自动切片。
- 自动上色失败与网格修复失败都进入准备页，由用户处理后再切片。
- 原始 OBJ、颜色信息和修复诊断继续保留在项目 `generated_models` 目录。

## 验收

- 关闭“使用可打印颜色”后，页面不再宣称必然按单耗材打印。
- 默认导入策略显示为“正常导入（保留颜色）”。
- 用户可显式选择“单色导入”。
- 自动颜色映射失败时模型仍被导入，进入准备页且不触发切片。
- 模型库模型沿用同一导入策略。
