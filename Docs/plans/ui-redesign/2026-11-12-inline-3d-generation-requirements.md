## 1. 背景与目标

当前智能模式和高级模式点击“生成3D模型”后，会进入工作台下的独立生成等待／结果页面，再从结果页进入模型编辑。生成过程与创作输入分离，也使“工作台”同时承担生成等待和模型编辑两种入口含义。

本需求将 3D 生成进度与结果预览放回各自创作页的中央区域。用户看到模型成功显示后，可选择重新生成，或点击“进入工作台”进行模型编辑。工作台 Tab 直接进入现有编辑工作区。

核心目标：

1. 智能模式从提交到显示结果，保持在智能创作页。
2. 高级模式从提交 3D 到显示结果，保持在高级创作页。
3. 完成态的双按钮和顶部提示使用已读取的 Figma 元素参数。
4. 两种来源统一进入现有的一套编辑工作台，继续原有下游业务。

## 2. 三条不可降低的业务底线

| 编号 | 底线 | 必须保留的行为 |
| --- | --- | --- |
| BL-01 | 智能模式业务流程正常 | 输入、原资格校验及任务保护、输入准备、3D 提交、进度、停止／恢复、下载、显示、历史与重新生成均正常 |
| BL-02 | 高级模式业务流程正常 | 独立草稿、四图生成与选择、整组历史、四图资格和确认、同组四图建模、停止／恢复及重新生成均正常 |
| BL-03 | 工作台下游原业务正常 | 模型编辑→导入切片→切片→G-code 预览→打印衔接正常，原有保护、确认、取消、失败恢复和返回入口正常 |

三条底线分别验收。智能通过不能代替高级通过，生成展示通过不能代替下游流程通过；编译、自动测试、界面验证和实物打印也分别记录。

## 3. 范围及新旧需求关系

### 3.1 本次范围

- 取消独立的 3D 生成等待／结果中转页及通往该页的业务路由。
- 将生成状态、下载／本地处理反馈及真实 3D 结果预览嵌入智能和高级各自中央区域。
- 完成态左栏底部同排显示“重新生成”和“进入工作台”。
- 完成态顶部显示指定成功提示。
- “进入工作台”显式打开当前显示成果，工作台 Tab 直接进入编辑区。
- 调整受影响的返回、历史恢复和异常展示入口，保留原有业务能力。
- 验证两种模式及统一工作台下游链路。

### 3.2 沿用的业务边界

生成供应商、模型算法、调用参数、确认策略、面数及质量选项、历史格式、计费规则和并发策略沿用现状。高级 2D 的四视角布局、选择、定向编辑和套图规则不因移动 3D 展示位置而改变。

模型检查／修复、多色／配色、美颜、底座、保存、候选接受／放弃、撤销／重做及切片／打印仍由现有工作台和 Orca 业务负责。本文未要求新增生成预算、历史迁移、自动编辑、自动切片或自动打印。

## 4. 术语与完成判定

| 术语 | 定义 |
| --- | --- |
| 创作页 | AI 创作中的智能工作区或高级工作区，分别保有自己的输入、任务和历史上下文 |
| 页内生成区 | 对应创作页中央区域，用于显示生成进度、本地处理和 3D 成果；不包含工作台编辑能力 |
| 当前任务 | 与来源模式、创作会话／套图及请求代次匹配的有效任务，不能仅以“最近返回的结果”判断 |
| 当前成果 | 预览所显示的具体模型及其任务／资产／历史引用，不等同于尚未生成的新输入 |
| 生成完成 | 当前任务远端成功，模型取得且必要校验／解析成功，并已在本地预览中成功显示 |
| 重新生成 | 用户显式发起的新一轮生成，按对应模式原流程校验；确认仅适用于原有该步骤的模式 |
| 恢复／重新加载 | 核对既有任务或重新获取／加载已有成果，沿原资格执行，与新提交生成区分 |
| 工作台 | 现有唯一的模型编辑工作区；当前编辑资产与各创作任务的成果相互独立 |

远端状态为成功、本地存在模型路径或进度到达 100%，均不能单独作为“生成完成”的充分条件。预览失败时不能显示完成双按钮和成功提示。

## 5. 页面与导航规则

### IG-01：创作页保持与中央展示

1. 两种模式发起 3D 生成后，当前模式和页面保持不变，中央区域切换为该模式的生成反馈。
2. 输入准备、提交、排队／生成、下载、解析和完成更新不自动切换 Tab 或打开其他页面。
3. 用户主动离开时沿原业务资格及保护处理；允许离开后，任务更新不能把用户拉回来源页。
4. 返回时展示对应模式、对应任务的实际状态，不重新提交生成。
5. 智能和高级状态互不覆盖，页面重绘、缩放、最小化恢复也不构成提交命令。

### IG-02：取消中转页

独立生成等待／结果页不再作为用户可达页面。原页面提供的有效进度、错误、停止／恢复和模型预览能力须迁入来源创作页，不能随页面一起丢失。

相关的“查看3D模型”、返回结果、任务恢复入口应按真实用途进入来源创作页或编辑工作台，不再回到被取消的页面。仍有效的切片和 G-code 预览页面继续保留。

### IG-03：工作台 Tab

- 点击工作台 Tab 进入现有模型编辑区，不恢复到生成等待／结果中转页。
- 已有当前编辑模型时恢复该编辑对象；生成页有新成果不会自动替换它。
- 没有编辑模型时展示工作台空态与历史模型列表，无对象的编辑／导入操作按原规则不可用。
- Tab 切换不重新导入、不自动切片、不停止正在执行的切片或打印业务。
- 从切片／预览重新进入工作台时，保留既有工程及返回入口。

## 6. 智能模式完整流程

### IG-04：首次生成

1. 用户在智能模式完成当前输入及原有选项设置。
2. 点击左下角“生成3D模型”，沿原智能资格及任务保护执行；校验失败不新增任务。原智能流程没有生成确认弹框，保持原流程，不新增确认步骤。
3. 受理后留在智能创作页，中央显示原输入准备流程及后续 3D 状态。
4. 原智能输入准备完成后，按原连续流程提交 3D，不新增高级四图确认步骤。
5. 生成成功后，继续显示下载、校验／解析和预览加载反馈。
6. 当前模型成功显示后，进入完成态：中央真实模型、底部同排双按钮、顶部完成提示。
7. 用户点击“进入工作台”后，才显式交接该模型给统一编辑工作台。

### IG-05：重新生成

用户已选择按各模式原流程处理。智能“重新生成”使用当前输入，重新执行原“输入准备→3D”的完整链路，不将其简化为仅复用上次中间结果提交 3D。

重新生成仍经过原资格、任务保护及防重复提交规则，不新增生成确认弹框；旧模型及历史引用保留。新任务受理后，中央显示新任务进度，成功后显示新成果。失败和恢复沿第 10 节执行。

## 7. 高级模式完整流程

### IG-06：四图与 3D 生成

1. 高级模式继续使用原有 2D／3D 阶段和独立创作会话。
2. 上传、描述、风格、四图生成、目标选择、双击预览、定向修改及套图历史沿原规则执行。
3. 当前整组四图有效，且输入／风格变化已经按原规则处理后，用户点击“生成3D模型”。
4. 沿原四图冻结、任务资格和确认流程，将整组四图用于同一个 3D 任务。
5. 任务受理后仍在高级创作页，中央区域显示 3D 生成及本地处理，完成后显示真实模型。
6. 四图、描述、套图及其历史引用保留；沿原阶段入口可返回查看 2D，不因切换展示而丢失四图或重发生成。
7. 完成态同样显示底部双按钮及顶部提示；点击“进入工作台”交接该成果。

### IG-07：重新生成

用户已选择按各模式原流程处理。高级“重新生成”复用当前已确认的整组四图，仅重新生成 3D，不默认重生 2D，不将四图退化为单图建模。

图片、风格等设计输入发生变化且按原规则要求更新四图时，应先回 2D 完成更新，再取得 3D 资格。缺图、无效图、待更新图或存在真实在途任务等情况，沿原规则阻止不合法提交并给出原因。

修改输入不会改写旧 3D 成果的来源。进入工作台始终对应正在显示的具体模型；旧成果不能被标记为尚未生成的新输入的结果。

## 8. 中央区域及操作状态

### IG-08：状态与动作一致

下表描述用户可见状态，不要求新增一套业务状态机。实际阶段、资格及进度从原模式任务状态投影获得。

| 状态 | 中央区域 | 左栏底部动作 | 成功提示 |
| --- | --- | --- | --- |
| 待生成／不满足资格 | 原模式输入／设计展示及原有资格说明 | 原“生成3D模型”，可用性沿原规则 | 不显示 |
| 校验／原有确认 | 沿原模式校验；仅原有确认步骤的模式保留该交互，保持当前页 | 原忙碌／确认保护，避免重复受理 | 不显示 |
| 输入准备／提交／排队／生成 | 当前阶段、真实进度及原有动画／耗时反馈 | 原停止／任务动作按实际资格呈现，不显示完成双按钮 | 不显示 |
| 下载／校验／解析／预览加载 | 对应本地处理反馈，不能一直伪装成远端生成 | 不提前开放当前新成果的工作台入口 | 不显示 |
| 完成 | 当前真实模型，可旋转／缩放 | 同排“重新生成”“进入工作台”，分别按原资格及有效资产判断可用性 | 显示指定完成提示 |
| 停止／等待恢复 | 原任务实际状态、原因和已有恢复入口 | 沿原停止／恢复／重试资格 | 不显示 |
| 生成／下载／预览失败 | 错误及可执行的恢复／重新加载说明 | 按失败类型沿原资格操作 | 不显示 |
| 进入工作台处理中 | 沿既有切页及资产加载保护呈现 | 阻止重复打开，成功后进入编辑，失败按原事务回滚 | 不重复触发 |

具体要求：

- 沿用原进度算法、阶段动画、耗时及估算标识；不能将 Figma 的静态 36% 当作真实进度。
- 无可靠百分比的阶段使用原阶段反馈，不伪造持续递增的进度。
- 完成双按钮固定在左侧栏底部，不随输入内容滚动离开可用区域。
- “重新生成”和“进入工作台”绑定当前来源及具体任务／资产，不能读取另一模式最近的结果。
- 点击后若出现原确认并选择取消，保留旧成果和当前界面，不新增生成或替换编辑模型。
- 当前任务处于忙碌状态时沿原防重复规则，不因连点、切页或窗口恢复创建额外任务。

### IG-09：完成模型预览

中央展示真实取得并成功加载的模型，复用现有预览的旋转、缩放和取景行为。模型按中央可用区域适配，不固定使用设计稿示例图片的尺寸、位置或形状。

创作页预览用于查看成果，模型编辑仍在统一工作台进行。显示模型统计时使用真实解析结果；修复状态依据原检查业务取得，不能照抄设计稿“检查修复 正常”。

## 9. 进入工作台与下游业务

### IG-10：显式交接与单一编辑资产

1. 点击“进入工作台”时捕获当前可见成果的准确任务／资产身份。
2. 继续使用原有未保存修改、未接受候选及处理中保护；取消切换保留现场。
3. 经原资产有效性校验、加载及呈现事务进入现有工作台，不创建高级专属编辑宿主。
4. 进入成功后，工作台当前模型与点击的成果一致，模型检查／修复等依照原入场策略执行。
5. 文件缺失、解析失败、加载失败或目标显示失败时，提示原因并按原事务语义恢复，不能清空原编辑对象或重复提交生成。

例如工作台正在编辑 A，创作页生成 B：B 完成时 A 保持；点击 B 的“进入工作台”后经保护才允许切换；取消或切换失败时 A 仍有效。

### IG-11：编辑→导入切片→切片→打印

| 阶段 | 必须保持的业务 |
| --- | --- |
| 编辑 | 原检查／自动修复、多色／配色、美颜、底座、保存、另存及撤销／重做；已有模型凭证及候选保护 |
| 导入切片 | 原确认、颜色／材料匹配、工程保护、统一进度、原生工程提交与目标视口准备 |
| 导入成功 | 按原入口进入切片准备流程，不因来源是高级模式而绕过到打印准备 |
| 导入取消／失败 | 原模型与有效工程保留；按原事务处理已提交结果，不重复导入 |
| 切片 | 用户显式操作，保留现有原生及智能切片选择、参数应用、取消、失败处理和重新切片规则 |
| 预览 | 使用当前有效工程和切片结果，旧 G-code 失效条件与重新切片资格保持 |
| 打印 | 继续原设备选择、有效 G-code 校验及发送／打印确认，不因进入工作台或切 Tab 自动发起 |
| 返回 | 编辑、切片、预览及创作之间沿既有入口往返，不能跳回被取消的中转页 |

导入不静默切片或改变预设。AI 不可用或关闭时，普通 Orca 工程、模型导入、预设、手动切片与打印行为保持。

### IG-12：返回与历史

- 从生成成果进入工作台后，返回相应来源模式／工作区。
- 用户已新建创作或切换高级套图时，尊重最新工作区，旧模型不能反向覆盖新草稿。
- 工作台切换 3D 历史只替换编辑对象，不改写创作输入或高级四图。
- 模型库、本地模型和已完成的 3D 历史继续走原直接打开编辑流程，不经生成等待页。
- 未完成任务恢复返回对应创作页并继续观察原任务；不能将高级任务按智能单图流程重提。
- 打开历史、返回页面和恢复程序本身不自动创建新生成。

## 10. 异常、异步及数据保护

### IG-13：异常与恢复

| 情况 | 要求 |
| --- | --- |
| 输入／服务资格不满足 | 在当前页提示原原因，不跳页、不创建任务 |
| 用户取消原确认（仅原有该步骤的模式） | 释放本次准备状态，保留输入、四图、旧模型及失败记录 |
| 输入准备或远端生成失败 | 当前创作页呈现真实失败；保留任务身份、历史及可用成果，沿原资格恢复或显式重新生成 |
| 请求结果不确定／断线 | 保留原任务并按原流程核对，不因未收到回执立即再次付费提交 |
| 停止 | 分发到正确来源和任务，保留原停止语义；不将停止本地观察冒充远端已经撤销 |
| 下载／本地校验失败 | 保留远端任务与已取得文件，沿原重新获取／恢复能力处理，不自动重生模型 |
| 解析／预览失败 | 显示加载失败及已有重新加载入口，不报生成完成、不弹成功提示 |
| 程序重启 | 沿既有持久化恢复任务／套图／历史，未完成任务回来源创作页，已完成成果按原查看或编辑入口打开 |
| 用户离开来源页 | 原任务按原规则继续或受保护；回调更新所属状态，不抢导航 |
| 进入工作台失败 | 按原资产交接事务保留或恢复原编辑对象及来源页，不重复生成／导入 |

### IG-14：异步结果归属

生成、轮询、下载、解析、预览、历史恢复和进入工作台的回调必须匹配来源模式、任务／会话、请求代次及目标模型／修订。过期回调不得：

- 替换当前输入、四图、模型或编辑对象；
- 抢占当前页面、Tab 或焦点；
- 显示另一任务的完成提示；
- 解除另一任务的忙碌保护或触发额外提交。

新建创作、切组、跨模式和重生成后，旧结果仍保留其原有任务／历史归属。

### IG-15：数据与运行兼容

- 保留用户原图、四图、已生成模型、历史引用和原有失败证据，不因取消页面删除成果。
- 成果继续写入既有用户模型目录，不改为安装目录，不新增历史迁移。
- 工作台当前编辑资产独立于生成状态；重绘、新建创作和生成完成不构成资产替换。
- 模型来源、内容摘要、颜色信息、参考图及现有检查凭证沿原链路交接。
- 保存、撤销、原生工程和设备状态仍由原业务所有者维护，展示层不能建立第二份业务真值。
- 日志沿原任务关联方式保留阶段和失败原因，不记录凭据或将用户素材复制进普通源码／日志。

## 12. 可行性、影响范围与开发约束

2026-11-13 用户已确认[四项实测反馈修改方案及30条补充测试](2026-11-13-inline-3d-generation-feedback-fix-plan.md)：智能输入空态仅保留原生成主按钮，未完成任务恢复仍须可达且不自动推进新的付费阶段；两模式重新生成图标使用透明原双星；高级3D提示复用既有中文状态映射并保留诊断；智能准备标题为“正在准备建模参考图…”，副文为“完成参考图准备与校验后，将自动生成3D模型。”。此补充不改变原业务流程、确认规则或41条验收口径；其他UX／业务不调整。

### 14.1 已确认

- 三条业务底线。
- 智能／高级在各自中央区域生成并显示3D，不因生成自动跳页。
- 独立生成等待／结果中转页取消，工作台Tab直接进入现有编辑工作区。
- 成功显示后底部同排“重新生成”和“进入工作台”，顶部显示指定提示。
- 点击“进入工作台”显式交接当前成果，继续统一编辑与下游流程。
- 重新生成按各模式原流程：智能完整链，高级确认四图重建3D；设计输入变化遵循原2D资格。
- 2026-11-13 用户明确确认：AC-S03 记为不适用，智能模式保留原无生成确认弹框的流程；输入、历史及旧成果保护的已有证据保留，详见第13.1节。
- 视觉以实际Figma元素参数为依据，样例和便签不扩展业务范围。
