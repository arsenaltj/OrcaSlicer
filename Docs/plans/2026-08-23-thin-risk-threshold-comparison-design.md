# 阶段 75：薄壁实测值与建议下限对照设计

日期：2026-08-23

## 目标

在风险区导航指标中并列显示当前区域最小实测厚度与本次质量报告使用的局部壁厚建议下限，避免用户只看到一个数值却不知道风险幅度。

## 数据与交互

1. C++ 客户端从质量报告已有 `thresholds.min_local_wall_thickness_mm` 读取可选建议下限，不新增 Sidecar 字段或 schema 版本。
2. 当前区域和建议下限都为有限正数时显示“最薄 X mm / 建议 ≥ Y mm”。
3. 旧报告没有 thresholds、字段格式异常或数值无效时只显示阶段 74 的实测值，不影响定位和导航。
4. v7 平面证据没有区域级指标时继续保持旧行为。
5. 文案只解释质量门判断，不自动执行加厚、修复、支撑或切片操作。

## 边界

- 修改限于模型生成 C++ 客户端契约、`ModelGenerationPanel` 和模型生成文档。
- 不修改 Provider、Sidecar、MainFrame、Plater、CMake、3MF/profile、默认切片行为或永久配置。
