# 阶段 68：局部悬垂风险定位设计

日期：2026-08-23

## 目标

把 Sidecar 已能识别的“显著局部悬垂”从质量报告数字落到 3D 模型预览上。用户可以一键高亮具体三角面，再旋转模型检查或在既有局部区域工具中手动增减选区。

本阶段只提供模型生成侧的风险定位，不自动生成支撑、不改变摆放方向、打印参数或切片结果。

## 方案

在无 wxWidgets 依赖的 `VertexColorRegionEditor` 中新增显著悬垂区域选择：

1. 以模型最低 Z 为热床基准，最低点以上 0.5 mm 作为离床判断带。
2. 面法向朝下且表面相对水平面的角度不超过 45°时，视为候选悬垂面。
3. 复用既有三角面邻接关系，把候选面聚合为连通区域；OBJ 因 UV/材质产生的重复顶点接缝继续按几何边焊接。
4. 仅选择面积至少 4 mm²、且占模型总表面积至少 0.05% 的显著区域。
5. 在模型质量卡增加“定位悬垂面”入口。定位成功后展开既有局部区域工具，橙色高亮结果，并保留撤销、清空和手动增减能力。

默认阈值与 `printable_model_quality.py` 的 `structural-v5` 规则保持一致，因此报告计数和预览定位采用相同的几何语义。

## 安全降级与误报控制

- 接地带内的模型底面不属于悬垂候选，避免把平放底座误标为支撑风险。
- 退化三角面不参与面积和选区。
- 小于绝对面积或相对面积阈值的孤立噪声不高亮。
- 无可定位区域时保持模型和原选区不变，并给出明确提示。
- 结果只是复核选区；不会写回 OBJ，除非用户随后明确点击既有“应用”按钮。

## 边界

实现仅修改模型生成区域编辑器、`ModelGenerationPanel`、对应 C++ 测试和文档。不修改 `MainFrame`、`Plater`、CMake、3MF、profile、Orca 支撑/切片算法或 Provider，不调用任何付费 API。
