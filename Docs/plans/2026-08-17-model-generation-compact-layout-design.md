# 3D 生成页紧凑排版设计

## 目标

在不缩小字体、不删功能、不改变生成状态的前提下，减少左侧表单的滚动距离，让每个控件的含义明确可见。

## 方案

- 页面外边距由 18 DIP 收紧到 12 DIP；标题区改为 12 / 4 / 10 DIP 的标题、说明和底部节奏。
- 旅程区使用 6–10 DIP 间距，保留步骤、当前动作和进度，但降低其占用高度。
- 表单采用三级间距：字段内部 4–6 DIP，同组字段 8 DIP，分组之间 10–12 DIP。
- 主体描述和自定义风格继续自适应高度，但减少内边距并隐藏不必要的垂直滚动箭头。
- 用全宽文字按钮 `显示高级设置` / `收起高级设置` 替换原生 `wxCollapsiblePane`。按钮通过普通面板显隐控制高级内容，不再依赖主题相关的箭头和标题绘制。
- 高级内容内部继续保留颜色用途和打印尺寸，行间距压缩到 4–5 DIP。

## 兼容与验收

- 现有字段指针、事件处理、请求值和恢复逻辑不变。
- 按钮应支持键盘焦点和屏幕阅读器，不使用只有图形的无标签操作。
- 正式 Windows Orca 中验证默认收起、文字可见、展开/收起不缩放窗口、文本框无无意义箭头、图片对比与页面状态保持。
- 不调用 Image2 或 Tripo。
