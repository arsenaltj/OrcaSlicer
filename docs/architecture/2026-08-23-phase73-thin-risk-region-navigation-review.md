# 阶段 73：薄壁风险区逐处导航验收

日期：2026-08-23

## 结论

阶段 73 已在模型生成 GUI 中完成薄壁风险区逐处导航。首次点击“定位薄壁”选择报告中最高风险区域，后续按钮变为“下一处薄壁”，按阶段 72 的风险顺序循环查看各报告区域；每次切换继续复用既有选区与撤销链路。

本阶段不修改质量报告、Provider、Sidecar、网格或切片逻辑，也不会自动修改模型。

## 交互与兼容性

- v8 报告按 `thin_local_regions` 的既有排序从第一处开始导航，并显示“第 N/已报告区域数”和质量门识别到的完整区域总数。
- 导航选区与当前选区严格匹配；撤销到上一风险区时导航序号同步回退，再次点击“下一处薄壁”不会跳过区域。
- 撤销到空选区或手动改变选区后，导航状态复位，按钮恢复“定位薄壁”，状态提示同步清零。
- 加载其他模型、清空质量报告或开始重新检查时重置导航状态。
- v7 只有平面 `thin_local_face_indices` 时继续使用一次性全证据定位，不显示逐处导航；无证据或编辑器不可用时仍安全禁用。
