# 3D 生成页输入精简与显式图片对照设计

## 目标

让首次使用者只需要理解“要生成什么、采用什么风格、是否参考图片、是否限制为当前耗材颜色”，同时让图片确认阶段无需记忆切换即可比较生成原图和可打印处理结果。

## 左侧信息层级

首层保留：

1. 模型描述。
2. 风格；选中自定义时展开自定义风格描述。
3. 可选参考图。
4. “限制为打印机耗材颜色”开关。
5. 色板来源、四色块和一句状态摘要。

“主色、轮廓/暗部、浅色、点缀色”以及打印宽度、喷嘴、线宽、最小特征统一放入默认折叠的“高级设置（通常无需修改）”。这保留专业能力，但不要求普通用户先理解颜色角色和几何阈值。

## 自适应文字框

- 模型描述：最少 2 行、最多 6 行。
- 自定义风格：最少 2 行、最多 5 行。
- 输入时按换行和当前宽度估算显示行数，实时调整高度。
- 超过上限后保留内部滚动，不继续挤压固定主操作区。
- 使用通用 wxWidgets 文本测量与 sizer 布局，不引入 Windows 专属消息。

## 图片对照

| 输入类型 | 左侧基准 | 右侧结果 |
|---|---|---|
| 纯文字 | AI 原图 | 严格色板 / 可打印清理 / 问题热力图 |
| 含参考图 | 用户参考图 | AI 原图 / 严格色板 / 可打印清理 / 问题热力图 |

选择“AI 原图”且任务没有参考图时只显示单图，避免左右重复。其余阶段默认双栏，并在各自顶部显示明确标签。

## 非目标

- 不修改图片生成、四色处理或 3D 生成算法。
- 不增加新的图片或 3D 付费调用。
- 不改变 Sidecar、任务 JSON、模型库、3MF 或打印配置。

## 验收

- 短文本框不留大块空白，连续输入后高度自动增长且不超过上限。
- 高级设置默认折叠，四色开关关闭时相关选项正确隐藏。
- 恢复现有纯文字任务后，默认同时显示 AI 原图和可打印清理图。
- 阶段下拉切换后立即刷新，不需要点击缩放或其他按钮。
- Windows Release 构建和正式 Orca 页面往返、重启恢复验证通过。
