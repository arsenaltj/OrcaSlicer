## 新增执行契约

- 新工具 `approved_palette_model_validation.py` 只接受阶段 64 汇总中 `tripo_candidate=true` 的一个案例。
- 工具不会创建人工批准；批准必须由已有 `manual-review` 命令生成。
- 每次运行都重新校验严格四色预览、视觉报告和建模参考图的 SHA-256；任一证据变化都会拒绝调用。
- 未提供 `--confirm-paid-call` 时只输出预检，不创建远程任务。
- 远程任务 ID 由既有可恢复执行器在 Provider 接受后立即落盘；中断后恢复同一任务。
- 最终 OBJ 自动进入 `structural-v9`，并把当前目标四色传给表面积覆盖检查。
