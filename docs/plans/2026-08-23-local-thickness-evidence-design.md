# 阶段 71：局部薄壁证据定位设计

日期：2026-08-23

## 目标

把阶段 70 的采样式局部薄壁数值警告补成可操作的面片证据：用户可在质量卡点击“定位薄壁”，直接在现有局部改色编辑器中高亮对应三角面，再旋转检查或手动调整选择。

定位只用于复核和选区辅助，不自动加厚网格、不生成支撑、不修改切片参数。

## 契约

1. Python 质量门在顶层可选 `evidence.thin_local_face_indices` 中输出命中局部薄壁的采样面序号。
2. 面序号对应 OBJ 解析后的三角面原始顺序；当前质量门只接受三角面，因此不会发生多边形三角化重排。
3. 证据去重、升序排列并限制为最多 256 个；数量上限通过 `local_thickness_evidence_limit` threshold 明示。
4. 报告 schema 保持 `1`，门禁版本提升为 `structural-v7`。旧报告没有 evidence、字段类型异常或序号越界时，C++ 客户端和编辑器安全忽略。
5. `VertexColorRegionEditor` 增加通用面序号选择入口，供后续模型生成语义/质量证据复用；它不依赖 wxWidgets 或 Orca 工作区。

## GUI 行为

- 只有当前预览具有可编辑顶点色，且当前质量报告包含有效局部薄壁证据时，启用“定位薄壁”。
- 点击后替换当前选区、写入现有撤销历史并打开局部区域工具；用户仍可增选、减选、清空或撤销。
- 无证据、无顶点色、旧报告或未完成检查时按钮禁用，不影响预览、重新检查或导入。
- 证据只反映确定性采样命中，不宣称覆盖模型所有薄壁；界面保持“风险复核”措辞。

## 边界

只修改模型生成质量模块、模型生成客户端契约、局部区域编辑器、模型生成 GUI、测试和文档。不修改 MainFrame、Plater、CMake、Orca 壁厚/支撑/切片算法、3MF/profile，也不调用 Provider 或付费 API。
