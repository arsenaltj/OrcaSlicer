## 验收目标

1. 一个主窗口颜色匹配页，生成页和准备页共用。自动计算、手动改色、保护和锁槽、原色对照、确认/取消、撤销/重做、历史恢复均消费同一个结果。
2. 预览、保存和打印使用同一面分组与真实槽位；不通过 RGB 重新猜槽、不二次聚类、不隐式切片。几何或材料变化时拒绝旧结果。
3. 按真实三维表面积评价逐面原始颜色误差，记录均值、P95、最坏区域和未覆盖比例；同时看关键部位残差、反差及细节保留，不只优化总平均色差。
4. 实际人体/人脸语义解析、多视图深度/面 ID 回投、人物身份分离和低置信度手动纠正。小面积重要图案不能按面积阈值直接删除。
5. n>6 时提供真实材料/工艺约束下的两/三料候选，分别记录可执行性和颜色证据；全目标都有去向或解释。没有实测时只能报告预测。
6. 混元、Tripo 均从 Orca 主窗口完整流程得到真实样本，覆盖结果、历史和恢复。真实 3D 累计≤20，生图不限量；账本沿用 `validation/20260914-six-color/provider-budget.json`，不重新计数。2026-09-15 已保守占用 3/20 次：Tripo 真实成功一次；混元两次在本地缺少 HY3D_API 的前置检查被拒绝（第二次用于 R14 错误展示修复的实际复测），未创建远端任务，暂仍计入预算。

## 迭代与停止条件

- 冻结比较样本、源哈希、实际材料/工艺与 n，再比较候选算法；同一模型不能换材料后只报告改善区域。
- 合法性、用户锁和关键部位保留先于软评分；观察到明显串色、细节丢失或恢复失败就修复并复测。
- 一轮优化只改变可解释的算法/参数，保存前后指标、同角度图和代价；拒绝以夸张换色换取高反差。
- 固定样本的相关回归通过，真实流程通过，且候选改进无法在不损害受保护细节/可执行性的前提下改善结果时，才认为达到当前样本和材料条件下的最佳版本。这个结论不等于数学全局最优或未经测量的实物最佳。
- 实物色卡、实际材料批次和测量是独立条件。硬件信息或校准缺失时保持明确缺口，不编造通过结论。
