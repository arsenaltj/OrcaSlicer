# 阶段 76：最终模型目标色表面积覆盖验收

日期：2026-08-23

## 结论

阶段 76 已把 Image2 预览阶段的“显著目标色”概念延伸到最终 OBJ：质量检查按三角形表面积统计每个目标色的使用比例，并在 GUI 中展示显著颜色数、最低建议数、总体目标色覆盖率和逐色表面积。该指标用于提示四色保持度，不把“必须使用四种颜色”变成硬性拒绝条件。

## 质量契约与降级

- 质量门升级为 `structural-v9`，报告 schema 仍为 1。
- Sidecar 只把当前任务中已确认的最多四色目标色板传给最终 OBJ 检查；重新检查沿用任务保存的色板。
- 每个三角形面积均分给三个顶点颜色，再归入最近的目标色；单色达到模型总表面积 2% 才记为“显著使用”。
- 最低建议显著颜色数为 `min(目标色数量, 3)`，避免机械要求所有四种颜色都出现。
- 目标色数量不足只产生 `review` 提示，不拒绝制品；存在色板外颜色时报告目标色总体覆盖率并提示复核。
- 旧任务、无色板任务和无对应字段的旧报告保持兼容：指标标记为不可用，GUI 不显示该行。
