# Code

Carry out the requested implementation and verify its observable behavior. Use applicable repository instructions and current requirements; do not add a second approval process.

Use this repository's current guidance on every development machine. Saved personal preferences apply only when relevant; do not require a machine-local memory file. Persist project decisions in project guidance only when requested.

Read references only for the relevant need:

- [planning.md](planning.md): sequencing substantial work.
- [execution.md](execution.md): implementation and decision boundaries.
- [verification.md](verification.md): tests and visual evidence.
- [state.md](state.md): changes to an ongoing request.
- [criteria.md](criteria.md): saving user preferences.

Use available tools within the user's scope and current permissions. A coding request authorizes necessary local edits and relevant local verification; it does not by itself authorize paid services, publication, external messages or destructive changes to unrelated work. Delegation follows current user and repository rules.
