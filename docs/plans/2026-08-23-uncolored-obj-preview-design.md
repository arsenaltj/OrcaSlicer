# 阶段 69：无顶点色 OBJ 预览兼容设计

日期：2026-08-23

## 诊断

Orca 的 `load_obj` 已能正确解析无顶点色 OBJ，`ModelPreview3D` 也已为渲染准备 ORCA 默认色。实际失败发生在渲染几何创建之后：预览把“局部改色编辑器必须有完整顶点色”误当成“整个模型必须有顶点色”，随后清空已创建的渲染模型并返回失败。

## 目标

允许历史模型库中的合法无顶点色 OBJ 以单一 ORCA 默认色进入 3D 预览、结构复检和正常导入流程，同时明确关闭依赖顶点色的局部改色与悬垂选区入口。

## 方案

1. `ModelPreview3D::load_model` 先独立完成 OBJ 解析和渲染模型创建。
2. 只有 OBJ 提供与顶点数完全一致的顶点色时才初始化 `VertexColorRegionEditor`。
3. 无顶点色时保留渲染模型并返回成功，颜色数报告为 1；局部编辑能力为不可用。
4. 增加只读的 `region_editing_ready()`，GUI 分别判断“3D 预览已就绪”和“局部区域编辑已就绪”。
5. 无顶点色模型隐藏局部改色面板，并禁用“定位悬垂面”；结构复检、AI 视觉复核和导入仍按原契约工作。

## 安全性

- 不为无色或 MTL/纹理 OBJ 伪造顶点色，避免局部保存时意外覆盖原材质外观。
- 不修改底层 Orca OBJ 解析器、导入器或默认颜色规则。
- 顶点色数量非零但与顶点数不匹配时仍视为不可编辑；预览继续使用已有可渲染颜色信息。
- 现有模型生成制品仍要求 Provider 输出完整顶点色，本阶段只增强历史/兼容预览，不放宽生成质量契约。

## 边界

只修改模型生成预览、模型生成 C++ 测试和文档。不修改 `MainFrame`、`Plater`、CMake、3MF、profile、Orca OBJ 核心或 Provider，不调用任何付费 API。
