# 多缺陷彩色 OBJ 保色闭合修复设计

## 问题

真实任务 `4ae4d7e9-f511-4c39-8e93-fd181698eb70` 的 OBJ 为单一主体、14,480 面、15 种自然色，但同时包含 23 条边界边和 3 条非流形边。现有 sidecar 会删除所有非流形边关联面之前，先用这些面的全局包围盒判断缺陷是否局部。三个独立小缺陷相距较远，使全局包围盒达到模型对角线的 20.5%，因此被 5% 阈值误拒绝；Orca CGAL 随后也无法闭合。

## 方案

保持现有阈值和门禁不变，将非流形关联面按共享顶点划分为连通缺陷簇。总删除面数仍不得超过模型面数 1% 或 64 面中的较大值；每个缺陷簇的包围盒对角线分别不得超过模型对角线 5%。任一簇超限时整体安全退出，不做部分修复。

通过簇校验后，沿用现有流程：删除关联面，拒绝剩余非流形边，将有向边界图分解为闭环，拒绝超过 64 边或空间跨度超过 5% 的环，为每个环增加中心顶点并按边界主色赋色，再生成三角扇。最终必须满足每条边恰好关联两个面、面数上限、单连通、顶点色有效和色板约束。

## 当前任务恢复

保留 `attempt-01` 中的原始 OBJ 和原始 `mesh-repair.json`。使用新算法从规范 OBJ 生成修复副本，验证成功后替换任务根目录规范 OBJ 与 `downloads` 副本；替换前保存备份。

Orca 导入时优先使用当前预览对应的本地 OBJ；仅当本地文件缺失且 sidecar 任务仍有效时才重新下载。模型库双击历史模型后恢复 OBJ 路径、顶点色格式和颜色模式，并由用户显式确认导入和切片。这样 sidecar 重启后无需恢复内存任务，也不会再次调用 Tripo。
