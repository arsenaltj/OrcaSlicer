# 3D 生成页模型预览与中文界面设计

## 目标

在不改变现有 AI 服务契约、OBJ 颜色导入和切片链路的前提下，将 3D 模型检查纳入“3D 生成”页面。模型生成完成后不再自动跳转，而是先下载并校验 OBJ，在当前页面展示可交互预览；用户确认后才导入当前打印板、修复模型并生成 G-code。

本次中文化只覆盖 `ModelGenerationPanel` 页面以及由该页面直接触发的状态、提示、确认框和模型库，不扩展到 OrcaSlicer 其他既有页面。

## 页面与交互

右侧预览区使用两个标签页：

- “图片预览”：继续并排展示完整参考图和 AI 风格化结果，保留缩放、适应窗口和滚动查看。
- “3D 模型”：生成结果下载完成后自动切换到该页，显示带颜色的模型、三角面数、模型尺寸和使用颜色数。

3D 预览支持鼠标左键拖动旋转、滚轮缩放和“重置视角”。空状态、下载中、解析失败和模型就绪状态均使用中文说明。模型解析失败时不允许进入导入与切片，但保留本地 OBJ 供诊断。

左侧主流程更新为“输入 -> 图片预览 -> 生成模型 -> 3D 预览 -> 生成 G-code”。模型生成完成后，主按钮显示“确认并生成 G-code”，旁边保留“重新生成”能力。输入、风格和耗材颜色在模型生成后发生变化时，现有结果标记为过期，要求重新生成预览。

## 技术方案

新增轻量 3D 预览控件，复用 OrcaSlicer 的 `OpenGLManager` 共享上下文、`gouraud_light` 着色器、`GLModel` 和 `libslic3r::load_obj`。不嵌入完整 `GLCanvas3D`，避免将打印板、选择、拾取、Gizmo 和切片状态耦合进生成页。

OBJ 顶点色或材质色按当前任务耗材色板映射为最多 16 个渲染分组，每组使用一个 `GLModel` 和一致的打印色。预览仅在 UI 线程初始化 GPU 资源。组件销毁或切换模型时先绑定共享 OpenGL 上下文再释放资源。

状态流调整为：

```text
AI 任务 ready
-> 下载 OBJ 到 generated_models/downloads
-> OBJ 解析与彩色预览
-> 等待用户确认
-> 导入当前打印板
-> 必要时保色修复
-> 触发切片和 G-code 预览
```

## 错误处理

- 非 OBJ 或缺少受支持顶点色：阻止预览和导入，显示中文原因。
- 下载失败：保留远端任务，允许重试。
- OBJ 解析失败：保留本地文件，显示解析错误。
- 导入、颜色映射或保色修复失败：撤销本次导入，不启动切片，保留本地产物。
- 服务不可达或任务失败：现有取消和重试语义不变，页面文案改为中文。

## 验收标准

1. 文字、图片、文字加图片三种输入仍可完成已有预处理流程。
2. 模型 ready 后留在“3D 生成”页并自动显示 3D 预览，不自动导入或切片。
3. 3D 预览可旋转、缩放、重置视角，并展示面数、尺寸和颜色数。
4. 点击“确认并生成 G-code”后才执行导入、修复与切片。
5. 页面所有用户可见交互文案为中文，OBJ、G-code 等标准格式名除外。
6. 使用已有本地 OBJ 和 mock sidecar 验证，不创建新的付费 Tripo 任务。
7. Windows Release 单并发构建通过，Python 回归和现有 G-code 回归无新增失败。
