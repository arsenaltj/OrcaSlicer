## 1. 验收前置与证据

使用对应源码版本的 Windows 完整运行文件及真实 Orca 主窗口，独立配置、模型副本和明确的数据目录。保留用户原始工程、原图、历史和正在运行的实例。

每次执行记录：源码／产物身份、EXE／相关资源版本、配置与端口、服务／供应商及模型、输入引用／哈希、窗口实际宽高、Windows 缩放比例、右栏状态、真实任务／组／视角引用、步骤、实际结果及证据位置。凭据不写入记录。

执行结果使用“通过／失败／阻塞／未执行”。供应商不支持、没有预算、没有匹配运行文件或没有真实调用证据时如实标阻塞或未执行，不能用本地 fixture 或仅界面显示替代真实多图生成／建模通过。

### 输入样本

| 样本 | 内容与用途 |
| --- | --- |
| S1 | 同一对象的清晰主参考、相对左转90°、反向180°、相对右转90°原图，带可辨别且方向不同的配件，用于视角对应与多图约束 |
| S2 | 一条明确、有效的纯文字描述，用于首次纯文字四视角 |
| S3 | PNG／JPG／JPEG／静态透明 WebP，有效尺寸和文件大小；另备不同宽高比图片 |
| S4 | 超过 20MB、损坏、伪造扩展名且不可解码、动画 WebP、不支持格式的无效输入 |
| S5 | 已有有效四图组、部分成功组、局部修改失败仍有旧图的组，使用真实历史或对应任务证据 |
| S6 | 已有旧高级单图历史、已有智能模式草稿／历史及普通 Orca 工程副本 |

真实请求只在已授权输入、服务和预算内执行。展示、选择、标签、侧栏收展和历史查看优先复用已有结果；参数化用例可共享符合条件的生成结果。异常顺序与失败场景可用离线自动测试补充，但真实主窗口对应行为须单独记录，不能另建 mock 服务冒充验收。

## 4. 首次四图生成

| MV-GEN-02 | ADV-04 | 主参考图＋任一个辅助视角 | 分别覆盖左／后／右三种辅助组合，生成四图 | 每种输入均目标为四张；辅助图按相对主相机方向归属正确，不减少输出 |
| MV-GEN-03 | ADV-04 | 主参考图＋任意两个辅助视角 | 覆盖左后、左右、后右组合 | 每种组合均得到四个正确相对视角，未上传方向同样补齐 |

- 智能业务变化、模式串状态、未选视角被重生成、双击误改选择、四图缺失仍绕过资格提交、3D 静默丢弃视角均判为失败，不能用视觉美观或编译通过抵消。
