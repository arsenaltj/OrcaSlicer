## 用户观察与图像复核

### 刘亦菲

1. 眉毛在外眼侧继续延伸并进入发区，属于眉毛/头发语义边界误判。
2. 左耳与头发仍串色，耳前发束和耳轮没有形成稳定边界。
3. 左耳附近存在未正确上色的发丝。
4. 发际线、眼缘、眉毛和耳发交界可见明显三角锯齿。
5. 用户指出细节需要开启光照才能辨认；关闭光照时几何轮廓不足。这是显示可读性问题，不能用光照明暗参与耗材归属。

### 方飞

1. 眉毛附近存在多余眉毛标签，眉形外侧出现误扩张。
2. 耳轮与耳腔出现红色、蓝色杂色；耳发交界也有锯齿状侵入。
3. 发际线、眉毛、眼白/虹膜边缘、嘴唇与衣领边缘均能看到三角离散造成的锯齿。
4. 面部局部图显示蓝色细边并非正常材质细节，不能由 4 倍 MSAA 消除。

## 归因与下一版要求

1. 耳朵与头发串色仍是粗语义掩膜问题。本包未启用边界模型，因此该失败符合当前版本能力边界，不能用于否定或确认 MobileSAM 的产品效果。
2. 当前锯齿中既有屏幕采样锯齿，也有真实材料分区沿三角面跳变。4 倍 MSAA 只能改善前者。后者必须由软轮廓回投和深度 3 自适应子面共同处理。
3. 下一版必须真实启用 MobileSAM Provider，并在界面运行结果中记录 Provider、模型哈希和处理版本；否则不得称为耳发优化候选。
4. MobileSAM 只处理耳发 ROI。眉毛和眼白/虹膜需要独立的边界目标与保护规则，不能依赖耳部提示外扩。
5. 下一版用户仍只需提供四模型六面图和问题描述。缓存、取消、故障回退、预算、模型身份和保存一致性由自动测试与日志负责。
