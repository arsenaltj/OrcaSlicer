# 阶段 65：语义材料区域快捷选择设计

日期：2026-08-23

## 目标

在阶段 58 的局部改色底部编辑器中增加“按语义材料区域选择”。对于使用可打印四色生成的顶点色 OBJ，用户可以按主体、结构、浅色或强调色一键选中模型上对应的全部材料面，再通过现有添加、减去、撤销和应用改色流程修正结果。

该功能只建议和建立选区，不自动改色，不调用付费 API，也不把任何智能切片逻辑带入 Orca 核心。

## 方案

### 不采用：Provider 返回三角面 ID

Provider 不掌握本地最终 OBJ 的稳定面序，百万级面 ID 也不适合进入 JSON 状态。网格简化、修复或重新导出后会让索引失效，失败恢复成本高。

### 不采用：在 `VertexColorRegionEditor` 中调用 Sidecar

这会把网络、业务状态和 wxWidgets 生命周期带入目前纯网格编辑器，破坏阶段 58 已建立的可测试边界。

### 采用：语义角色映射到确定性材料选择

AI 推荐链路已经提供 `primary / structure / light / accent` 与目标 HEX 的稳定关系。最终 OBJ 使用同一色板写入顶点色。GUI 只把角色标签和当前模型色板交给本地编辑器；编辑器逐面计算平均顶点色，并使用与 3D 显示一致的最近色板色规则，把全部面确定性分组。点击一个角色时替换当前选区，随后仍可人工补选或减选。

## 契约与状态

- `VertexColorRegionEditor` 新增纯本地的按色板索引选区接口；输入是有序 RGBA 色板和目标索引，输出仍是既有选择位图。
- 最近色判断使用 RGB 平方距离，距离相同时稳定选择较小索引，与当前 `ModelPreview3D` 分组规则一致。
- 选择动作进入已有最多 20 次的选区撤销历史；空色板、越界索引或未加载模型安全返回，不改变选择。
- GUI 最多显示四个来源材料按钮。存在 AI/用户角色映射时显示“主体/结构/浅色/强调”，缺失或历史数据不完整时显示“材料 1–4”。
- 当前模型色板与目标耗材色板分离：来源按钮只使用模型加载时的色板，改成按钮继续使用 `IPrintablePaletteProvider` 提供的当前耗材色。
- 模型库元数据中已有可选 `palette_roles`；阶段 65 读取并恢复该字段。旧元数据没有该字段时自动按现有色板分配通用角色，不修改 schema，也不影响加载。

## GUI

局部改色展开后，在手动点击选择行上方增加一行“智能区域”。每个按钮包含语义角色和当前模型 HEX。点击后立即高亮全部匹配材料面，摘要显示选中三角面数量。按钮只在顶点色模型、可用来源色板和非忙碌状态下启用。

用户仍可：

1. 用“添加区域/减去区域”修正自动选区；
2. 用撤销或 `Ctrl+Z` 回到点击前选区；
3. 选择当前打印机耗材色后显式点击应用；
4. 放弃选择而不产生新 OBJ。

## 边界与兼容性

- 修改仅限 `VertexColorRegionEditor`、`ModelGenerationPanel`、模型生成测试和阶段文档。
- 不修改 Sidecar HTTP、Provider 上游、`MainFrame`、`Plater`、CMake、3MF、profile 或打印默认行为。
- 不读取或改写 Orca 全局耗材配置；目标色继续通过 `IPrintablePaletteProvider` 获取。
- 自然色模型、无顶点色模型或缺少色板时不显示/禁用快捷来源，不影响原有手动局部改色和模型预览。

## 验收

- 纯编辑器测试覆盖分离色块的全局选择、最近色映射、稳定平局、越界无副作用和选择快照恢复。
- Release 构建通过。
- 只用本目录 `build/src/Release/orca-slicer.exe` 验证：加载四色历史模型、展开编辑器、按角色选择、撤销、人工补减、应用颜色并重新加载。
- 工作树干净，所有改动追加提交，不通知集成线。
