# 自动修复失败兜底与模型库切片设计

## 目标

为 3D 生成结果补齐两个明确出口：自动网格修复失败时，用户可以将原始 OBJ 手动导入准备页；从模型库双击预览历史模型后，可以继续导入并切片。

## 安全边界

自动修复失败不能直接进入切片。失败后先撤销包含失败修复的首次导入，再显示“手动导入 / 取消”确认框。“手动导入”重新读取同一个本地 OBJ，复用当前项目的耗材颜色映射，但只进入准备页，不触发切片；用户可在准备页使用现有修复工具处理。取消时不导入模型，原 OBJ 和诊断文件继续保留在 `generated_models`。

## 模型库交互

模型库保持双击仅加载 3D 预览，避免浏览历史模型时产生不可逆的切片动作。历史模型预览成功后，主操作按钮显示“导入并切片”；点击后复用现有 OBJ 导入、保色、自动修复和切片门禁。新生成模型仍显示“确认并生成 G-code”。

## 回调与页面切换

生成面板的导入完成回调携带是否开始切片的布尔值。正常生成或模型库导入成功时更新准备页、触发当前打印板切片并切换到预览页；修复失败后的手动导入只更新准备页并切换到准备页。

## 验证

- 使用已保存的开放网格 OBJ 触发自动修复失败，确认出现“手动导入 / 取消”。
- 选择“手动导入”，确认模型进入准备页、未自动切片，颜色映射仍存在。
- 从模型库双击封闭彩色 OBJ，确认按钮显示“导入并切片”。
- 点击后确认进入 G-code 预览，模型颜色和切片结果正常。
- 完成 Windows Release 构建与 `git diff --check`，不创建新的付费 3D 任务。
