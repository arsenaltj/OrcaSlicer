# 模型生成盲测校准批报告

日期：2026-08-16  
清单：`model-generation-blind-pilot-v1`  
样本：4 个未参与提示词调优的文字输入

## 结论

当前链路已经能稳定把未知文字输入转换为严格动态四色、拓扑合法的高面数顶点色 OBJ；但还不能把“首次生成即可无需复核”作为承诺。4 个模型全部可继续导入 Orca，3 个结构直接通过、1 个因 5 个极小脱离组件建议复核；与此同时，4 个模型都被视觉复核识别出不同程度的语义偏差，人工盲评也全部给出 `review`。

最主要的产品缺口已经从“OBJ 没颜色、拓扑不可用”转移到“单张正面参考无法约束背面和侧面”。机器人和相机的背面出现了参考图没有充分定义的大结构；狐狸的指南针连接偏细；塔楼视觉最好，但有可清理的微小组件。

## 成本与恢复记录

- Image2：4 次。
- Tripo 生成：4 次，均为 30 万面档；没有重复生成。
- OBJ 转换：4 次，每个生成任务 1 次。
- AI 视觉复核：4 次。
- 每例都保留独立 `case-state.json`、远端任务 ID、原始包、最终 OBJ、结构报告、五视图、视觉报告和人工评分。
- 汇总：`generated_models/model-blind-benchmark-phase49/benchmark-summary.json` 与 `.csv`。

## 自动与人工一致性

- 自动结论：4 个 `review`、0 个 `pass`、0 个 `fail`。
- 人工结论：4 个 `review`。
- 三态精确一致率：4/4，100%。

该一致率只证明第一版复核能抓住本批明显问题，不代表统计泛化能力：样本量仅 4，且人工复核仍由同一轮工程验收完成。扩容时需要让其他同事独立评分，并在看自动结果前完成盲评。

## 已验证的产品假设

1. 动态四耗材色板有效。四例使用四组不同色板，最终 OBJ 均只有对应四种顶点色，没有色板外颜色。
2. 本地后处理和拓扑门禁稳定。四个约 26.6–29.7 万面模型都没有边界、非流形或退化面错误。
3. 稳定商品不强加底座的规则正确。相机自身可稳定落地，结构门禁直接通过。
4. 多视角视觉复核有实际价值。它发现了正面预览无法揭示的机器人背部圆盘、相机背部膨胀结构和细长连接风险。
5. `review` 比“只允许一个对象”更合理。塔楼的微小组件需要清理，但不应因此丢弃整个高质量模型。

## 尚未达成的目标

- 以“无需人工复核即可直接打印”为口径，3D 首次通过率本批为 0/4。
- 单视图输入对背面、侧面和遮挡区域约束不足。
- 仍没有真实耗材打印数据，无法证明细杆强度、支撑、换色成本和屏幕/耗材颜色一致性。
- 尚未在其他同事环境中完成独立盲评和批量 Orca 导入统计。

## 下一步

1. 优先验证多视图建模输入：让同一参考设计至少提供正面三分之四视图与背面/侧面一致视图，再送入支持多图约束的 3D 路径。
2. 给微小脱离组件增加安全清理预览和用户确认，不把它们与合法多部件模型混为一谈。
3. 修复背面一致性后先扩到 20 个校准样本；规则冻结后再扩到 50–100 个正式盲测。
4. 选择狐狸、相机和塔楼进入 Orca 做代表性导入，再选 10–20 个模型完成真实打印校准。
