# ADR-009：原生修复事实、接收策略与成果身份

状态：Accepted（内部契约）；完整官方差分、速度及实窗验收另行记录。

日期：2026-11-17

## 决定

固定官方来源为 `93941dc34e8a534ce3966a5979fe1edac002cb68`。原生菜单先按完整 ModelVolume 修复，在私有副本中提交；仅真实失败后进入旧分片兼容路径。工作台保留当前严格成功路径，失败时才从不可变原件使用原生修复。资源异常、取消和过期请求不进入算法重试。

`StrictMeshTopologyReport::safe()` 始终表示完整严格安全。原生兼容接收必须记录真实执行、源与输出的有序三角形坐标摘要，不能由单个布尔值授权。非法索引、非有限坐标、空成果及身份不匹配仍拒绝。交叠、自交谓词不可用和几何变化作为事实保存，不伪造零风险。保存、历史、编辑及导入共同消费同一证据读取器。

保持 v12 分区读取与算法身份。新增原生接收或颜色后备标识为 v13；拓扑凭证 v2 绑定实际输出，未知版本拒绝。原有历史外层格式不变。大缓存使用内容寻址分块版本，清单最后发布；块次序、摘要、范围和总量都验证，旧 v1 继续读取。

颜色后备只处理已接受几何的标签。优先复用色板及平滑前标签，其次确定性加权中位切分（最多32色），保存实际颜色数和色差。原生兼容输出不再执行颜色几何平滑。缺失纹理、容量和设备资源故障不伪装成几何失败，也不进入颜色后备。无色 OBJ 使用 Orca 默认灰材质；有声明但损坏的纹理不得替换成灰色。

每次调用的修复回调同时携带执行函数和“保留已修复几何”策略，复制、移动及赋值必须保留两者。显式处理可变左值的复制，防止继承的std::function转发构造／赋值递归包装或丢失策略；取消回调继续原样传递。该策略仅来自真实修复执行，不单独授予原生兼容凭证。

`ModelSurfaceSampler` 是模型层的共用外观采样实现，原 `ModelOriginalSurfaceSampler` 为兼容别名。未变化面使用有序角点，重合面稳定绑定，变化面仅投影到有效来源表面；检查修复的非顶点色产物使用面角点，避免共享顶点吞掉材质接缝。纹理与原件继续保留，不改变业务 Session 所有权。

临时处理块16MiB、额外暂存256MiB；原生不可分割网格与最终编辑数据另计。大模型不靠固定面数宣告修复失败，不压面或丢色。OBJ 展开成果写出、读回和预览采用相同容量规则，超预算明确报告资源阶段。

## 验证与限制

CGAL阶段诊断使用本次调用内的128事件定长缓冲，保留开始／结束、微秒偏移、阶段耗时和网格规模；缓冲满时提交再复用，返回、失败及取消时统一排空，不新增线程或持久缓存。阶段计时不含最后一次批量日志写入，调用方的严格修复总耗时仍包含它，不能把移动日志位置当作提速。日志接收端异常不参与几何接收；进程异常终止可能无法排出尚在内存中的事件。该取舍针对实测同步日志写入约9ms的阻塞，不修改修复、终检、颜色或取消语义。

聚类阶段同样使用调用内128事件缓冲，保持原诊断回调的立即执行、先后次序和值；固定K与自适应调用各自排空，嵌套调用仅在线程局部保存当前缓冲指针，不共享颜色状态。日志故障不抑制回调或改变颜色，最终输出仍计入外层颜色总耗时。缓冲满、取消及异常离开均提交已收集记录；该变更针对小模型聚类计算不足1ms、同步日志却达约9ms的实测阻塞，不改变聚类试验、浮点或线程策略。

严格修复汇总、外层色板／标签计时及平滑阶段的日志输出也隔离接收端异常；只捕获诊断表达式，算法、文件发布及资源错误仍沿原失败路径传播。正常输出顺序和计时边界保持。v18合并620次CPU测量中，低颜色样本的算法P95为16→17ms、CPU首次处理P95为17→19ms；用户明确接受这次1–2ms差异，作为该固定输入与数据集的局部验收决定保存，不修改原始比较、不推广为其他输入的默认容差。完整受理至有效首帧仍需单独验收。

编译、单元测试、官方算法差分、CPU配对、完整受理至有效首帧及用户视觉分别取证。CPU提速不能证明完整速度不退化。参考执行器按完整 ModelVolume 调用官方入口，独立于候选接收和颜色；源码及依赖闭包的实际一致性必须记录，不能称作未构建的独立官方二进制。

严格路径在颜色几何平滑后验证实际 float 输出：复用不可变投影树，仅遍历扩展包围盒，再对最终移动面及其可能相交面调用与完整 CGAL 检查一致的精确谓词；两个移动面只验证一次，保留共享边／顶点语义。失败恢复已验证几何和完整未平滑标签。不增加整网格 CGAL 检查或新的修复轮次，实际速度仍须配对验证。原生兼容路径保留官方已接受几何，不进入几何平滑。

聚类每个K试验可保留不超过16MiB的调用内精确距离与逐点有效位。仅当工作色集合不可变、中心三个double的位完全相同且当前线程通过既有默认浮点环境保护时复用；改变中心、非默认环境或超过工作区时重新走原距离公式。RGB、小工作集及超过64个中心保留原路径。原中心累加、空簇混合新旧中心搜索、相等时首选顺序、迭代上限、取消检查及半径检查不变；缓存不跨调用、K试验或输入，分配失败只放弃可选存储，不重试算法。新算法身份不冒用于未通过输出差分的结果，性能另行配对。

移动面终检可复用现有最多4线程的局部 arena；每批最多512面，只读最终坐标和已构建的不可变树。每面保留自己的诊断，批次结束后按原面序选择失败；树遍历及精确谓词保持原顺序。取消回调只在调用线程执行，批次前后检查；未提供 arena、单线程或少于256个移动面时保持串行路径。串行、并行及完整 CGAL 检查必须通过相同通用扰动对照，不能用并行化替代实际速度验证。

CGAL 修复始终对实际 float 输出执行完整自交终检。可选的 `FloatOutputValidation` 只在成功后由修复器写入有序几何摘要；调用者不能设置它的内部事实，失败或取消先清空。紧接着的严格接收继续独立检查所有拓扑，只在重新核对实际几何摘要完全相同时复用这次终检；不匹配或没有事实时执行原完整自交查询。该对象仅在本次调用内存在，不序列化、不授权原生兼容接收，也不改变 `safe()`；后续几何平滑仍接受实际移动面终检。

严格检查已经通过且私有副本完全未修改时，面积变化与双向偏差准确记为零，不重复面积扫描或最近表面查询。实际修改路径保留全部原采样点，独立距离查询在最多4线程的局部 arena 中计算，再按原顺序汇总；取消回调留在调用线程，分批检查。此优化不改变普通页面调度器或全局线程上限。

面积检查在预算允许时保留已经构造的精确三角形集合，每份采用不超过16MiB的保守节点／桶估算；更大的输入沿用原释放及距离查询。重复面去除、顶点焊接或面重排后，只有两份实际坐标集合逐项相等，才确认为同一几何表面并记录零偏差；哈希只索引，不能独立授权。独立拓扑终检及原顺序面积累计继续执行。任何新增补面、退化面移除或真实形变使集合不同，仍进行原双向采样。

后备色差诊断在单次调用内以完整源／目标RGB对复用标量CIEDE2000值；65536槽共1MiB，冲突仅淘汰，不近似、不改变面序累计，诊断关闭时不分配。面积去重哈希统一正负零，仍由实际坐标等值比较决定重复面。距离查询以2048个double为批缓冲，样本及提交顺序不变。终检在移动面足够密集且最终包围盒数组不超过16MiB时复用完全相同的包围盒，稀疏或更大的输入保持逐次计算，不改变树遍历或精确谓词。上述减少分配与重复计算的修改仍须逐样本性能对照，不能以逻辑等价推定速度通过。

`partition-build-report.total_ms` 在算法探针中只计构建算法，在生产交接中计对应交接范围，不能作为完整操作耗时。完整口径使用 `ORCASLICER_UI_LATENCY_TRACE` 的 `WorkbenchCheckUsable`：从受理（含后续排队）到控件可编辑且匹配的 GPU／导航首帧完成。`failed-or-canceled`、`asset-replaced`、`presentation-left` 等终态单独保留，不能纳入成功样本或作为更快的首修成绩。

CPU 安装不解除业务门禁。模型安装使用独立的首帧等待者，只有匹配模型、布局、尺寸、DPI 的完整 GPU 上传和导航帧提交成功才结束检查；不占用 Presenter、拉手或原 workflow 回调。等待期间重复消费者继续等待，新的配色选择暂不受理，已保存检查点不能提前放行。取消或呈现失败保留发布成果并异步恢复原画面及历史绑定；过期结果不恢复到其他资产。

发布前失败仅在当前会话保留已经完成的分区、不可变解码源及原始算法报告的共享所有权，不复制网格或新增持久化检查点。重试优先恢复正式发布的成果，否则重新核对源摘要并真实解码（包括OBJ外部材质和纹理），在后台逐项比较所有几何、面序、UV、材质、预计算色及纹理像素后复用完成分区。任何解码差异均拒绝，并要求重新打开，避免旧外观证据与新标签混用。比较按不超过16MiB的区间检查取消；资产、代次、编辑修订、页面代次变化或取消即失效。原始区域枚举成功事实始终保留，连续发布失败不把本次“跳过”阶段当作新的算法执行证据。新的尝试单独记录实际来源校验、解码和发布耗时，原修复事实不冒称本次重做；首次成功路径只共享已有所有权。

完整能力和速度双门禁未通过时，专项保持未完成。首轮官方参考受 Windows Nowide 环境变量缓冲覆盖影响，输入摘要前退出的结果无效；修正后必须重新构建取证，不能将其当作官方阴性样本。
