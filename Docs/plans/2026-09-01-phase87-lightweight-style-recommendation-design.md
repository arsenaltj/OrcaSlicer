# 阶段 87：轻量风格推荐设计

## 目标

用户选择原图后，在不增加隐式付费调用的前提下，为人像和非人像给出一个首选打印风格与两个备选。推荐只降低选择成本，不锁定风格，也不改变现有图片预览、3D 生成、历史恢复或付费确认边界。

## 风格集合

用户界面统一显示六种输出风格：手办、单色雕塑、低多边形、浮雕、写实微缩、微缩场景。内部继续兼容既有 `cartoon`、`sculpture`、`realistic` 和旧别名；新增的 `low_poly`、`relief`、`diorama` 使用独立提示策略。自定义风格仍作为第七个手动选项，不参与自动推荐。

## 推荐策略

推荐只由本地 Sidecar 执行。它综合用户文字、图片质量指标和低成本图像特征：

- 人像、宠物与动物优先手办，降低写实重建和毛发贴图缺失带来的不自然感。
- Logo、文字、透明效果和平面图形优先浮雕，避免猜测背面。
- 产品、车辆、机械和家具优先写实微缩，保留硬表面比例与部件。
- 建筑优先写实微缩或低多边形；多主体场景优先微缩场景。
- 图片明显模糊、主体碎裂或信息有限时优先低多边形。

语义关键词具有最高优先级；图片仅用于判断平面程度、颜色复杂度、边缘密度、主体连通性与构图复杂度。没有足够证据时使用手办这一通用稳健方案，并以低置信度原因提示，不宣称识别出了具体主体。

## 交互

现有“风格”下拉框保留，选项名称缩短。选择图片后，下方出现一张浅色推荐卡：

1. 第一行显示“推荐：手办”等主结论。
2. 第二行只显示一句推荐原因。
3. 第三行显示两个备选按钮。

分析完成后自动选中首选风格。如果用户已经手动选择，下发较晚的推荐只能更新卡片，不得覆盖用户选择。选择新图片会重新分析；移除图片会隐藏推荐卡。推荐失败时只显示一句“暂时无法推荐，可直接选择风格”，不弹窗、不阻断生成。

## 契约与兼容

新增本机原图推荐接口，返回 `primary`、两个 `alternatives`、`reason` 和 `confidence`，不创建任务、不持久化原图、不访问远端服务。Sidecar 协议版本提升，启动器会自动重启旧服务。旧任务中的风格字段继续按既有别名恢复；推荐结果不写入 3MF、打印机配置或耗材配置。

## 验收

- 人像、宠物、Logo、车辆、建筑、多主体场景和低质量输入都有确定性测试。
- 推荐接口在未配置 API Key 时仍可用，并确认没有 Image2/Tripo 调用。
- 风格手动覆盖不会被异步结果反选。
- 推荐卡在默认、加载、失败、清除图片和忙碌状态下布局稳定。
- Python 全量测试、Windows Release 构建、正式 GUI 视觉复验通过。
