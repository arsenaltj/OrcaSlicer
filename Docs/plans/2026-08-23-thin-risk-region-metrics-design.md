# 阶段 74：薄壁风险区导航指标设计

日期：2026-08-23

## 目标

在阶段 73 的逐处导航中显示当前薄壁风险区的量化依据，让用户知道该区域为什么排在当前顺序，以及应优先检查什么。

## 交互

1. 当前区域存在有效指标时，在 3D 预览提示和底部状态中显示最小实测厚度、采样数和采样面积。
2. 厚度和面积使用毫米单位并保留三位小数；样本数保持整数。
3. 报告字段缺失、非有限或不大于零时只省略对应指标，不阻断定位和导航。
4. 撤销到某个已报告风险区时同步显示该区指标；撤销到空选区或手动选区时不显示旧风险指标。
5. v7 平面证据定位继续沿用旧提示，因为该报告没有区域级指标。

## 边界

- 只消费阶段 72 已存在的 `thin_local_regions` 数据，不修改报告 schema、Provider 或 Sidecar。
- 不自动加厚、修复、加支撑或修改切片参数。
- 只修改 `ModelGenerationPanel` 和模型生成文档；不修改 MainFrame、Plater、CMake、3MF/profile。
