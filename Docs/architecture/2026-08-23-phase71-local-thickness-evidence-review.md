# 阶段 71：局部薄壁证据定位验收

日期：2026-08-23

## 结论

阶段 71 已把采样式局部薄壁结果接入模型生成 3D 预览。质量卡在报告包含有效证据时显示可用的“定位薄壁”按钮；点击后通过现有局部区域编辑器高亮采样命中的三角面，并支持手动增减、清空和撤销。

该功能只帮助用户复核风险和编辑选区，不修改网格、不自动加厚、不生成支撑，也不改变摆放或切片参数。

## 报告与 C++ 契约

- 报告 schema 保持 `1`，门禁版本提升为 `structural-v7`。
- 新 threshold `local_thickness_evidence_limit` 默认 256。
- 新可选字段 `evidence.thin_local_face_indices` 对应 OBJ 三角面的原始读取顺序；质量门只接受三角面，因此没有多边形三角化重排。
- 命中序号去重、升序并截断到上限；局部厚度样本统计仍保留完整命中数。
- C++ 客户端最多读取 256 个非负整数；旧报告、缺失字段、非数组内容和无效序号安全忽略。
- 纯 C++ `VertexColorRegionEditor::select_faces` 负责通用面序号选区，不依赖 wxWidgets 或 Orca 工作区；重复和越界序号被忽略，空/全无效证据不破坏当前选区。
