## 目标与范围

在当前 Windows 开发环境、现有人像和六个耗材条件下，降低脸部、衣服等区域的无意义碎色，保留五官、衣物边界和人物辨识度；比较连贯色块与 ImageMap 纹理打印，选择适合默认流程的方案。

- 沿用已有原始照片、AI 设计图、全彩模型与贴图，不重新付费生成模型。
- 默认仍在原生颜色匹配弹窗和美颜工作台完成，不增加独立页签或一批需要新手理解的参数。
- 原始模型、纹理、用户局部改色与已有工程均保留；清理产生派生结果，可以恢复。
- 每轮只改一个可解释因素，先软件对照，再打印小样。预览改善与实物改善分别记录。

## 固定实验条件

- 主样本：历史资产 `3f554ec4-1781-4843-b6c3-db0d895587d3`，约 94.9 万面；以实际源文件哈希确认，保持当前 100 mm 高度及朝向。
- 耗材初始参考：准备页六色 `#F7E2DA / #282629 / #F6F7F9 / #EA9A92 / #668CB6 / #958B86`。实验前读取实际工程确认，不把 HEX 当作实测色。
- 固定观察：正面、左右侧及背面；重点检查脸颊、眼睛、眉毛、嘴唇、衣领、袖口和衣服褶皱。
- 对照图分为无光照配色图与同一中性光照下的外观图；不把全彩原图与六色结果的逐像素差异作为唯一质量指标。
- 保留参考版本与独立实验工程，避免在用户未保存的当前工程上覆盖试验。
- 开始实物实验前确认真实打印机、喷嘴、工具号和六个实物耗材。先读取现有配置；缺失信息集中补齐。设备确认不阻塞离线分析与预览实验。

## 对照组

| 组别 | 输入与处理 | 要回答的问题 |
| --- | --- | --- |
| A：当前默认 | 原贴图 → 当前 12 组分色 → 六耗材 | 现有杂色的基线是什么？ |
| B：区域清理 | 原贴图与几何辅助分区 → 保边去杂色、保护细节 → 同六耗材 | 保持现有切片方式，能改善多少？ |
| C：ImageMap | 同一原模型、原贴图、六耗材 → ImageMap 的纹理打印方式 | 改变打印表达方式，本身能改善多少？ |
| C+：清理后 ImageMap（按需） | B 的连续清理纹理 → 同一 ImageMap 设置 | 源纹理清理与打印方式是否有叠加收益？ |

C+ 使用压成六个纯色之前的清理纹理，避免提前丢失渐变。A/B 不改变几何；C/C+ 记录外壁调制对尺寸与表面的影响。需要不同层高、线宽或摆放时，单列为工艺差异，不称为完全等条件对比。

## 阶段与验收

### 1. 建立基线，定位杂色来源

- 检查贴图/顶点色、UV、材质信息，区分原贴图已有斑点、光影被转成颜色、量化边界和耗材匹配偏差。
- 对齐照片和模型的可见区域；照片主要辅助识别衣服、皮肤与五官，背面和不一致区域保留模型信息。
- 保存 A 组固定视角截图、配色结果、打印配置与来源哈希；建立关键细节保护区域。
- 产出：一张标注问题位置的对照图、一份基线记录、用于后续实验的独立工程。
- 通过：能说明主要杂色在哪一步产生，后续版本可以用同一输入重现比较。对未证实原因明确标注推测。

### 2. 做出 B 组最小实验，优先得到可见改善

- 首先尝试保边去噪、基于表面邻接的区域合并，以及区域一致的耗材分配；以实际尺寸限制碎色，避免仅按三角面数量判断。
- 保护眼睛、眉毛、嘴唇、衣领等小而重要的区域；显式局部改色不被自动清理覆盖。
- 在 UV 接缝两侧检查连续性，避免贴图上相邻、模型上不相邻的区域互相污染。
- 阴影抑制作为单独对照因素；第一轮不把重型 AI 分割或本征分解设为必需依赖。只有简单方法确实无法区分的区域才评估更复杂方法与授权条件。
- 产出：A/B 同视角对照、可恢复的派生配色、处理耗时和变化区域统计。
- 通过：主要观察区域明显更干净；五官与衣物边界仍可辨认；几何、源文件和手工改色保持完整。未达到时先解释失败区域，不用全局加大模糊掩盖问题。

### 3. 独立试用 ImageMap，评估 C 组

- 固定上游版本，先在独立运行目录与配置中验证，避免直接合并整个分支。
- 从原始全彩模型导入，验证纹理保留、六耗材求解、侧面和倾斜表面的切片路径；单独检查顶部处理。
- 记录设备适配、层高、线宽、耗材透光参数、换料次数与预计打印时间。颜色求解器预测不视为实物标定结果。
- 产出：C 组切片/预览结果、最小小样工程、需移植模块与不兼容点清单。
- 通过：能为实际设备生成可检查的路径，并明确哪些表面适用；不要求此阶段先完成主工程集成。
- 如果原纹理杂色仍明显，增加 C+，沿用 C 的工艺设置，单独测量纹理清理收益。

### 4. 实物小样对照，决定技术路线

- 先做保留原曲率与最终比例的脸部、衣领/肩部小样；裁切保留 UV，新增切面不进入颜色评价。
- 使用同批六耗材、同一设备、相同观察光照与距离。先制作必要色样，记录真实材料色与适用的透光/叠层参数。
- 软件侧准备并检查工程、G-code 和操作说明，实际打印由用户配合完成；打印尚未执行时明确记为 NOT_RUN。
- 比较 A/B/C；C+ 只在能回答额外问题时加入。记录实际时间、耗材、换料、层纹与表面变化。
- 产出：同条件实物照片和简短结论，明确哪些收益是源颜色处理带来的，哪些来自打印方式。
- 通过：有实物证据支撑路线选择。局部小样通过后，再打印一个完整人像验证多角度和整体一致性。

### 5. 将胜出方案接入默认流程

- B 胜出：将稳定的区域清理设为默认处理，保留恢复原始配色能力。
- ImageMap 明显胜出：按已验证的表面和材料范围接入颜色求解、纹理保存及必要切片能力；不能只移植颜色预览并宣称获得同等打印效果。
- 两者互补：默认采用清理后的目标颜色，由验证合格的打印方式表现；避免新增用户需要手动串联的操作步骤。
- 完成受影响的导入/取消、局部改色、撤销重做、3MF 保存重开、切片和导出回归，再将其作为新的默认版本。
- 产出：可直接试用的 Windows 版本、最终同样本效果图、实际验证边界。

## 共同判据与决策规则

1. **干净程度**：记录非保护区的小色岛数量、实际面积和主要问题区域截图。阈值在基线阶段按喷嘴、模型尺寸确定并冻结，不能通过删除眼睛嘴唇来降低统计值。
2. **辨识度**：逐项检查五官、肤色连贯性、衣物边界；配色误差只作为辅助，不替代观察。
3. **打印可行性**：检查有效路径、细节是否落地、表面方向差异与外壁尺寸变化。
4. **使用成本**：记录预处理耗时、切片时间、换料次数、打印时长和耗材；在效果接近时优先采用成本更低、行为更稳定的方案。
5. **色域限制**：当前六色缺少原照片中的直接深绿色。所有组先用同六色比较；更换耗材只能作为后续单独实验，不能用换色掩盖算法差异。

不提前保证某种算法获胜。B 或 C 失败时保留失败样例和原因；每个最小实验产出可见结果后再决定下一项调整，避免同时改贴图、色板和切片参数而无法归因。
