# 阶段 59 架构复核：跨 OBJ 接缝的局部区域识别

日期：2026-08-20

## 结论

本阶段把局部区域识别从“只认共享顶点索引”扩展为“同时识别无歧义的几何边接缝”，仍完全位于模型生成独立选区模块内。实现不修改网格、OBJ、3MF、Orca 模型对象、打印配置或切片流程。

## 问题与方案

OBJ 导出器常在 UV 或材质接缝复制顶点。两个三角面在空间中连续，但共享边的顶点索引不同，原邻接表会把同一视觉区域拆断。

初始化现在保留原有索引边邻接，并额外执行以下只读分析：

1. 按模型对角线计算位置容差，并限制在 `1e-7` 至 `1e-4` 模型单位。
2. 使用空间网格把容差内的重复位置映射到同一临时顶点 ID。
3. 只收集原索引中使用一次的边界半边。
4. 只有恰好两个边界半边映射到同一几何边时才补充邻接；三面以上的歧义边不连接。
5. 区域扩展继续使用原有颜色距离和法线夹角门槛，几何邻接不会绕过边界判断。

临时映射只用于选区邻接，`m_mesh` 顶点和三角面索引保持原样。

## 兼容性与风险控制

- 原共享索引网格仍走原路径，邻接表最终排序去重。
- 有真实位置间隙的边不会连接。
- 同位置但颜色不同或法线锐变的面仍会被 `smart_region` 阻断。
- 同一几何边出现三个以上候选面时视为歧义，不猜测壳体关系。
- 补选和擦除仍使用既有局部半径与法线规则，没有引入 Provider、Sidecar 或 GUI 状态。
