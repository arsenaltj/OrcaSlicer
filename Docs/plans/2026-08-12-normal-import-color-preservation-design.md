# 正常导入颜色保真修复设计

## 问题

生成页的“正常导入（保留颜色）”与“使用可打印颜色”共用同一映射路径。两者都先通过温度兼容性筛选耗材槽；当筛选结果只剩一个槽位时，彩色 OBJ 的所有顶点都会被映射为同一种耗材颜色。界面仍显示“已保留并映射自然颜色”，与实际结果不符。

本次正式 OBJ 只有一个对象和一个组，但全部引用顶点都带 RGB。单对象不限制表面多色，不能通过拆对象替代颜色映射修复。

## 行为

- 正常导入：使用当前项目全部有效耗材颜色，将 OBJ 顶点色转换为 Orca 的 MMU 表面涂色。
- 使用可打印颜色：继续只使用温度兼容耗材槽，保持切片安全边界。
- 单色导入：继续显式忽略 OBJ 颜色。
- 如果源 OBJ 含多个顶点颜色，而正常导入最终只使用一个耗材颜色，则保留已导入模型并进入准备页，提示配置更多颜色或手动上色，不自动切片。

## 验收

- 正常导入与严格可打印模式使用不同的候选槽位集合。
- 映射结果记录候选槽位数和实际使用颜色数。
- 多色源不得在实际只使用一个颜色时显示“已保留颜色”。
- 单色导入和严格可打印颜色模式行为不回退。
- 使用已有真实 OBJ 验证，不创建新的图片或 Tripo 任务。
