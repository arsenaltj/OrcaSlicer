# 阶段 68：局部悬垂风险定位验收

日期：2026-08-23

## 结论

阶段 68 已把 `structural-v5` 的显著局部悬垂语义接入模型生成 3D 预览。用户可在质量卡点击“定位悬垂面”，直接高亮达到阈值的离床向下三角面，再旋转检查或通过既有局部区域工具手动增减、撤销和清空。

该能力只提供风险定位，不自动添加支撑、不改变模型摆放、打印参数或切片结果。只有用户随后明确应用局部颜色时才会写出新的 OBJ。

## 实现与一致性

- 纯 C++ `VertexColorRegionEditor` 新增 `OverhangRegionSettings` 和显著悬垂区域选择接口，无 wxWidgets、Orca 工作区或切片依赖。
- 默认规则与 Sidecar 一致：接地带 0.5 mm、离床向下面约 45°、连通区域面积至少 4 mm²、区域面积占总表面积至少 0.05%。
- 复用既有面邻接和 OBJ 几何接缝焊接，因此同一悬垂区域不会因 UV/材质重复顶点被无故切断。
- 退化面、接地底面和未达到绝对/相对面积阈值的噪声不进入选区。
- 找不到显著区域时返回 0 并保留已有选区；GUI 只显示安全提示，不展开编辑器。
- 定位成功时把原选区压入既有历史栈，橙色高亮结果并展开局部区域工具；撤销后模型提示同步恢复，避免残留“已高亮”旧状态。
