以下旧章节保留为最初 P0/P1 设计记录，不代表当前产品状态。当前共享页、原色/派生版本、直配应用及恢复已接通，R65 有实际 n12 主窗口及切片证据；3D 保守台账为 **3/20**，不按下方历史 0/20 重置。

`PrintColorTarget::recipe_proof` 使用 `PrintColorRecipeProof`，随已选择的两/三料候选保存完整材料和工艺输入、物理槽升序、已检查层高对应的子层厚度、颜色来源/SHA、不确定度以及绑定目标的校验和。`LocalPrintRecipeProofState` 与枚举共用 canonical context 和本地前向预测；恢复时重新检查候选 ID、材料/工艺、厚度/比例/Z/温度/尺寸限制、来源结构及预测输出。

证明范围固定为 `supplied-constraints-only`：层高数组是检查集合，不是模型实际层序；引用的校准 SHA 不是校准文件已被重新读取或测量真实性的认证。校验和检测内容变化，不是外部来源的身份认证。应用前仍须重新绑定实际材料、几何区域和原生切片能力；此扩展不授权含配方结果直接导入打印。

旧 direct 记录无新字段也可恢复；旧 recipe 预览缺证据时降为不可执行、待重算，旧 recipe 确认记录缺证据时拒绝，不能覆盖最后确认值。恢复 recipe 确认还要求当前计算结果存在同候选、同证据校验和且重新通过校验的条目，不能只凭历史记录恢复确认。当前共享页和应用器继续拒绝真正配方应用，原生事务/层序及真实六材料/实测校准仍待完成。本次验证以本机 `validation/20260915-six-color-r67` 的最终报告为准，代码接通不代替实际验收。

## 本次已实现的代码范围

- `AI/Contracts/LocalPrintColorResult.hpp`：独立的本地打印意图与结果。n 默认 6，支持 1–32；n 决定 direct/layered，实体槽仍限实际 1–6。旧提供商 `ColorIntent`、旧试色板六色上限不变。
- `GUI/AI/ModelGeneration/LocalPrintColorMatching.hpp`：显式供给面 RGB 和三维表面积，进行有保护的 Oklab 量化；直接分配复用已有 sRGB→CIELAB→CIEDE2000。最多枚举 720 次，对区域输出反差计算软代价或直接拒绝硬约束不合格的分配。
- 用户面改色、区域保护、显式物理槽锁参与量化之前的处理。同一槽锁区可包含多种原色；不同锁槽即使显示颜色相同仍保留独立组。锁区以真实输出色作固定分类中心，其原色不消耗自由量化预算；残差仍对锁区原始/显式改色后的代表色计算。
- 实体槽不足时在 k≤6 范围保留部分可行直配，优先已保护面积权重，再比较色差；余下目标标为 unresolved，不虚增槽位。无可行硬约束方案时返回未满足结果。
- `GUI/AI/Model/LocalPrintColorState.hpp`：JSON 版本记录编码和严格恢复。保留源 SHA、几何、父版本、实体材料/工艺指纹、n、面分组、区域/人物 ID、锁定、用户改色、反差约束、实验阈值、证据等级与确认状态。身份或算法版本过期、数据非法时不覆盖原有目标结果。

`source_color_count` 是调用方提供的原件信息，0 表示未知；算法另记 `sampled_source_color_count`（原始面样本按 8-bit RGB 统计），不把它冒充整张 UV 贴图的颜色数，也不因局部改色改写原件信息。

## 调用与接入

共享颜色匹配页提供不可变 `Input.identity` 和同一几何上的 `Input.faces`，设置目标 n、真实兼容实体槽、源/几何/材料/工艺身份、已有区域和用户改色。传入三维表面积，不用截图像素数或三角面数作为面积。遇到退化面当前明确要求先修复几何，不让零面积覆盖项消耗预算。

`compute()` 不操作文件、打印板、预设或提供商。调用方放到工作线程，使用 `cancelled` 回调，计算成功后再原子替换页面草稿。失败/取消保留原件与上次确认结果。无区域证据时结果明确标注只是统计匹配；人工/语义保护要求由调用方提供，算法不伪造人体分类。

页内调节后将阈值、反差约束和区域一并保留。重新计算时以当前页设置构造 `Input`；其中 tolerance、important_area_floor 应使用已保存设置。清空反差约束需同时清空 identity.contrasts，避免恢复旧约束。

`LocalPrintColorState::encode/decode` 只处理记录。宿主仍需实现文件原子保存、版本 ID、取消/撤销/重做事务和历史资产注册。恢复缓存时向 decode 提供当前源、几何、材料、工艺身份和匹配算法版本；不要只凭模型路径复用。合法 JSON 往返测试不等于程序历史恢复已经接通。

确认后，准备页需要直接消费 `face_targets` 和目标的实际槽/配方。面索引只对同一 `geometry_id` 有效；不能再聚类、重选颜色或重新弹一次旧匹配窗口。几何细分/修复后应失效或经过明确的面映射迁移。当前 `IModelArtifactConsumer` **尚未消费此结果**，不要把它塞进旧 `ModelColorTrial` 的六色向量冒充接通。

保护当前以每个供给区域的一个代表中心为基础，区域可以仍含多个目标色，但不保证所有内部次要颜色均被保护。重要细节应有独立子区域；完整多色语义保护属于后续 P2。默认 ΔE00=5 和面积权重下限 0.02 是实验参数，不代表实物达标。直接分配只用耗材显示色，证据标 estimated。

配方结构校验不等于工艺/物理校验。本轮不产生叠色候选，宿主不能凭一份外部 JSON 的 executable 字段执行叠色；P3 必须对材料与工艺重新验证候选，并保留测量/插值/估计/未知来源。
