# 3D 预览保持与持久模型库设计

## 目标

修复 3D 生成流程中的三个问题：生成 OBJ 的颜色在 3D 预览中稳定显示；切换页面或完成导入后仍保留当前 3D 预览；模型库跨软件重启展示 `generated_models` 中的真实历史模型，并支持双击加载到当前 3D 预览。

## 状态与数据边界

远程生成任务状态与当前显示状态分离。任务完成或服务端任务清理后，只清理任务 ID、轮询和导入状态，不清理 `displayed_model_path`、显示调色板或 OpenGL 网格。只有开始新任务、明确放弃或加载另一条历史记录时才替换当前显示。

模型库使用本地混合索引：新模型在 `generated_models/downloads` 写入同名 JSON 元数据；旧模型通过目录扫描兼容。扫描优先选择 `generated_models/<job-id>/model-vertex-color.obj`，没有规范产物时才使用 `downloads/orcaslicer-ai-<job-id>.obj`，并按任务 ID 去重。网格只在用户双击时解析，避免打开页面时加载全部 OBJ。

## 颜色行为

3D 预览直接从 OBJ 顶点色或面颜色构造颜色组。可打印颜色开启时使用当次耗材调色板；关闭时从 OBJ 自然颜色提取显示色，不把“单耗材打印”误解为“预览必须灰色”。导入到准备页时，可打印颜色开启才生成 MMU 涂色；关闭时仍按当前单耗材打印。

修正顶点色映射中跳过基色面的判断：仅当三点都属于对象的基色耗材时跳过，任一顶点属于其他耗材都必须生成 MMU 面颜色。

## 交互与错误处理

模型库按修改时间倒序展示全部有效历史 OBJ。双击卡片或卡片子控件后加载模型，切换到“3D 模型”页并更新三角面、尺寸和颜色统计，不自动导入、摆盘或切片。文件缺失、JSON 损坏或 OBJ 解析失败不会影响其他历史记录；失败信息显示在当前页面并保留原文件。

页面重新显示时刷新现有 OpenGL 画布，不重建网格。渲染前清理历史 OpenGL 错误并记录本次渲染的实际错误，避免把共享上下文中的旧错误误判为当前预览失败。

## 验证

- 扫描现有真实 `generated_models`，验证规范产物优先和下载副本去重。
- 双击自然色和彩色约束 OBJ，确认颜色、统计和页面切换。
- 在 3D 生成、准备、预览页面间往返，确认网格保持。
- 导入双色模型，确认非基色 MMU 面不再被错误跳过。
- Windows Release 单并发构建，并用实际软件完成回归。
