# 阶段 73：薄壁风险区逐处导航设计

日期：2026-08-23

## 目标

让用户在阶段 72 报告的多个薄壁风险区之间逐处复核，而不是只能查看第一处最高风险区或一次选中全部平面证据。

## 交互

1. v8 报告至少包含一个有证据面的风险区时，质量卡按钮初始显示“定位薄壁”。
2. 首次点击定位排序第一的最高风险区；当报告含多个可定位区域时，按钮改为“下一处薄壁”。
3. 后续每次点击按报告风险顺序前进，到最后一个报告区后循环回第一处。
4. 状态文字显示“第 N / 已报告区域数”，同时保留质量门识别到的完整区域总数，避免把最多 16 个报告区误解为全部区域。
5. 每次区域切换都通过 `VertexColorRegionEditor::select_faces` 替换选区并写入现有撤销历史；撤销可返回上一风险区，再次撤销可回到导航前选区。

## 生命周期与兼容性

- 加载其他模型、清空质量报告或开始重新检查时重置导航到第一处。
- v7 只有 `thin_local_face_indices` 时保持阶段 71 的一次性全证据定位，不显示“下一处”。
- v6/无证据、无顶点色或编辑器不可用时继续禁用。
- 不新增报告字段，不修改 Provider、Sidecar、网格或切片逻辑。

## 边界

只修改 `ModelGenerationPanel` 的模型生成 GUI 状态与文档。不修改 MainFrame、Plater、CMake、3MF/profile，也不调用付费 API。
