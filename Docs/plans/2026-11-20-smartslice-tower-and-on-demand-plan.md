**审批稿 · 2026-11-20**\
**任务编号**　`MAINLINE-BUGFIX-001`\
**范围**　Windows 工作台的擦料塔首次摆放、本地推荐按档计算、手工拖塔后的校验和切片。实施和验收在审批后开始。

## 1. 需求与审批项

| 顺序 | 需求 | 用户能验收的行为 |
| --- | --- | --- |
| 第一优先 | 修复历史多色模型刚进入切片页就报擦料塔越界 | 存在可用位置时，首屏的模型、塔位和原生校验结果一致，用户可以继续操作。确有越界、冲突或空间不足时显示具体原因。 |
| 第二优先 | 综合最优、速度优先、质量优先按选中档计算 | 首次进入只计算默认选中的综合档。点选其他档才产生该档参数和试切任务。回切到同一输入下已验证的档位直接显示结果。 |
| 同批完善 | 单纯拖动擦料塔 X/Y 时复用推荐工艺 | 松手后更新塔位合法性和切片状态。合法位置可以用原方案正式切片，正式结果使用用户刚设定的位置。 |

**待审批的默认规则**

- 首次打开本地推荐，默认选中的综合档自动计算。用户切换档位后，后台只处理最后选中的档位。
- 每档每轮通常执行一次完整原生试切。出现可修正的塔位冲突时，当前档最多补试一次。同一时刻最多一个原生试切任务。
- 仅拖动塔位后，精确预估标记「待更新」。用户选择重新分析可刷新当前档预估，也可以在新塔位校验通过后直接开始正式切片。

## 2. 软件开发方案

### 2.1 首次摆塔和原生校验

1. **热床准备完成后初始化塔位。** 检查开机、首次建盘和切换设备的执行顺序。`PartPlateList::reset_size()` 当前会触发默认塔位计算，而真实热床轮廓在之后写入。调整调用时机或延迟塔位落定，直到当前盘轮廓、局部原点和喷嘴可达区均就绪。空轮廓阶段视为等待摆盘输入，首次校验使用准备完成的盘状态。 [热床更新](../../src/slic3r/GUI/Plater.cpp#L15414) · [默认塔位](../../src/slic3r/GUI/PartPlate.cpp#L6263)
2. **导入完成时用最终配置检查塔位。** 历史模型及其耗材映射提交后、原生校验前，用当前盘有效工艺判断是否需要塔，并校验相应占地。统一使用盘内坐标。新建或本次生命周期内已知来源的自动塔位无效时，复用 Orca 的位置搜索逻辑。确认模型首层占地、扩边、禁打区和参与喷嘴的共同打印区都满足要求后，提交新位置。图形预览与原生校验读取同一坐标。 [导入提交](../../src/slic3r/GUI/PlaterUndoRedo.ipp#L390) · [有效配置](../../src/slic3r/GUI/PartPlate.cpp#L3918) · [原生位置搜索](../../src/libslic3r/Print.cpp#L5216)
3. **按塔位来源处理。** 有效的手工位置和已有工程位置按原值恢复。对无可靠来源记录的旧 3MF，将坐标视为工程已有位置。此类位置或本次手工位置校验失败时显示冲突，引导用户调整。合法位置随现有工程保存和撤销机制提交。自动摆塔只修改对应打印盘的塔位。
4. **用实际塔底做最终校验。** 导入预校验采用可信的塔底估算。实际切片生成塔底后，由引擎按完整多边形校验，包括旋转、扩边和塔型产生的实际轮廓。如果候选在估算时可摆放、生成实际塔底后发生冲突，只给符合条件的自动塔位一次同档补试机会。当前证据无法确认安全落点时，保留具体诊断并关闭打印资格。 [实际塔底校验](../../src/libslic3r/Print.cpp#L5873) · [原生试切诊断](../../src/slic3r/GUI/AI/Orca/OrcaTrialSliceExecutor.cpp#L867)

**阶段交付**　先完成首次摆塔相关用例。用原历史模型走真实入口及确定性夹具两条路径复验，确认导入预校验和正式实际塔底校验均成功。真正的空间冲突进入原生保护分支。SS-02-A 的同档预算在按档调度完成后联合复验。

### 2.2 按档计算和发布

| 阶段 | 软件行为 |
| --- | --- |
| 选档 | 同盘首次进入时选中综合档。点击档位立即更新选中状态。此前已经验证且输入一致的选中档从缓存返回。 |
| 推荐参数 | 几何特征可由同一模型共享。当前档独立取得层高、支撑、填充、墙数等参数，按对应目标和原有结构、工艺约束选择候选。已有可比的原生基线可用于排序。 |
| 试切 | 只把当前档候选交给原生试切。每轮至多提交两次尝试，包含早期被原生校验拒绝的尝试。第二次留给可修正的同档故障。原生成功结果提供预计打印时间、耗材和有效工艺。 |
| 切换和取消 | 用户切到未计算的档位时，旧任务退出后启动最后一个仍有效的选择。只接收与任务代次、档位、打印盘和输入匹配的结果。取消、超时和失败显示对应原因并可对当前档重试。 |
| 界面反馈 | 未计算显示「待计算」，参数已出且试切进行中显示「正在试切」。只有选中档完成验证才显示本档的已验证统计。相同工艺在同一原生输入下可以复用同一份有效统计。 |

将桌面入口接到现有推荐策略的单目标计算路径。`SmartSlicingFeatureHost` 调度当前目标，并移除本地入口的基线、质量和速度整组任务构造及三档批量回填。将已计算的几何和可比基线用于本档的轻量筛选。朝向对照由用户进入相应操作后按当前档验证，确认后随原生事务应用。每次尝试记录选中档、代次、打印盘、输入签名、开始结束时间和诊断。云端和移动端的三目标契约纳入兼容回归。 [本地轻量计算](../../src/slic3r/GUI/AI/SmartSlicing/SmartSlicingFeatureHost.cpp#L617) · [当前试切调度](../../src/slic3r/GUI/AI/SmartSlicing/SmartSlicingFeatureHost.cpp#L938) · [三档回填](../../src/slic3r/GUI/AI/SmartSlicing/SmartSlicingFeatureHost.cpp#L1104)

### 2.3 手动拖塔、预览和正式切片

1. **识别仅坐标变化。** 对比当前盘有效输入。差异仅在塔的 X/Y 时复用原推荐参数及已生成的层高曲线。模型或姿态、工艺、耗材、喷嘴等影响工艺的输入改变时，重新评估当前档。继续用完整工程版本约束试切和正式产物，防止旧估时、旧 G-code 或错误盘的结果仍被使用。 [塔位写入](../../src/slic3r/GUI/GLCanvas3D.cpp#L6622) · [完整版本计算](../../src/slic3r/GUI/AI/Orca/OrcaSmartSlicingAdapter.cpp#L806) · [当前版本刷新](../../src/slic3r/GUI/AI/SmartSlicing/SmartSlicingFeatureHost.cpp#L1465)
2. **松手后校验新位置。** 本次只有 X/Y 变化且塔底形状与当前工艺匹配时，可平移已验证轮廓进行快速校验。塔底证据不足时使用原生估算，或在用户发起的当前档试切、正式切片中重新取得实际塔底。新位置越界、落入禁打区或侵入首层占地时，提示具体原因并限制切片入口。连续拖动、撤销和重做走同一位置变更处理。
3. **保持工艺和新位置的一致性。** 当原推荐仍适用且新位置通过预校验，点击「开始切片」可直接采用此前验证的工艺和当前塔坐标。调整当前依赖完整试切版本的开始门禁，将该例的工艺凭证与新位置校验绑定。正式切片仍执行实际塔底和路径校验，之后才恢复「去打印」。未试切的新推荐仍走当前档验证。 [开始切片门禁](../../src/slic3r/GUI/AI/SmartSlicing/SmartSlicingFeatureHost.cpp#L2177) · [应用事务](../../src/slic3r/GUI/AI/SmartSlicing/SmartSlicingFeatureHost.cpp#L1711)
4. **回滚以手工移动后的工程为准。** 正式应用快照在用户拖塔动作完成后创建。失败或取消时，按工程、打印盘与事务身份回滚本次应用，恢复开始前的坐标和工艺。应用阶段从工程读取最新有效塔位，避免试切回填覆盖用户后来拖出的合法位置。 [失败回滚](../../src/slic3r/GUI/AI/SmartSlicing/SmartSlicingFeatureHost.cpp#L1800)

### 2.4 模块职责与实现顺序

| 模块 | 实现职责 |
| --- | --- |
| `PartPlate`、`Plater` 与导入事务 | 解析当前盘配置，提交合法的自动塔位或用户位置，维护工程、3MF 及撤销。 |
| `Print` 与擦料塔占地计算 | 提供可打印区、擦料塔位置能力、实际底面及原生路径校验。 |
| `SmartSlicingEngine` 与 `SmartSlicingFeatureHost` | 生成当前目标参数，调度当前档任务，按输入维护缓存、预算和异步结果。 |
| `OrcaSmartSlicingAdapter` 与 `OrcaTrialSliceExecutor` | 捕获当前盘的具体打印输入，在副本上执行验证并返回原生统计或诊断。 |
| `GLCanvas3D`、工作台侧栏 | 从同一当前盘状态显示塔位、选中档、预估状态和切片资格。 |

依次完成首次摆塔、按选中档调度、手工拖塔刷新。每阶段先跑本阶段定向测试，再用匹配的 Windows 运行版完成对应实窗用例。最终复跑受共同入口影响的原生切片、安全校验、撤销和保存重开用例。 [架构维护入口](../architecture/PLATFORM_ARCHITECTURE.md#开发时怎样用) · [Windows 验证入口](../coordination/quick-development.md)

## 3. 测试环境与样本

- 使用同一台 Windows 主机、隔离数据目录和匹配的 EXE、DLL、资源及 sidecar。从现场同源的现有历史资产导入模型，按现场机型、耗材映射和工艺复现。记录软件构建、模型指纹、打印盘、有效配置和塔位。现场自动备份的配置字段已留在证据中，实窗重点走从历史模型进入切片的入口。
- 使用 300×270 mm 多色边缘夹具、保存为 15° 的合法塔位工程、无空间夹具及双盘人工覆盖工程。对比按档结果时采用具有多色换料和缺支撑基线的肖像，再配合一个可快速跑完的平面件或悬空件。原工程和夹具的来源见原验收记录。 [现有样本和证据](2026-09-25-product-convergence-and-lightweight-plan.md#smartslice-case-results-20261120)
- 实窗记录选档、第一次显示参数、每次原生试切启动和结束、预估可用、正式切片完成。用时间戳、档位、尝试序号、是否补试、输入标识和结果归属对应截图。记录当前盘塔坐标、实际塔底、有效层高范围、支撑、原生预计用时和总克重。性能对照以同一输入多次取得的中位数为准，首个推荐和精确预估分别计时。
- 下列 24 项均待执行。用例编号沿用原 SS 项并追加字母，原 42 项状态对应原验收记录。真实导入、拖动和正式预览使用主窗口。确定性的预算、失效和回滚顺序可用定向测试验证。
