# 阶段 72：局部薄壁风险区聚类与排序设计

日期：2026-08-23

## 目标

阶段 71 已能高亮有上限的薄壁采样面，但真实高面数模型可能产生数百个分散命中。阶段 72 把命中整理为少量、可解释且按风险排序的局部区域，默认定位最高风险区域，降低一次高亮 256 个离散点造成的视觉噪声。

## 区域定义

1. 局部厚度采样器保留每个命中面的面序号和测得厚度；命中总量仍受既有采样总量上限约束。
2. 同为命中面的拓扑邻面直接归入同一区域，不受三角面大小影响。
3. 对高面数确定性抽样造成的间隔，面重心距离不超过 2.0 mm、且属于同一连通组件的命中面归入同一区域；使用固定网格邻域和并查集，避免二次方全量比较。
4. 区域风险排序依次使用：最小采样厚度升序、累计采样面积降序、代表面序号升序。
5. 每个区域的代表面是测得厚度最小、面序号最小的命中面。

2.0 mm 是局部风险展示的保守聚类半径，不参与是否产生薄壁 warning；它不会扩张选择到未经厚度命中的普通面。

## 有上限报告

- schema 保持 `1`，门禁版本提升为 `structural-v8`。
- 新 thresholds：`local_thickness_region_radius_mm=2.0`、`local_thickness_region_limit=16`、`local_thickness_region_face_limit=64`。
- 新 metrics：`thin_local_region_count`、`reported_thin_local_region_count`。
- 新 evidence：`thin_local_regions`，每项包含完整样本数、累计样本面积、最小厚度、代表面和有上限的命中面序号。
- 所有区域共享阶段 71 的 256 个唯一证据面总上限；优先为高风险区域分配，每区最多 64 面。既有 `thin_local_face_indices` 保留并包含相同证据集合，供旧 GUI 降级使用。

## GUI 行为

- 新报告有区域信息时，“定位薄壁”默认只选择排序第一的最高风险区域；状态文字同时显示该区选中面数和报告中的区域总数。
- 旧 `structural-v7` 平面证据仍选择全部已有证据；更旧报告无证据时继续禁用。
- 质量详情显示识别到的风险区数量和实际报告数量，明确它是采样聚类而不是切片级壁厚证明。

## 边界

只修改模型生成质量分析、模型生成 C++ 契约、模型生成 GUI、测试和文档。不修改网格、支撑、切片、MainFrame、Plater、CMake、3MF/profile，不调用 Provider。
