# 阶段 69：无顶点色 OBJ 预览兼容验收

日期：2026-08-23

## 结论

阶段 69 已修复合法无顶点色 OBJ 被模型生成 3D 预览错误拒绝的问题。模型现在以单一 ORCA 默认色正常渲染，可继续执行本地结构复检和原有导入流程；依赖完整顶点色的局部改色与悬垂定位保持关闭。

该修复没有放宽真实模型生成 Provider 的顶点色质量契约，只增强历史模型和兼容输入的安全预览。

## 根因与修复

- 底层 `load_obj` 原本即可解析无顶点色 OBJ，预览也已成功创建默认色 `GLModel`。
- 失败来自 `ModelPreview3D::load_model` 的末尾条件：缺少顶点色会清空已创建的渲染模型并返回失败，因为局部改色编辑器要求完整顶点色。
- 修复后渲染与局部编辑能力分别判定：有完整顶点色时初始化区域编辑器；没有时保留渲染模型并让区域编辑器保持不可用。
- GUI 通过 `region_editing_ready()` 控制局部改色面板和悬垂定位按钮，避免为无色、MTL 或纹理 OBJ 伪造顶点色并在保存时覆盖原材质。
