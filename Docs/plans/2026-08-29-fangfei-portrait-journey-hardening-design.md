# 方飞总多色写实：人脸、材质与软件旅程加固设计

## 问题定义

当前多色写实模型有两个不可接受的独立问题：一是脸部几何收敛成通用化的商业玩偶脸，与原照及较好的单色雕塑母版差距明显；二是白衣、绿色内搭、肤色和深色结构在不可见面形成随机碎斑。前者主要发生在 Image2 参考图和 Tripo 几何表达层，后者同时可能发生在二维耗材映射、Tripo 纹理补全和本地四色量化层。软件页面还必须让用户在一次清楚旅程中发现、修复或拒绝这些问题。

## 路线比较

1. 全局提高小色岛清理阈值：实现最简单，但真实测试已证明会把眼眉、眼睛、手表和内搭边缘当噪声删除，风险不可接受。
2. 不断重新生成直到看起来干净：无法复现、费用不可控，也不能保证背面材质归属正确。
3. 身份与颜色分层，再做肖像语义连通域修复和硬门禁：让 Image2 先把脸型和五官变成可读的雕塑几何线索，再赋予大块基础材质；模型输出只在证据充分的区域修复错色，剩余明显碎斑直接拒绝。这是本轮采用方案。

## 数据流

用户在 Release 软件中导入原照，选择“多色写实”。预处理提示首先冻结源图可见身份锚点、裁切、发型、交叉手臂和底座，生成允许轻微美化的写实肖像雕塑母版；颜色层只允许白西装、深绿内搭、自然肤色、深色头发/底座等连续部件色。图片结果同时保留细节丰富的生成参考和严格耗材预览。两者分别通过身份/结构检查和材料连通性检查后，才允许进入 3D 确认。

3D 返回后，质量流程先执行通用拓扑与可打印性检查，再在明确的真人写实证据和显式色板角色下执行肖像材质组件分析。底座、头发、脸颈、手腕、内搭和主衣料按几何连通、位置及邻接关系识别；只修复远离合法主体组件且被主衣料包围的错误色岛。修复后若衣服仍存在明显肤色/强调色污染，状态为 reject，界面禁止一键导入并给出重新生成或手动检查入口。

## 页面与状态

页面保留一个主流程：原图与描述、三种预设/自定义风格、耗材色、图片结果、生成 3D。首屏始终显示当前选择摘要和唯一主按钮；高级说明、技术指标和历史记录折叠到次级区域。图片生成显示稳定的阶段文案和可恢复状态；3D 确认明确展示费用语义、预计时间、远端取消含义与质量档。质量拒绝必须说明具体部位与下一步，不允许用笼统“请检查模型”替代。

## 验收

- 新生成图片从 Release 软件真实入口触发，逐张与原照、上一轮单色雕塑和当前多色模型同屏比较。
- 白袖从肩到袖口连续，肤色不进入衣身、袖管或底座；模型背面没有肉眼可见的绿/肤/深色随机碎斑，否则硬拒绝。
- 人脸至少保持原照的长椭圆脸、眼距与眼型方向、鼻翼/鼻尖、开放笑容、盘发、露耳和开放下颌；轻微美化不改变这些锚点。
- 真实 Release 旅程覆盖正常、失败、恢复、质量拒绝、导入和历史路径，主按钮在常用窗口高度下无需猜测或寻找。
- 针对性测试、完整 AI 回归和 Windows Release 构建通过；不创建未经授权的额外 Tripo 任务。
