### 3.2 保证可比

- 每个模型记录原始 GLB/OBJ、纹理/材质、SHA-256、几何身份、尺寸/单位/朝向、来源以及分组。
- 同一模型所有方法使用相同源模型、耗材/配方快照、相机、光照、视口和输出分辨率。耗材不必在不同模型间相同，但一个模型的各候选必须一致。

- 额外推理视角计入时间与预算；相近角度或同视角裁剪不作为额外独立证据重复加权。
- 识别用中性显示的原始纹理，并可附深度/法线；不要从已匹配耗材或黄线覆盖后的图像识别。
- 用户历史参考照片用于核对颜色/五官和身份；照片与生成模型的对应未经验证时，不直接把照片掩码投到三维上。

**要回答：目前哪里错、慢在哪里，新方案和谁比较？**

工作：
1. 记录相关源码/运行环境身份，保留现有修改和正在运行的程序；不清理工作区，不要求先提交或制作新安装包。

通过条件：满足下节保留集门槛。普通物品失败时可以仅交付经验证的人像能力，必须明确适用范围；不能宣称通用物品已支持良好。若只有开发集进步，回到失败分析，不接入默认产品路径。

### P4：接入现有工作台，保证结果可用、可恢复

**要回答：算法收益能否变成顺畅的实际操作？**

工作：
1. 接入同一个 3D 美颜工作台。先匹配现有耗材再编辑；保留原图对照、直接拖边界、快捷隐藏黄线和更多操作，不增加算法选择菜单。
2. 默认显示简洁编辑块，选中五官时仍能调用细部约束。语义分析记录与编辑块各自持久化、各自校验来源。
3. 分别缓存渲染/识别、分区、配色。相同模型和识别配置复用结果；更换耗材仅使相关配色失效，不重新运行视觉模型。
4. 新算法版本不能静默迁移用户手动区域。需要重新分析时生成新结果，原版本可恢复；用户在粗结果上已开始编辑后，晚到的后台识别也不能覆盖这些修改，需检查编辑版本再应用。
5. 保持运行时可取消，缺依赖、超时、损坏缓存、身份不匹配时明确回退；未知区域仍可手工编辑。
6. 若需新增字段/类型，核对架构约束及全部证据消费者；严格版本校验，不把新契约硬塞进旧 schema。外部模型的权重/许可证和运行依赖在产品接入前核对。

交付：增量编译的开发版、实际主窗口操作证据、受影响测试结果；不自动制作安装包。

通过条件：点选/改色/拖边界/撤销/重做/保存/重开都正确；旧版本可恢复；再次进入不重复推理。实际 UI 操作通过后才称为工作台接入完成。

### P5：准备页与文件交接验收

**要回答：用户修改后的颜色能否正确进入原生打印流程？**

工作：
1. 至少覆盖两张历史照片模型和两个未见人像；从原模型进入工作台、修改、保存新版本、导入准备页。
2. 对比原始全彩、工作台匹配后、准备页三个阶段；逐面核对导入前后的最终耗材/叠色配方。取消导入不影响原准备页。
3. 保存 Orca 项目 3MF 并重开，检查最终打印颜色/耗材映射；完整美颜编辑记录从模型库 GLB＋JSON 恢复，不承诺任意 3MF 携带所有编辑历史。
4. 用已知实际设备配置试切代表模型，检查颜色分配与预览。切片成功不能替代实物色差、表面或强度验证。

交付：真实 GUI 全流程记录、3MF 往返与试切证据、剩余限制清单。

通过条件：交接颜色无变化、保存/恢复无丢失、无静默替换耗材。需要阶段安装包时再进入已有内部打包流程。

## 5. 验收指标与选择规则

以下数字是建议的工程目标，不是已经测得的成绩，也不代表统计意义上的泛化证明。P0 根据基线记录适用项；一旦候选开始调参，就不能为了让结果通过而事后放宽指标。

| 维度 | 如何测量 | 建议通过条件 |
|---|---|---|
| 关键错误 | 固定观察点：眼珠/眼白/唇线、发际、头发与皮肤、衣服与皮肤、衣服与底座 | 相对基线不新增关键错误；新方案不得靠吞掉五官消除碎区 |
| 分区完整性 | 预先标注的连续同材质、同目标色大面 | 同块覆盖其可见标注面积 ≥95%；真实图案、断开部分和不确定边缘另列 |
| 不必要边界 | 固定标注的大面内部多余边界长度，按表面尺度归一化 | 开发集各样本中位数降低 ≥30%；不是比较全模型黄线总数 |
| 未见人像 | H 集逐模型同条件检查 | 至少 3/4 改善，剩余样本无明显退化，全部无新增关键错误；4 个样本只是初步证据 |
| 手工修正负担 | 同一操作者完成同样任务，记录修正次数和用时；比较时交替顺序 | 中位修正次数或用时降低 ≥30%，另一项不明显增加；只做离线图时此项记未测 |
| 识别质量 | 预先人工标注的关键区域、侵入和漏识别；未知单列 | 分别报告皮肤/衣服等大面和五官，避免用衣服面积掩盖眼睛错误 |
| 颜色保真 | 每方法的原纹理/匹配后对照；导入与保存前后逐面检查 | 分区实验不顺带调配色参数；若重分区改变取色，变化单列、重点检查肤色/眼唇；交接过程变化必须为 0 |
| 首次体验 | 固定设备记录冷启动与首次分析的完整耗时 | 默认路径中位时间不超过 A 的 1.2 倍；首个可操作粗结果目标 ≤15 秒，细化异步完成 |
| 重开与资源 | 已有资产缓存重开、取消和内存/显存峰值 | 重开不重复推理；重开目标 ≤5 秒，取消响应目标 ≤2 秒；不能 OOM 或阻塞主界面 |

如果当前加载本身超过交互目标，拆分记录瓶颈并优先修复加载/缓存，不把推理缓存命中当成整个工作台已达到目标。更大模型若只在 GPU 上通过，报告适用硬件；CPU 回退单独验收。

均匀背部衣服的拼图数、面积覆盖和错误边界一起判断。识别正确但配色不佳时，进入独立的区域取色/耗材优化任务，保持本次分区方案不变；不能用强制统一肤色掩盖错误。

- [打印与颜色边界](../domain/printing-color-boundaries.md)：屏幕颜色、耗材编号、原生配方、切片和实际打印分层验证。
