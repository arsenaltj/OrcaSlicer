# 切片工作台需求文档

主线 `MAINLINE-BUGFIX-001` · 2026-11-20 · 需求已确认

用户可以在同一个 Windows 切片工作台中，选择智能推荐或自己设定工艺。两种方式各自维护参数，共用当前打印盘、切片操作、预览和打印入口。同一工程通过 3MF 保存两套工艺，重开后可分别继续使用。

## 交付范围

| 阶段 | 交付内容 |
| --- | --- |
| 首批 | 在工作台集成「自定义切片」，支持两套工艺独立切换和 3MF 保存恢复，共用正式切片与打印交接。同步修复智能三档连续换档串工艺、自动擦料塔失去自动重摆资格。 |
| 后续修复 | 多盘缓存按实际依赖隔离，按 REQ-08 验收。 |
| 已登记优化 | 档位收益对照、窄盘求位和重复试切开销继续按实测收益排期。采用现有主计划记录。 |

自定义切片提供工程级全局工艺编辑。盘、对象、零件和分层的独立编辑入口列入后续扩展。打印机发现、设备选择和发送确认由现有打印页面承接。 [主计划的修复顺序与需求确认](2026-09-25-product-convergence-and-lightweight-plan.md#smartslice-next-fixes-review-20261120)

## REQ-01 工作台内切换标签

- 当前切片页面提供「智能切片」和「自定义切片」两个标签。原「Orca 原生」入口改为「自定义切片」，点击后在当前页面显示相应的左侧工艺内容。
- 切换时使用同一个工程、打印盘、模型和画布。用户通过共用的「开始切片」触发正式切片。进度、取消、G-code 预览、用时、耗材统计和「去打印」均在这套工作台流程中呈现。
- 自定义控件使用工作台现有主题。页签、输入框、下拉及其弹出列表、参数搜索、滚动条、字号、分组间距和选中、悬停、禁用、错误状态与当前窗口一致。表单在常规宽度、窄侧栏和 Windows 高 DPI 下可阅读、滚动和操作。

## REQ-02 自定义切片的工艺编辑

- 提供原生的「简单设置」「高级设置」「专家设置」。首次进入默认「简单设置」。较高挡位显示更多可编辑项。切换显示挡位保留已选预设及已编辑的参数。
- 工艺预设下拉按当前工程的机型和喷嘴规格列出兼容预设。选择预设会载入整套工艺。例如 `0.12mm Draft @WonderMaker ZR Ultra 0.2 nozzle` 中的 `0.12mm` 是工艺名义层高，`0.2 nozzle` 是适配的喷嘴规格。喷嘴以工程中已选的设备配置为准。 [本地预设定义](../../resources/profiles/WonderMaker/process/fdm_process_wm_0.12_nozzle_0.2.json#L7)
- 提供原生质量、强度、速度、支撑、多材料和其他参数，以及原生的参数联动、范围和兼容性校验。工艺预设下拉旁只提供参数搜索，支持搜索和定位原生参数。本工程的自定义修改通过「保存工程（3MF）」保存。
- 全局工艺作用于本工程中继承该工艺的盘和对象。工程中已有的人工盘级、对象、零件和分层覆盖按原生优先级生效。切片摘要应能区分所选工艺和当前盘实际采用的层高或范围，涉及覆盖时标明来源。

## REQ-03 智能与自定义工艺独立

- 自定义切片保留用户在该标签选择的预设和修改值。智能切片使用独立的兼容工艺基线和推荐档位。往返切换时各自恢复自己的选择和参数。用户从某个标签点击「开始切片」时，采用该标签的工艺。
- 模型、打印盘、机型、喷嘴和耗材属于同一工程，为两套工艺提供实际输入与兼容条件。共享输入变化按其实际影响重新校验。两套工艺各自保留参数来源，工程原有的人工覆盖按 REQ-02 生效。
- 智能产生的盘级工艺或自动变层高属于对应智能方案。下一次自定义正式切片使用自定义工艺与真实的人工覆盖。例如，无局部层高覆盖的模型先以智能质量档 `0.12 mm` 出片，再切到自定义 `0.20 mm` 出片，自定义的名义层高及生成层序应对应 `0.20 mm`。反向切换亦按各自工艺切片。

## REQ-04 智能三档切换与试切

- 「综合最优」「速度优先」「质量优先」从同一份智能工艺基线出发。前一档由程序应用的层高、变层高曲线、壁数、填充率、外壁速度及支撑工艺按其来源处理。后选档采用自己的建议，已有人工层高与支撑覆盖继续按工程约束生效。
- 在模型、摆放、设备、耗材和用户工艺相同的条件下，正式切完一档再切换，后选档的有效工艺与直接选择该档一致。验收覆盖双向换档及保存重开，重点核对已生成智能变层高曲线后切到速度档的实际层序。
- 共享模型分析就绪后三档显示建议层高。完整试切按选中档执行，自动塔位补试遵循现有规则。智能正式切片要求当前盘、所选档、有效输入相匹配的试切证据。仅移动塔位时，按现行位置复核规则判断能否复用已验证工艺。
- 试切结果和错误归属到实际的盘、档及输入。换档、换盘和输入变更后，只接受匹配的结果。失败、取消和超时显示对应状态，切片资格按当前有效证据判断。

## REQ-05 正式结果和打印交接

- 自定义切片按现有原生工艺与打印盘规则校验。智能切片按 REQ-04 校验所选档。两种方式通过共用的正式切片流程生成 G-code，并在当前工作台展示对应的预览和统计。建议层高、试切预估与正式统计按实际数据来源显示。
- 只浏览标签时可查看最近一次有效的正式预览，并标明出片来源。当前盘和当前生效工艺匹配的有效正式结果才具备打印资格。工艺或摆盘发生有效变更时，采用重新验证后与当前输入匹配的结果。
- 切片期间由共用进度和取消入口处理。一次应用失败或取消时，恢复该次应用前的工程工艺及塔位状态，保留用户已确认的编辑。失败结果显示具体原因，未通过校验或过期的结果按现有打印门槛处理。
- 两个标签的「去打印」都进入现有打印页面。打印机发现、选择与发送确认在打印页面进行。

## REQ-06 3MF 保存并恢复两套工艺

- 从任一标签执行「保存工程（3MF）」时，保存自定义页所选预设及用户修改值，同时保存智能页已应用的工艺。智能工艺包含恢复已应用方案及正确区分人工覆盖所需的信息，包括已应用的层高曲线及其来源。自动塔位来源按 REQ-07 保存。
- 重开同一工程后，两个标签分别恢复对应工艺。例如，自定义使用 `0.20 mm`，智能已应用 `0.12 mm`，从智能标签保存并重开后，自定义仍为 `0.20 mm`，智能仍保留已应用的 `0.12 mm`。从自定义标签保存时同样可恢复两套工艺。
- 工艺恢复后，智能试切资格和正式结果的打印资格按当前盘及有效输入重新核验。现有 3MF 按原生规则读入，保留其中已有的工艺、人工覆盖和塔坐标。

## REQ-07 自动擦料塔的来源和重摆

- 系统生成的塔位在应用方案、正式切片、换档和新 3MF 保存重开后仍可识别为自动塔位。本次正式切片使用已校验的塔坐标。后续智能三档或自定义工艺的有效输入变化时，按对应工艺重新校验。
- 自动塔位发生冲突时尝试重摆。找到并通过原生校验的落点后使用新位置。以实际塔底为出片校验依据，覆盖扩边和旋转后的轮廓、真实可打印区域、喷嘴共同可达区、禁打区以及相关首层占位。无法验证合法落点时，显示当前冲突或求位结果，并限制该结果进入打印流程。
- 用户手工定位的坐标及旋转继续按工程设置处理。手工位置发生冲突时提示用户调整。缺少可靠来源的旧 3MF 坐标按已有固定塔位读入。取消、失败、撤销与重做恢复对应的坐标和来源。
- 保留按选中智能档执行的试切预算。首次尝试可按估算修正自动塔位，实际塔底确定后至多进行一次完整补试。

## REQ-08 后续修复多盘缓存隔离

修改第 2 盘独有对象后返回第 1 盘，第 1 盘输入仍有效时复用其工艺证据、正式统计和打印资格，新增完整试切次数为零。改变两盘实际使用的共享配置时，按相应依赖重新校验。沿用原 SS-06-A 的盘级验证口径。 [既有多盘验收](2026-11-20-smartslice-tower-and-on-demand-plan.md)

## 已登记优化

- 档位收益用匹配当前输入的原工艺数据作对照。优先验证速度档实际用时，原工艺更快且通过安全校验时推荐沿用原工艺。记录各档的时间、耗材和层序。表面质量与拆支撑另按实物验收。
- 窄盘求位用有合法落点和确实放不下的样本作对照。区分固定位置冲突、搜索未得到可验证落点和已确认的空间不足。
- 等待时间用同机轻件和重多色件对照，分别记录三档建议出现及所选档可开切的时间。复用已验证且仍匹配的结果，记录完整试切次数。

## 首批可验收场景

| 对应需求 | 操作 | 通过条件 |
| --- | --- | --- |
| REQ-01、REQ-02 | 在 Windows 工作台切换两个标签，检查常规宽度、窄侧栏和高 DPI。从自定义首次进入开始切简单、高级、专家，再切回简单。 | 始终使用当前工作台及画布。默认简单，逐级出现相应的原生可编辑参数。已编辑的值保留，控件和弹出列表可读、可操作。 |
| REQ-02 | 使用适配 `0.2 mm` 喷嘴的预设样本，切换 `0.10 mm Standard`、`0.12 mm Draft`，通过搜索定位一个参数。 | 下拉列出匹配设备的工艺预设。载入的名义层高与所选预设一致。喷嘴规格仍由工程设备决定。下拉框旁只有参数搜索入口。 |
| REQ-02、REQ-03 | 打开带人工盘级、对象级或层范围覆盖的 3MF，修改自定义全局层高后切片。 | 继承全局工艺的对象采用新设置。已有覆盖的对象按原生优先级取值。切片摘要和实际层序能核对到有效配置。 |
| REQ-03、REQ-05 | 同一无局部层高覆盖模型以自定义 `0.20 mm` 和智能质量 `0.12 mm` 分别正式出片，双向切换。 | 两套预设和修改值各自恢复。名义层高、实际层序和统计对应发起切片的模式。有效工艺及正式产物匹配后，「去打印」统一进入现有打印页。 |
| REQ-04 | 选用适合自适应层高的模型，比较直接按速度档切片和先正式切质量档再切速度档。再检查反向及重开后的切换。 | 相同输入下，后选档的层高曲线、壁数、填充率及其他有效工艺与直接选择一致。当前档自己的试切结果决定其切片资格。 |
| REQ-04、REQ-05 | 在工作台触发试切失败、取消或超时，另对正式切片触发取消或输出失败。随后修正条件重试。 | 显示对应任务和错误，失败或过期结果的打印入口禁用。取消及失败恢复应用前状态。取得与当前输入匹配的有效正式结果后恢复打印资格。 |
| REQ-06 | 为同一工程配置不同的智能和自定义工艺，从两个标签分别保存 3MF，再重开并切换。 | 两套工艺分别恢复。自定义预设及其项目修改值、已经应用的智能工艺和层高曲线来源可核对。重新切片的实际层序和统计对应所选工艺。 |
| REQ-07 | 在有可重摆位置的多色盘正式切片，双向换档并重开 3MF。另验手工固定塔位和确实放不下塔的摆盘。 | 自动塔位保留来源，校验后可按新工艺重摆，正式结果的实际塔底合法。合法手工塔位和旋转保持。空间不足或手工位置冲突时给出原因，相关结果不可打印。 |

Windows 实窗验收以实际模型、打印盘、G-code 层序、塔坐标及轮廓、正式统计和打印资格为依据。编译、定向测试、实窗和实物结果分别记录。原故障 3MF 与实物质量沿 SS-01、SS-36 补验。后续实施方案按本文件编号列出改动范围与验收映射。 [既有验收及待取证项](2026-09-25-product-convergence-and-lightweight-plan.md#smartslice-case-results-20261120)
