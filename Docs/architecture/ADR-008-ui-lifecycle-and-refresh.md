# ADR-008：页面生命周期、后台任务交接与刷新统一

状态：Accepted（架构决定）；实机性能及完整功能验收按既有主计划分别记录。

日期：2026-11-12

## 背景

wxWidgets 页面常驻复用，但路由、共享控件挂载、主线程布局与 GL 首帧由多个回调交叉处理。历史栏、最小化恢复、完整旧页过渡及异步生成的故障说明，仅增加 Refresh／Update 或 Freeze 不能控制所有权和时序。智能／高级生成仍需独立业务会话，全应用必须只有一个编辑工作台和一个共用 3D 进度／结果页。

## 决定

1. Shell 组合、PageCoordinator 唯一持有页面与过渡状态；保留页面适配器以 prepare／apply_snapshot／presented／hidden／dispose 接入。wx parent 管窗口、Sizer 管布局，共享跨宿主控件使用可验证代次的挂载租约。
2. 生成／编辑／账号／发布的业务真值留在既有 Session／Application；TaskContext 只管理执行身份与取消，不构造第二业务状态机。业务接受与可见展示分别校验。
3. GUI 控件及 GL/WebView 提交仅在主线程；重处理返回数据快照。有界 TaskRunner 适配新迁移工作，原 HTTP、历史 Worker、切片及语义执行器保留原能力，逐一接退出排空，不全量重写。
4. RefreshScheduler 合并同轮 dirty，固定快照、显隐挂载、布局、浮层、绘制和呈现确认顺序。隐藏保留 dirty，同尺寸恢复也重新呈现；普通路径不递归 Update、不用 Yield 或 GUI 等待掩盖阻塞。
5. 模型 CPU 数据与严格凭证在后台准备，GL 分批上传后才允许完整帧；页面和模型／布局／尺寸／DPI 变化使旧通知失效。15 秒、取消、回滚、最小化暂停和有效凭证零重复修复保留。
6. 正常退出先失效展示，保留 owner 至后台和 GUI 回调全部排空，再释放控件／GL；不使用 detach、强杀或提前销毁服务。原事务发布边界不可被取消清理改写。
7. 后续 UX 必须遵守平台架构的宿主、快照、线程、资源、dirty、浮层、首帧和异常清单；不增加整页定时刷新或第二工作台／3D 页。

## 影响与验收

新 orca_ui_runtime 是执行／展示基础设施，既有 native kernel 和业务 API 不变。保留 C++17、wxWidgets、现有 GL 双缓冲、HTML 消息桥和持久化。迁移保持增量编译与消费者回归；基础测试只能证明身份、合并及排空契约，不能证明主窗口效果。CPU／GPU 不可切分调用与未迁移老执行器显式记录，不通过增大统计口径放宽性能门槛。

取消令牌在适配入口统一建立，排空任务始终执行；生产者队列同时约束待执行任务和待交接结果。历史及耗材验证的完整摘要在后台完成，短期文件读租约只保持到安装，不作为持久化凭证或预览长期状态。

满队列拒绝必须在移除任何旧请求之前完成；被替换请求的取消交接不能丢失。普通请求先停止受理，shutdown hook 仅可通过专用 finalizer 提交最后的事务快照；该窄入口允许既有 owner 的末次保存排空，不能用于创建新业务。裁切草稿按资产串行保存／清理，只合并显式可替换的快照；原格式不变，关闭及页面销毁不能取消已经冻结的末次保存。完成后的 scope 及时释放。

模型加载中的手工颜色覆盖与法线在后台准备，GUI 只安装冻结几何；覆盖模型同样参与分批上传和完整首帧门控。额外法线存储计入原 384MiB 预览缓存预算，不以扩大缓存换取验收通过。

撤销／重做和放弃候选采用异步准备、原有原子提交两步。历史记录只有在验证和安装成功后才移动或清理；失败、取消、重复完成、会话替换和销毁不得提前释放候选或推进时间线。业务取消使结果无效，仍由原请求在排空时释放忙碌门禁；不能将“任务已受理”作为同步恢复成功。切片页本地工具保留原生工程保护与单次 Undo 提交，执行结果由任务适配器交回，不再通过 future 轮询等待。

异常回滚、套装／耗材配置和候选接受中的逐面重匹配使用同一后台准备与GUI原子提交边界。配置变化或准备失败时必须有原有反馈并撤销失效的美颜进入意图。兼容导入入口复用原生异步事务，不保留第二套同步解析流程。挂载租约不可复制，避免栈顶所有者指针随对象复制失效；原生父窗口销毁或Sizer替换需以真实隐藏wx控件回归。普通结果及替换取消回调不能无界积压，测试应覆盖消费者停止交接及恢复排空。

功能、编译、自动、真实窗口、视觉和打印分别取证；既有四项预算及几何差异不因本决定豁免。源码锚点、所有权、线程矩阵、刷新和关闭时序见 [平台架构](PLATFORM_ARCHITECTURE.md#页面生命周期后台任务与刷新2026-11-12)，实施进度继续使用原主计划。

原生切片展示复用 Shell 的同一调度器，以 dirty 保存隐藏快照；进度浮层不重复运行完整状态布局，导航改变后不得继续提交旧页面。原生完成后解除资源暂停不依赖页面可见。只读网格快照复用原生 shared_ptr，不复制编辑会话。无 Windows 等价读锁的平台保留交接时的完整摘要校验，禁止仅凭大小／时间接受凭证；此回退及原生最终几何校验的性能分别保留待验，不能宣称所有主线程成本已消除。

回归补修明确两条交接约束：历史解析／修复重选返回最终预览对象，完成闭包不得捕获重选前的空指针；模型数据、外观和证据随同一有效结果进入GUI。图片展示也采用带资源版本、尺寸和DPI的有界异步通道，绘制回调不解码或高质量缩图。高级页状态及显隐统一合并，隐藏暂停展示而不停止生成业务。普通窗口平移与恢复事务分离；仅恢复采集旧画面，标题栏和系统命令幂等共用，纯平移不得触发截图、布局或图片失效。相关CPU／交接／离屏测试和实际GPU／主窗口／流畅度验收继续分开。
