# 阶段 64：真实 Provider 四色质量闭环设计

日期：2026-08-23

## 目标

把已经完成的“AI 推荐四个目标色”从契约与 Mock 验证推进到可重复的真实 Provider 质量基准。基准先使用 GPT 推荐语义四色，再使用 Image2 生成严格四色参考图；只有本地门禁通过、视觉复核完成且经过人工明确批准的案例才有资格进入后续 Tripo 3D 验证。视觉复核保持建议性质，避免模型误报覆盖人工结论。

本阶段优先建立可信证据，不把批量实验状态塞入 Orca GUI，也不自动匹配真实耗材。

## 方案比较

### 方案 A：直接在 GUI 中批量调用

能最快看到结果，但会把样本管理、付费重试、评分和实验状态带进 `ModelGenerationPanel`，难以恢复，也会扩大 Orca 接入面。不采用。

### 方案 B：临时复用现有盲测脚本

开发量小，但现有盲测清单从固定人工色板开始，无法度量推荐色是否合理，也无法区分推荐、Image2 预览和本地门禁各阶段的失败。不采用。

### 方案 C：独立可恢复的四色质量基准

新增纯模型生成域的清单、编排器、视觉审查和汇总。每个付费阶段先落盘审计状态，已有成功产物默认复用，结果不直接触发 Tripo。该方案最适合小批量调优后扩到 20–100 例，采用此方案。

## 边界

- 新代码位于 `tools/ai/`，基准清单位于 `Docs/benchmarks/`，结果位于被忽略的 `generated_models/`。
- 复用 `recommend_printable_palette`、`generate_image`、`process_printable_image` 和 `complete_vision`。
- 不修改 `MainFrame`、`Plater`、CMake、3MF、profile、打印参数或 Orca 默认行为。
- 不自动调用 Tripo。汇总只输出 `tripo_candidate`，后续显式选择通过案例。
- 不保存 API Key；状态只记录 Provider 类型、模型名、调用次数、时间、输入指纹和产物哈希。

## 数据流

每个案例按以下阶段运行：

1. `recommendation`：GPT 根据描述、风格和可选参考图返回四个语义角色色。
2. `preview`：Image2 使用推荐色生成可打印参考图。
3. `local_gate`：现有确定性图片管线输出严格预览、清理图、建模参考图和颜色质量指标。
4. `visual_review`：GPT 对照描述、推荐角色、原始图和严格预览，检查语义匹配、大色块、颜色角色、轮廓与碎片化风险。
5. `manual_review`：生成空白人工评分模板；没有人工批准时不把案例标为最终通过。
6. `summary`：输出 JSON/CSV，分别统计 Provider 成功率、本地门禁通过率、视觉通过率和人工认可率。

推荐与 Image2 成功后立即写入产物并保存 SHA-256。若状态显示一次付费调用已经开始但没有可复用产物，默认拒绝自动重试，必须使用显式重试参数。

## 视觉审查契约

视觉审查只给出 `pass / review / unavailable`，不替代确定性门禁。检查项固定为：

- `semantic_palette_fit`：四个颜色及角色是否适合主体语义；
- `role_usage`：主体、结构、亮部、强调色是否用于合理的大区域；
- `subject_fidelity`：图像是否忠实表达输入主体；
- `silhouette_readability`：轮廓是否完整、清晰；
- `large_color_regions`：是否避免细碎色块、渐变和抖动；
- `modeling_reference`：是否适合作为后续图生 3D 参考。

总分低于 80 或任一检查为 `review` 时，自动结论为 `review`。Provider 失败返回 `unavailable`，保留本地结果，不产生隐式重试。

## 第一批样本

冻结 12 个文字输入，覆盖角色、动物、产品、建筑、车辆和有机物，并覆盖现有五种内置风格。样本不复用阶段 49 的四个调优案例，避免只验证已知提示词。

第一批验收目标：

- 12/12 推荐响应满足严格四角色、唯一颜色和对比度契约；
- 本地四色门禁通过率不低于 80%；
- AI 视觉建议与人工结论逐例保留，不用小样本宣称统计泛化；
- 至少选择 4 个不同类别案例作为后续 Tripo 候选；
- 失败可恢复，重复运行不重复调用已经完成的付费阶段。

## 后续演进

基准稳定后扩到 20 个校准样本，再冻结规则并扩到 50–100 个正式盲测。通过案例可交给现有 Tripo、结构门禁和五视图复核链路；语义局部选区与薄壁检测分别作为阶段 65、66，不与本基准耦合。
