# 局部改色交互重设计 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把 3D 预览中的局部改色从拥挤的表单改成画布优先、操作意图清晰、可即时预览并支持纠错的底部停靠编辑器。

**Architecture:** 保留现有 `VertexColorRegionEditor` 的选区算法、OBJ 副本写出和模型历史链路，仅重组 `ModelGenerationPanel` 内的 wxWidgets 控件与选择状态；选区撤销通过编辑器的显式快照恢复接口实现，不进入 Orca 切片核心、3MF 或打印配置。

**Tech Stack:** C++17, wxWidgets, OrcaSlicer OpenGL preview, Catch2

---

## 1. 用户旅程与信息层级

默认状态只展示模型画布、模型摘要、重置视角和“编辑局部颜色”入口。进入编辑后，在画布底部显示停靠工具区：第一行完成选区方式与范围设置，第二行完成耗材色选择和应用；不再使用需要理解字段含义的“点击方式/目标耗材颜色”表单。

核心旅程：

1. 打开已有 3D 模型，点击“编辑局部颜色”。
2. 使用“自动识别”点击模型部位；需要修正时切换“添加区域”或“减去区域”。
3. 直接点击四个可见耗材色块，高亮立即切换为目标颜色。
4. 查看“已选择区域 · N 个三角面”，点击“应用为耗材 N”生成新的 OBJ 副本。
5. 误操作可撤销或清空；原始 OBJ、拓扑和未选区域颜色不变。

## 2. 布局与视觉规格

- 使用 Orca 原有字体与中性色，强调色沿用现有主题；不引入独立皮肤。
- 主间距采用 8 / 12 / 16 DIP；按钮最小高度 36 DIP，避免窄而松散的表单行。
- 选区方式使用三个直接可见的互斥按钮：`自动识别`、`添加区域`、`减去区域`。
- 识别范围保留一个紧凑选择器：`精细 / 标准 / 宽松`，默认标准。
- 目标颜色使用最多四个互斥色块按钮，显示耗材序号和十六进制色值；根据背景亮度自动选择黑/白前景。
- 无选区时显示 `点击模型选择要改色的部位`；有选区时显示 `已选择区域 · N 个三角面`。
- 主操作根据目标色动态显示 `应用为耗材 N`，无选区或忙碌时禁用；撤销、清空为次级操作。

## 3. 状态模型

| 状态 | 画布 | 底部工具区 | 主操作 |
|---|---|---|---|
| 无模型 | 空态 | 隐藏 | 隐藏 |
| 已加载、未编辑 | 可旋转/缩放 | 仅入口 | 隐藏 |
| 编辑、无选区 | 可点击选区 | 显示模式/范围/色块 | 禁用并提示选择部位 |
| 编辑、已有选区 | 目标耗材色高亮 | 显示数量与纠错操作 | 启用 |
| 应用中 | 保留当前视图 | 控件禁用 | 显示处理中状态 |
| 应用成功 | 加载新 OBJ，选区清零 | 保持编辑状态 | 禁用，等待下一次选择 |

关闭编辑器时清除临时选区但不修改模型。模型加载、页面往返和历史模型加载继续走现有状态恢复路径。

## 4. 键盘与可访问性

- 色块和模式均使用原生可聚焦按钮，不能只依赖颜色表达选择状态。
- `Esc` 清空当前选区，`Ctrl+Z` 撤销最近一次选区变化。
- 所有按钮提供中文 tooltip；文本与背景保持可读对比度。
- 颜色按钮的标签同时包含耗材序号，色觉差异用户无需只靠色相判断。
