## 4. ADV-2D-01：左栏描述与生成范围

1. 左栏描述框显示输入内容、原提示和字节计数，移除「全视角」及其它视角标签。
2. 左栏描述是当前创作的全局描述；左栏生成面向当前输入允许的全部方向。
3. 当前单大图方向、缩略图焦点、四格／单图模式、3D勾选均不决定左栏生成范围。
4. 全局描述及风格继续作为各方向生成约束。现有左栏润色、风格和其它控件仅适配上述范围语义，不扩大UX修改。
5. 左栏原有生成确认流程保持；本次取消二次确认仅适用于局部描述浮层的单视角提交。

## 5. ADV-2D-02：有图与无图的生成范围

1. 没有任何原图时，沿用有效文字描述生成四个方向；无图且无有效描述时沿用原输入校验。
2. 有原图时，仅生成已上传方向：上传1／2／3／4张，左栏一次生成对应1／2／3／4张设计图。
3. 图片模式下，左栏批量生成以当前上传原图的方向为范围。独立的星芒入口按第9节校验。
4. 四个方向保持固定槽位。少于四图不意味着本次新增方向、自动合成缺失图或重新排列现有四格。
5. 删除所有原图后，下一次显式左栏生成按纯文字四图规则处理，不自动发起生成或恢复已失效旧图。

## 6. ADV-2D-03：上传、替换和删除

1. 必须先上传主视角，才允许上传辅助方向；点击上传和拖入均执行同一规则。
2. 删除或替换某个原图后，立即清空该方向中央设计图显示；替换后等待新设计图成功再显示，旧图不回填。
3. 清空的设计图退出可用3D输入；历史原件与旧模型证据沿现有规则保留。
4. 仍有辅助原图时删除主图，只清空主图及对应设计图，保留其它原图和设计图。
5. 补回主图前，暂停生成以及辅助原图新增／替换；仍可查看和删除辅助图。
6. 删除全部原图后回到无原图输入规则；不自动提升辅助图为主图。

## 7. ADV-2D-04：2D取消业务选图，3D方案A承接改选

### 7.1 2D页面

1. 单击中央设计图不执行选中或取消。
2. 中央设计图不显示原选中描边和勾选角标。
3. 保留现有双击查看大图能力；新单大图展示模式与原双击弹窗分别保留，不相互替代。
4. 点击缩略图、模式切换、星芒或关闭／发送不触发卡片业务选择。
5. 旧“已有模型后回2D点选下一次建模图片”的入口由方案A替代，原规则和用例须对应更新。

### 7.2 首次建模前

1. 3D展示输入设计图时，与2D共用中栏的四格／单大图及当前视角。四格单击图片选中或取消，保留选中描边和右上角勾选，双击查看原图。
2. 首次建立建模选择时，默认勾选全部可用设计图，主视角必须勾选且不可取消。
3. 辅助方向允许手动取消或选入；不可用图片不能新选入；已选后失效的辅助图仍允许取消。
4. 普通切Tab及同方向设计图更新保留用户已确认的方向偏好。
5. 3D单大图的四个图内缩略图各有一个常显右上角勾选框。点勾选框立即更改建模选择并保留所看视角，点缩略图主体只切换预览。当前预览保留白色描边。勾选区按主视角必选与辅助图可用性显示相应状态，禁用时也保留独立点击区。3D的四格及单大图悬停时保持原图亮度。2D保留悬停蒙层和星芒。

### 7.3 已有模型后的方案A

1. 点击现有“重新生成”，在同一个模型生成确认弹窗显示当前设计图缩略图并改选。
2. 回显原3D方向偏好，不每次自动全选；展示和提交使用当前可用设计版本。
3. 主视角必选，辅助可选；失效辅助图可取消，但不可选入不可用图。
4. 取消弹窗不提交任务、不修改原方向偏好；最终确认才采用新选择并保存偏好。
5. 弹窗中的视角、张数与实际冻结及上传图片完全一致；旧选图计划不能继续用于新勾选。
6. 3D任务的生成、加载、停止、失败和模型结果由任务视图接管中栏。已有模型从“重新生成”进入本节的选图确认。

### 7.4 单图／多图路由保留

| 供应商 | 仅主视角1张 | 主视角＋任意1～3张辅助图 |
| --- | --- | --- |
| Tripo | 单图生成模型能力 | 多图生成模型能力，实际上传2～4张 |
| YOYOClaw | 单图生成模型能力 | 多图生成模型能力，实际上传2～4张 |

沿用现有供应商选择与参数，不借本次改动迁移接口或扩大能力。后续验证覆盖两家单图／多图四条路径，并核对确认内容、冻结版本和实际输入。

## 8. ADV-2D-05：四格、单大图及预览状态

1. 默认四格，沿用当前四个固定方向的位置；未生成、已删除或失败方向显示对应空位／既有状态，不补图。
2. 中栏底部独立居中显示四格／三横线模式切换，切模式时开关保持原位置。
3. 单大图一次显示一个方向。大图内部底部居中的四个固定槽位提供切换，缺图方向保留状态占位。
4. 缩略图悬停显示眼睛和视角名，当前方向用描边区分；点击只切换大图，不改变生成范围或3D勾选。
5. 同一创作在2D与3D输入页手动往返、首次生成成功自动跳转及图片更新时，保留展示模式、预览方向和布局位置。两页共享中栏底部的模式切换。
6. 新建、打开另一创作或重启后回到四格，不新增跨创作或重启的预览状态持久化。
7. 每个创作首次切单大图显示主视角；之后四格与单大图往返记住上次方向。
8. 当前方向失去图片时仍对应本方向的空位及状态。
9. 2026-11-25确认四格单卡260×350、间距8，单大图548×740。两种布局均使用16 DIP圆角、等比居中铺满。可用空间不足时按比例缩小，四格整组和单大图在中栏顶部状态提示与底部模式切换之间上下居中。双击查看原图。两模式在图内顶部居中显示52×24的视角名，距顶12，圆角8，黑底65%，白字12／行高18。
10. 有图时仅悬停卡片叠加Figma六色标渐变及对应星芒，名称常显。无图失败卡由现有补生成资格决定星芒是否可见。空位、排队、生成中、失败和待重新生成使用现有状态。

## 9. ADV-2D-06：单视角局部描述和重生成

### 9.1 浮层和生命周期

1. 四格中每个有当前设计图或明确失败状态的方向，以及单大图中的对应方向，都从左下星芒打开本方向的浮层。尚未生成的空槽位不提供入口。
2. 使用页面内浮层，只保留星芒标识、关闭按钮、多行输入框和发送箭头。去掉未圈工具及推荐语后收缩高度。
3. 点击关闭不提交，并清空本次局部描述；下次打开不自动恢复关闭前文字。
4. 点击发送后校验通过即直接提交1张，不再弹第二次确认，也不要求因为局部重生成而重新确认首次全局生成。
5. 请求提交成功后关闭浮层；校验或提交失败时保留输入。这里的提交成功指请求已受理，不要求等待图片生成完成；原未决请求恢复和防重复提交保护继续执行。
6. 已提交局部描述保留在该次生成记录中，供原历史／恢复流程读取；不新增历史面板或文本编辑功能。

### 9.2 文字、基底和范围

1. 局部描述允许为空，表示使用当前描述和风格重生成；空文字不单独使发送按钮禁用。
2. 有当前设计图时，以该图为编辑基底；沿用全局描述及风格，并叠加本次局部描述。
3. 局部与全局描述冲突时，只在本方向采用局部描述优先，其它方向不受影响。
4. 局部描述不回写左栏全局描述，不污染全局草稿和原3D生成资格。
5. 上限沿用原2000字节规则；不新增计数算法或未圈出的控件。
6. 严格只请求本方向，不能把其它待更新方向自动并入本次任务；其它设计图不因本次局部操作被清空或重画。
7. 有当前设计图时，可使用该图作为本方向的编辑基础，包括只有主视角原图的历史四图套图。无当前图的失败方向优先参考本方向原图，其次参考主视角原图或设计图。纯文字场景缺参考图时可用全局或局部描述重试当前方向。每次请求限一张。
8. 上传的主视角缺失且还有辅助原图时，发送继续执行补主图校验。发送的其它输入、能力及任务状态校验沿既有规则，明确失败时保留浮层与输入。

## 10. 保留的业务与兼容保护

- 空白创作及“新建创作”后的首次全范围设计任务，全部目标成功且图片可用后才自动进入3D Tab；部分失败不自动跳。用户返回2D后，同一创作后续生成不再自动跳，新建重新开始一次性规则。局部重生成不新增自动跳转触发。
- 部分失败时，待操作结束且主图可用，仍可手动进入3D并用合法成功图建模；未选失败辅助图不阻断合法输入。
- 原忙碌、只读、停止、失败、未决请求、输入版本校验及过期结果保护保留；晚到回调不得串入另一创作或恢复已失效设计图。
- 模型冻结输入、点云、模型展示、工程／工作台交接及旧历史读取沿用原规则；新增局部记录字段须兼容旧数据。
