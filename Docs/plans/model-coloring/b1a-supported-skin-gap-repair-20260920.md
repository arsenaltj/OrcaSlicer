# B1a 侧颈皮肤碎片与背景漏洞修复

日期：2026-09-20  
分支：`codex/exp/mobile-sam-local-validation`  
冻结识别输入：`D:\测试验收\B1a-eyebrow-extent-1024\right\analysis-candidate.json`

## 问题归因

刘亦菲右侧耳后和后颈的残留不是眉毛越界。固定探针框
`right (430,340)-(630,530)` 显示：

- 灰色槽有 4,026 像素，其中 685 个原面标签为 `BodySkin`；这些面大多因置信度低于 0.70 没有进入材料发现。
- 粉色槽有 790 像素、242 个原面，其中 241 个标签为 `Background`；其原色仍为兼容的暖肤色。
- 原探针只统计 `FaceSkin` 邻居，漏掉 `BodySkin`。修正后确认粉色区域有 84 个面直接共享可靠皮肤边。

## 候选过程

1. **低置信皮肤和背景的空间支持补全**：灰色降至 2,754，粉色降至 771。灰色改善有效，背景漏洞改善不足。
2. **最多三圈空间传播**：只比第一候选多修复 1 个灰色像素，粉色不变，证明传播深度不是主要瓶颈。
3. **共享边皮肤归属可继续传播**：灰色降至 653，粉色降至 245，但恢复后的 `Background` 又成为供体，沿暖色白衣传播，候选淘汰。
4. **终端共享边修复**：共享边供体必须是原始高置信 `FaceSkin/BodySkin`；恢复后的 `Background/Unknown` 不得继续作为供体。该候选保留。

## 最终保留规则

- 低置信 `FaceSkin/BodySkin`、`Unknown` 和 `Background` 只有在原色兼容、法向连续、邻近材料归属唯一时才能继承皮肤材料。
- `Hair` 和 `Clothes` 不进入皮肤缺口候选。
- 高饱和红色、非流形共享边、五官保护冲突和两个皮肤材料同时争夺时拒绝。
- 共享边优先只接受原始高置信皮肤语义。恢复后的背景面是终端结果，不能继续扩张。
- 面部供体继续使用严格兼容阈值；身体皮肤供体允许更宽的颈部光照变化。
