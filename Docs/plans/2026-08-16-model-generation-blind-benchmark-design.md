# 模型生成盲测基准设计

## 目标

用未参与提示词和后处理调优的新样本，验证“文字 → 四色参考图 → 3D → 顶点色 OBJ → 结构/视觉复核”闭环是否稳定，而不是继续凭单个成功案例调效果。

第一批是校准批，不追求样本量：4 个新任务，覆盖角色/动物、稳定商品和复杂结构物。校准评分表、恢复机制和成本记录后，再扩到 50–100 个样本。

## 约束

- 每个样本最多 1 次 Image2、1 次 Tripo 生成、1 次 OBJ 转换、1 次视觉复核。
- 第一批最多新增 4 次 Tripo 生成；默认 30 万面。
- 调用前必须显式传入付费确认参数；状态文件存在时只恢复，不重复创建任务。
- 盲测运行期间冻结提示词、风格和结构/视觉阈值，不根据中间结果改规则。
- 四个样本使用不同的真实四耗材色板，验证动态色板而非固定红绿蓝白。
- 所有参考图、任务 ID、模型、报告和人工评分表只写入 `generated_models/model-blind-benchmark-phase49/`。

## 数据流

1. 清单加载后生成不可变的样本指纹。
2. Image2 生成一张干净的设计师玩具参考图。
3. 本地图片管线量化为严格四耗材色，并输出透明 `model_reference.png`。
4. Tripo 只读取该模型参考图，生成并转换 OBJ。
5. 既有后处理生成最多四色的顶点色 OBJ。
6. 本地结构门禁生成 `model-quality.json`。
7. 五视图渲染与 AI 视觉复核生成 `visual-quality.json`。
8. 汇总器生成 `benchmark-summary.json`、`benchmark-summary.csv` 和每例 `human-review.json`。

## 人工评分

每项 1–5 分：提示符合度、主体完整性、语义连贯性、轮廓可读性、底座/接地关系、四色块清晰度、打印准备度。人工结论为 `pass / review / fail`，并记录主要缺陷和是否愿意直接进入 Orca。

自动结论与人工结论分别保留，不互相覆盖。结构 `reject` 仍是硬阻断；视觉结果仅给建议。第一批完成后计算自动与人工是否一致，再决定阈值或提示词是否需要修改。

## 恢复与防重复

- 每例有独立目录和 `case-state.json`。
- 已有参考图时不再请求 Image2；已有 Tripo `validation-state.json` 时只轮询原任务。
- 清单指纹发生变化时拒绝在原目录继续，防止结果串样。
- 单例失败写入状态后继续下一例，失败本身作为盲测数据保留。
- 汇总阶段不产生任何付费请求，可反复执行。

## 验收

- 无付费确认参数时只能完成清单校验/汇总，绝不创建远端任务。
- 中断后重跑不会创建第二个 Tripo 生成任务。
- 四例均有独立参考图、任务状态及可审计调用计数。
- 成功生成的模型均有结构和视觉报告；失败例有明确阶段和错误。
- 自动汇总和人工评分表可直接用于下一批 50–100 例扩展。
