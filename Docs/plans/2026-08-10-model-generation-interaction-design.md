# 3D Generate 页面交互优化设计

## 目标

在不修改模型导入流程和切片核心的前提下，解决演示页面的三个高频误解：参考图无法完整查看、生成时看起来长期卡在第一步，以及图片模式跳过二维风格确认直接生成 3D。

本轮仅面向 Windows 演示主链。macOS、Linux、模型三维预览和工作流扩展不在范围内。

## 交互决策

### 参考图预览

- 用户选图后立即显示原始参考图，不等待 AI 预处理。
- 默认采用完整适配，保持原始宽高比，不裁切。
- 标题栏提供缩小、适配、放大和当前百分比；缩放范围为 50% 到 400%。
- 放大后预览区本身滚动，页面布局和左侧操作区不随图片尺寸变化。
- 图下显示图片来源、像素尺寸和当前结果摘要；空状态保留明确提示。

### 图片 + 文字的两段式生成

- 图片模式固定为 `参考图 + 文字指令 → AI 风格预览 → 用户审核 → 3D 生成 → 导入`。
- 选图后标题显示 `Reference image`；AI 风格图下载并成功解码后切换为 `AI style preview`，避免用户混淆输入与结果。
- `Generate 3D from preview` 在 AI 风格图成功显示前保持禁用；点击后再次确认本次 3D 生成基于当前风格预览并可能消耗额度。
- 图片预处理不允许降级为复制原图。`/images/edits` 未配置、失败或返回无效图片时任务失败，3D 生成继续禁用。
- 文字模式仍可通过显式演示开关保留原始 prompt 降级，不影响图片模式的强确认门槛。

### 生成进度

进度以用户可理解的五个阶段表达，而不是直接显示 provider 内部百分比：

| 步骤 | 用户阶段 | 显示范围 |
|---|---|---:|
| 1 | Input | 0% |
| 2 | Prepare prompt / Create style preview | 10%–25% |
| 3 | Review prompt / Review style preview | 35% |
| 4 | Generate / Finalize model | 40%–92% |
| 5 | Import model | 95%–100% |

进度条上方同时显示 `Step N of 5 · 阶段名` 和百分比。provider 的生成、转换和产物准备状态映射到第四步的不同区间，避免任务已推进但进度仍像停在预处理阶段。错误发生时保留最后阶段和进度，由状态文案说明失败原因。

## 布局与状态

- 左侧工作流保持固定窄栏并独立纵向滚动，右侧优先留给预览。
- 预览区有稳定最小尺寸，由 `wxScrolledWindow` 双缓冲自绘；图片位图不参与外层 sizer 的尺寸计算。
- 无图片时禁用缩放控件；达到缩放上下限时禁用对应按钮；适配状态下禁用 Fit。
- 图片选择、预处理结果返回、窗口调整尺寸和缩放操作都复用同一预览更新路径。
- 选择新图片时清理旧远端任务，避免页面显示新输入却继续操作旧任务。
- 左侧流程摘要采用两行布局，动态状态按窄栏宽度换行，长文件名以尾部省略号显示。

## 验收标准

- 1080×1620 竖图默认完整显示且不改变页面宽度。
- 点击放大后百分比变化，位图超过预览高度时出现可滚动范围；点击 Fit 恢复完整适配。
- 图片模式在参考图阶段禁用 3D 生成；AI 风格预览成功下载并显示后才启用。
- 图片风格化失败时显示真实错误，不得进入可确认状态，也不得把参考图标记为 AI 风格预览。
- Review 显示第三步和 35%；Generate 从第四步和 40% 开始；转换、产物准备、Ready 持续向前推进。
- Release 构建通过，现有 AI Python 回归通过，`git diff --check` 无空白错误。
