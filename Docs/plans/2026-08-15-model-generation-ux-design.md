# 3D 生成页面渐进式交互设计

## 目标

让第一次使用的用户始终知道“现在要做什么、下一步会发生什么”，同时保留专业用户需要的色板、打印约束、导入颜色和自动切片能力。

## 用户旅程

1. **输入**：文字、图片至少提供一项；选择风格和是否限制为可打印颜色。
2. **图片确认**：对照参考图与 AI 图片；必要时切换严格色板、清理图和热力图；确认后选择 3D 模型精度。
3. **生成 3D**：显示生成、转换和下载进度，可安全停止任务。
4. **导入**：检查 3D 预览，再选择颜色处理和是否自动切片。

## 布局原则

- 左栏顶部固定四步进度，中央只滚动当前阶段的设置，底部固定状态和唯一主操作。
- 首屏不展示模型面数、导入颜色和自动切片，避免用户在尚未看到结果时处理后续决策。
- 喷嘴、线宽、尺寸和最小特征保留在折叠的“高级打印约束”中；默认值覆盖演示和常规打印。
- 模型精度只在图片/提示词确认后出现，不再让精度变化导致图片预览失效。
- 导入颜色与自动切片只在 3D 模型就绪后出现。
- 右栏按“图片确认 / 3D 预览 / 历史模型”组织结果，继续复用现有预览保持和模型库逻辑。

## 状态与主操作

| 状态 | 主操作 | 次操作 |
|---|---|---|
| 无输入 | 生成图片预览（禁用） | 无 |
| 输入完成 | 生成图片预览 | 无 |
| 图片生成中 | 停止生成 | 无 |
| 等待确认 | 确认图片并生成 3D | 重新开始 |
| 3D 生成中 | 停止生成 | 无 |
| 3D 已就绪 | 导入并自动切片 / 导入到准备页 | 重新开始 |
| 输入或色板已变化 | 重新生成图片预览 | 重新开始 |

## 兼容边界

- 不改变 Sidecar 契约、付费确认、任务恢复、OBJ 解析、模型库或 Orca 导入适配器。
- 保留文字、图片、文字加图片三种输入方式。
- 保留自然颜色和可打印颜色两条链路。
- 保留手动匹配、自动匹配和单色导入三种颜色处理方式。
- 页面切换后继续保留图片和 3D 预览状态。

## 验证

- Windows Release 编译并链接 `OrcaSlicer.dll`。
- 正式 Orca 中检查初始、等待图片确认、3D 就绪三个状态。
- 检查主操作始终可见、高级约束可展开、阶段控件只在对应阶段出现。
- 检查更改模型精度不会把已确认的图片预览标记为过期。
- 不创建新的 Image2 或 Tripo 任务完成本轮交互验证。
