# 人像一体底座设计

日期：2026-08-28

## 目标与边界

调研确认人像预览如果沿用“源图无底座就不新增底座”，进入 3D 后常出现胸像无稳定接触面、全身人物只靠脚尖或阴影落地的问题。新规则把底座定义为人物类别唯一允许新增的结构性元素，应用于单色雕塑、多色写实、多色卡通和自定义风格，也同时覆盖图片输入与文字输入。非人物对象继续保留源图底座语义，避免鞋、相机、车辆、建筑等被无差别改成展台模型。

## 构图与数据流

Image2 提示词先判断主体是否为真人或人形角色。半身、胸像和裁切人像保持原可见解剖范围，将现有躯干或衣物下缘干净收口并连接到一个低矮圆形、椭圆形或柔和多边形台座，不补造骨盆、腿脚。完整站姿、坐姿或蹲姿保持原姿势，把脚、衣摆或座椅等最低接触点连接到底座。用户明确要求多人时，所有人物共享一个底座，同时保留人数、左右顺序、间距、姿势和配饰。底座必须平底、实体连接、视觉从属；多色模式使用一个大块耗材色区域，单色模式与人物同材质。

## 验证

单元测试锁定人像必有底座、半身不补腿、多人共享底座和非人物不新增底座四个条件；验证清单增加平底、实体连接和禁止阴影接触/悬浮的人工检查项。此次只改变 Image2 构图契约与测试文档，不改变 3MF、打印机配置、切片默认值、API 协议或付费调用次数。
